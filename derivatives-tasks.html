Профессиональные задачи: Производная

📖 Зачем это нужно в профессии?

Производная — это не просто штрих в тетради. Это скорость изменения любой величины. Когда вы следите за тем, как остывает деталь, как падает напряжение в сети, как меняется нагрузка на кран или как ускоряется автомобиль, вы имеете дело именно с производной.

Электрик использует производную для расчёта тока (ток — это скорость изменения заряда). Автомеханик — для ускорения. Сварщик — для контроля скорости остывания шва. Технолог — для нахождения оптимальных режимов резания. И везде важно не просто посчитать, а сделать вывод: пройдёт ли деталь контроль, выдержит ли конструкция, не сорвётся ли график.

💡 Как пользоваться:
Выберите свою специальность ниже. В каждой — 4 задачи с подробным разбором и 7 задач для самостоятельной работы (с подсказками). Считайте так, как будто вы уже на объекте.
⚡ ЭРЭО (Электрика) Скорость изменения тока, напряжения и нагрева
📘 Задачи с подробным решением (4)
Изучите эти примеры, чтобы понять, как применять производную на практике.

При включении двигателя сила тока в обмотке меняется по закону $I(t) = 5t^2 + 2t$ (А), где $t$ — время в секундах. Инженеру нужно найти скорость изменения тока в момент $t = 3$ с. Если она превышает $35$ А/с, сработает защита.

Шаг 1. Находим производную. Скорость изменения тока — это производная $I'(t) = 10t + 2$.

Шаг 2. Подставляем $t = 3$. $I'(3) = 10 \cdot 3 + 2 = 32$ А/с.

Ответ: $32$ А/с < $35$ А/с. Защита не сработает.

При нагреве кабеля его сопротивление меняется по закону $R(t) = 0{,}1t^3 - 0{,}5t^2 + 2$ (Ом), где $t$ — температура в десятках градусов. Технологу нужно найти момент времени (температуру), когда сопротивление растёт максимально быстро. Если скорость роста превысит $2$ Ом/ед., изоляция начнёт плавиться.

Шаг 1. Скорость роста. $R'(t) = 0{,}3t^2 - t$.

Шаг 2. Максимальная скорость. Это экстремум производной. Найдём $R''(t) = 0{,}6t - 1$. Приравняем к нулю: $0{,}6t = 1 \Rightarrow t \approx 1{,}67$.

Шаг 3. Проверяем значение. $R'(1{,}67) = 0{,}3 \cdot 2{,}79 - 1{,}67 = 0{,}837 - 1{,}67 \approx -0{,}83$ Ом/ед. (это минимум, скорость роста на самом деле отрицательная, то есть сопротивление падает). Проверим границы: при $t=0$ $R'=0$, при $t=3$ $R'=2{,}7 - 3 = -0{,}3$. Скорость роста нигде не превышает $2$.

Ответ: Максимальная скорость роста (по модулю) не превышает $2$ Ом/ед. Изоляция в норме.

Электрик измеряет скорость изменения напряжения в цепи. Напряжение задано функцией $U(t) = t^3 - 6t^2 + 9t + 2$ (В). Нужно найти моменты времени, когда скорость изменения напряжения равна нулю (переходные процессы). Если хотя бы в один из этих моментов напряжение падает ниже $2$ В, оборудование отключится.

Шаг 1. Производная. $U'(t) = 3t^2 - 12t + 9$.

Шаг 2. Приравниваем к нулю. $3t^2 - 12t + 9 = 0 \Rightarrow t^2 - 4t + 3 = 0$. Корни: $t = 1$ и $t = 3$.

Шаг 3. Значения напряжения. $U(1) = 1 - 6 + 9 + 2 = 6$ В. $U(3) = 27 - 54 + 27 + 2 = 2$ В.

Ответ: В момент $t = 3$ напряжение равно $2$ В (на границе). Оборудование может отключиться, если падение продолжится.

При зарядке конденсатора энергия меняется по закону $W(t) = 0{,}5t^2 + 2t$ (Дж). Найдите ускорение изменения энергии (вторую производную) в момент $t = 2$ с. Если ускорение больше $1{,}5$ Дж/с², конденсатор может выйти из строя.

Шаг 1. Первая производная (скорость). $W'(t) = t + 2$.

Шаг 2. Вторая производная (ускорение). $W''(t) = 1$.

Шаг 3. Значение. $W''(2) = 1$ Дж/с².

Ответ: Ускорение $1$ Дж/с² < $1{,}5$ Дж/с². Конденсатор в норме.

✍️ Задачи для самостоятельной работы (7)
Время проверить себя! Решите задачи в тетради, а если возникнут трудности — загляните в подсказки.

Скорость изменения тока. Сила тока в цепи меняется по закону $I(t) = 3t^2 + 5t - 1$. Найдите скорость изменения тока при $t = 2$ с. Если она больше $20$ А/с, нужен предохранитель.

$I'(t) = 6t + 5$. $I'(2) = 12 + 5 = 17$ А/с. $17 < 20$, предохранитель не нужен.

Остывание нагревателя. Температура нагревателя после выключения меняется по закону $T(t) = 120 \cdot e^{-0{,}1t}$ (в градусах, $t$ — минуты). Найдите скорость остывания при $t = 10$ мин. Если она меньше $-5$ °C/мин, нагреватель остывает слишком медленно.

$T'(t) = 120 \cdot (-0{,}1)e^{-0{,}1t} = -12e^{-0{,}1t}$. При $t=10$: $-12e^{-1} \approx -4{,}4$ °C/мин. По модулю $4{,}4 < 5$, остывает медленно.

Максимум мощности. Мощность в цепи зависит от сопротивления: $P(R) = \frac{100R}{(R+5)^2}$. Найдите сопротивление, при котором мощность максимальна (производная равна нулю). Если это сопротивление больше $10$ Ом, схему нужно пересмотреть.

$P'(R) = \frac{100(R+5)^2 - 100R \cdot 2(R+5)}{(R+5)^4} = \frac{100(R+5) - 200R}{(R+5)^3} = \frac{500 - 100R}{(R+5)^3}$. Приравниваем к нулю: $R = 5$ Ом. $5 < 10$, схема в норме.

Переходный процесс. Напряжение меняется по закону $U(t) = t^3 - 3t^2 + 4$. Найдите моменты, когда скорость изменения напряжения отрицательна (напряжение падает). Если падение длится более $2$ секунд, оборудование может отключиться.

$U'(t) = 3t^2 - 6t = 3t(t - 2)$. $U'(t) < 0$ на интервале $(0; 2)$. Длительность падения $2$ с, ровно на границе.

Вторая производная (ускорение). Заряд конденсатора меняется по закону $q(t) = 2t^3 - 3t^2 + t$. Найдите ускорение изменения заряда при $t = 1$ с (вторую производную). Если оно больше $5$ Кл/с², конденсатор перегреется.

$q'(t) = 6t^2 - 6t + 1$, $q''(t) = 12t - 6$. $q''(1) = 12 - 6 = 6$ Кл/с². $6 > 5$, перегрев возможен.

Оптимальная нагрузка. КПД трансформатора $\eta(x) = \frac{x}{x^2 + 4}$ (в долях). Найдите нагрузку $x$, при которой КПД максимален. Если оптимальная нагрузка меньше $1$, трансформатор неэффективен.

$\eta'(x) = \frac{x^2+4 - x \cdot 2x}{(x^2+4)^2} = \frac{4 - x^2}{(x^2+4)^2}$. Приравниваем к нулю: $x = 2$. $2 > 1$, трансформатор эффективен.

Скорость изменения сопротивления. Сопротивление провода при нагреве: $R(t) = 0{,}02t^2 + 0{,}3t + 10$. Найдите скорость изменения сопротивления при $t = 5$ (в градусах). Если она больше $0{,}5$ Ом/град, провод перегреется.

$R'(t) = 0{,}04t + 0{,}3$. $R'(5) = 0{,}2 + 0{,}3 = 0{,}5$ Ом/град. Ровно на границе.
🚗 ТОА / Автомеханик Скорость, ускорение и оптимальные режимы
📘 Задачи с подробным решением (4)
Изучите эти примеры, чтобы понять, как применять производную на практике.

При разгоне автомобиля его путь меняется по закону $S(t) = 2t^2 + 3t$ (м). Найдите скорость через $4$ секунды после старта (производная пути). Если скорость превысит $20$ м/с, водитель превысил ограничение.

Шаг 1. Скорость — производная пути. $v(t) = S'(t) = 4t + 3$.

Шаг 2. Подставляем $t = 4$. $v(4) = 16 + 3 = 19$ м/с.

Ответ: $19$ м/с < $20$ м/с. Нарушения нет.

При торможении скорость автомобиля меняется по закону $v(t) = 20 - 4t$ (м/с). Найдите ускорение (производную скорости) и определите, за какое время автомобиль полностью остановится. Если ускорение по модулю превышает $5$ м/с², пассажиры получат травмы.

Шаг 1. Ускорение — производная скорости. $a(t) = v'(t) = -4$ м/с².

Шаг 2. Время остановки. $v(t) = 0 \Rightarrow 20 - 4t = 0 \Rightarrow t = 5$ с.

Ответ: Ускорение по модулю $4$ м/с² < $5$ м/с². Остановка через $5$ с, травм не будет.

Расход топлива автомобиля зависит от скорости: $Q(v) = 0{,}01v^2 - 0{,}8v + 30$ (л/100 км). Найдите скорость, при которой расход минимален (производная равна нулю). Если эта скорость меньше $30$ км/ч, автомобиль неэффективен на трассе.

Шаг 1. Производная. $Q'(v) = 0{,}02v - 0{,}8$.

Шаг 2. Приравниваем к нулю. $0{,}02v = 0{,}8 \Rightarrow v = 40$ км/ч.

Ответ: $40$ км/ч > $30$ км/ч. Автомобиль эффективен на трассе.

Мощность двигателя меняется по закону $N(t) = 100t - 5t^2$ (л.с.). Найдите момент, когда мощность максимальна, и определите, насколько она превышает паспортные $400$ л.с. Если максимум меньше $400$, двигатель неисправен.

Шаг 1. Производная. $N'(t) = 100 - 10t$.

Шаг 2. Максимум. $N'(t) = 0 \Rightarrow t = 10$ с. Максимум $N(10) = 1000 - 500 = 500$ л.с.

Ответ: Максимум $500$ л.с. > $400$ л.с. Двигатель в норме (даже мощнее паспорта).

✍️ Задачи для самостоятельной работы (7)
Время проверить себя! Решите задачи в тетради, а если возникнут трудности — загляните в подсказки.

Скорость автомобиля. Путь задан $S(t) = t^3 - 3t^2 + 4t$. Найдите скорость при $t = 2$ с. Если она больше $10$ м/с, водитель превышает.

$v(t) = 3t^2 - 6t + 4$. $v(2) = 12 - 12 + 4 = 4$ м/с. $4 < 10$, нарушения нет.

Ускорение. Скорость $v(t) = 3t^2 - 2t + 1$. Найдите ускорение при $t = 3$ с. Если оно больше $15$ м/с², перегрузка.

$a(t) = 6t - 2$. $a(3) = 18 - 2 = 16$ м/с². $16 > 15$, перегрузка.

Оптимальная скорость. Расход топлива $Q(v) = 0{,}02v^2 - 1{,}2v + 25$. Найдите скорость минимального расхода. Если она меньше $25$ км/ч, автомобиль неэффективен.

$Q'(v) = 0{,}04v - 1{,}2$. Приравниваем: $v = 30$ км/ч. $30 > 25$, эффективен.

Максимум мощности. $N(t) = 50t - 2t^2$. Найдите момент максимальной мощности. Если максимум меньше $300$ л.с., двигатель слабый.

$N'(t) = 50 - 4t = 0 \Rightarrow t = 12{,}5$. Максимум $N = 625 - 312{,}5 = 312{,}5$ л.с. $312{,}5 > 300$, двигатель в норме.

Тормозной путь. Скорость при торможении $v(t) = 15 - 3t$. Найдите путь до остановки (интеграл не нужен, просто момент остановки). Если остановка позже $4$ с, тормоза слабые.

$v = 0 \Rightarrow t = 5$ с. $5 > 4$, тормоза слабые.

Скорость изменения расхода. Расход топлива $Q(t) = 0{,}5t^2 - 2t + 10$. Найдите скорость изменения расхода при $t = 3$ с. Если она больше $2$ л/с, водитель слишком резко давит на газ.

$Q'(t) = t - 2$. $Q'(3) = 1$ л/с. $1 < 2$, режим нормальный.

Вторая производная (ускорение). Путь $S(t) = t^3 - 6t^2 + 9t$. Найдите ускорение при $t = 2$ с. Если оно отрицательное, автомобиль замедляется.

$v(t) = 3t^2 - 12t + 9$, $a(t) = 6t - 12$. $a(2) = 12 - 12 = 0$. Ускорение нулевое, автомобиль движется равномерно.

При точении детали температура резца меняется по закону $T(t) = 20 + 5t^2 - 0{,}5t^3$ (в градусах, $t$ — минуты). Найдите скорость изменения температуры при $t = 2$ мин. Если она больше $15$ °C/мин, резец перегреется.

Шаг 1. Производная. $T'(t) = 10t - 1{,}5t^2$.

Шаг 2. Подставляем $t = 2$. $T'(2) = 20 - 6 = 14$ °C/мин.

Ответ: $14$ °C/мин < $15$ °C/мин. Резец в норме.

Износ резца зависит от скорости резания: $I(v) = 0{,}02v^2 - 0{,}4v + 5$ (в мкм/мин). Найдите скорость резания, при которой износ минимален (производная равна нулю). Если эта скорость меньше $8$ м/мин, режим выбран неверно.

Шаг 1. Производная. $I'(v) = 0{,}04v - 0{,}4$.

Шаг 2. Приравниваем к нулю. $0{,}04v = 0{,}4 \Rightarrow v = 10$ м/мин.

Ответ: $10$ м/мин > $8$ м/мин. Режим выбран верно.

Скорость съёма металла зависит от подачи: $V(s) = 4s^2 - s^3$ (см³/мин). Найдите подачу, при которой скорость съёма максимальна. Если она меньше $2$ мм/об, станок работает неэффективно.

Шаг 1. Производная. $V'(s) = 8s - 3s^2$.

Шаг 2. Приравниваем к нулю. $s(8 - 3s) = 0 \Rightarrow s = 0$ или $s = \frac{8}{3} \approx 2{,}67$ мм/об.

Ответ: $2{,}67$ мм/об > $2$ мм/об. Станок работает эффективно.

Мощность резания меняется по закону $N(t) = 10t - 0{,}5t^2$ (кВт). Найдите ускорение изменения мощности (вторую производную) в момент $t = 3$ мин. Если ускорение по модулю больше $1{,}5$ кВт/мин², станок вибрирует.

Шаг 1. Первая производная. $N'(t) = 10 - t$.

Шаг 2. Вторая производная. $N''(t) = -1$ кВт/мин².

Ответ: Ускорение по модулю $1$ кВт/мин² < $1{,}5$ кВт/мин². Вибрации нет.

✍️ Задачи для самостоятельной работы (7)
Время проверить себя! Решите задачи в тетради, а если возникнут трудности — загляните в подсказки.

Скорость нагрева. Температура резца $T(t) = 25 + 3t^2$. Найдите скорость нагрева при $t = 3$ мин. Если она больше $20$ °C/мин, резец перегреется.

$T'(t) = 6t$. $T'(3) = 18$ °C/мин. $18 < 20$, в норме.

Минимальный износ. Износ $I(v) = 0{,}05v^2 - 0{,}8v + 10$. Найдите скорость минимального износа. Если она меньше $5$ м/мин, режим неверный.

$I'(v) = 0{,}1v - 0{,}8 = 0 \Rightarrow v = 8$ м/мин. $8 > 5$, режим верный.

Максимум производительности. $V(s) = 6s^2 - s^3$. Найдите подачу максимума. Если она меньше $3$ мм/об, станок неэффективен.

$V'(s) = 12s - 3s^2 = 0 \Rightarrow s = 4$ мм/об. $4 > 3$, эффективен.

Скорость изменения мощности. $N(t) = 8t - 0{,}2t^2$. Найдите скорость изменения при $t = 5$. Если она меньше $5$ кВт/мин, станок теряет мощность.

$N'(t) = 8 - 0{,}4t$. $N'(5) = 8 - 2 = 6$ кВт/мин. $6 > 5$, в норме.

Ускорение изменения мощности. $N(t) = 12t - 0{,}5t^2$. Найдите вторую производную при $t = 2$. Если ускорение по модулю больше $1{,}2$, станок вибрирует.

$N'(t) = 12 - t$, $N''(t) = -1$. По модулю $1 < 1{,}2$, вибрации нет.

Оптимальный угол. Сила резания $F(\alpha) = 10\sin\alpha + 5\cos\alpha$ (условно). Найдите угол (в градусах), при котором сила максимальна. (Подсказка: производная по углу). Если угол больше $45^\circ$, резец может сломаться.

$F'(\alpha) = 10\cos\alpha - 5\sin\alpha = 0 \Rightarrow \tan\alpha = 2 \Rightarrow \alpha \approx 63{,}4^\circ$. $63{,}4 > 45$, резец под угрозой.

Скорость остывания. Температура детали после обработки: $T(t) = 150e^{-0{,}05t}$. Найдите скорость остывания при $t = 20$ мин. Если она меньше $-2$ °C/мин, деталь остывает слишком медленно.

$T'(t) = -7{,}5e^{-0{,}05t}$. При $t=20$: $-7{,}5e^{-1} \approx -2{,}76$ °C/мин. По модулю $2{,}76 > 2$, остывает нормально.

Время работы алгоритма зависит от размера данных: $T(n) = 2n^2 + 5n$ (мс). Разработчику нужно найти скорость роста времени при $n = 10$ (производную). Если она больше $50$ мс/ед., сервер не справится.

Шаг 1. Производная. $T'(n) = 4n + 5$.

Шаг 2. Подставляем $n = 10$. $T'(10) = 40 + 5 = 45$ мс/ед.

Ответ: $45$ мс/ед. < $50$ мс/ед. Сервер справится.

Количество запросов к базе данных растёт по закону $Q(t) = 100t^2 - 20t^3$ (тыс. запросов в час), где $t$ — часы. Найдите момент времени, когда скорость роста запросов максимальна. Если она превышает $200$ тыс./ч², база данных перегружена.

Шаг 1. Скорость роста. $Q'(t) = 200t - 60t^2$.

Шаг 2. Ускорение (для нахождения максимума скорости). $Q''(t) = 200 - 120t = 0 \Rightarrow t \approx 1{,}67$ ч.

Шаг 3. Значение скорости. $Q'(1{,}67) = 333{,}3 - 166{,}7 = 166{,}6$ тыс./ч².

Ответ: Максимальная скорость $166{,}6$ тыс./ч² < $200$ тыс./ч². База данных в норме.

Стоимость хранения данных зависит от объёма: $C(v) = 0{,}01v^2 + 50v$ (руб.). Найдите объём, при котором стоимость хранения растёт с минимальной скоростью (производная минимальна). Если оптимальный объём меньше $100$ ГБ, система неэффективна.
