Декартовы координаты в пространстве

📖 Зачем нужны координаты в пространстве

Представь, что ты в незнакомом городе и хочешь объяснить другу, где находится кафе. Ты говоришь: «Иди прямо 200 метров, потом направо 100 метров, потом поднимись на 3 этаж». Три числа — три направления.

Это и есть координаты. Они описывают положение любой точки в пространстве через три числа: длину, ширину и высоту.

💡 Где это нужно:
• Навигация: GPS-координаты — широта, долгота, высота.
• Компьютерная графика: каждая точка 3D-модели — три координаты.
• Астрономия: положение звёзд и спутников.
• Физика: положение и скорость тела в пространстве.

Сейчас разберём, как устроена декартова система координат, как задавать точки, векторы и решать с ними задачи.

📚 Декартова система координат в пространстве

Определение. Прямоугольная (декартова) система координат в пространстве — это три взаимно перпендикулярные прямые, пересекающиеся в одной точке $O$, с заданными на каждой из них положительным направлением и единичным отрезком.

Элементы системы:

  • начало координат — точка $O$ пересечения осей;
  • три оси: $Ox$ — ось абсцисс, $Oy$ — ось ординат, $Oz$ — ось аппликат;
  • оси попарно перпендикулярны: $Ox \perp Oy$, $Oy \perp Oz$, $Oz \perp Ox$;
  • единичный отрезок — одинаковый для всех трёх осей;
  • единичные векторы (орты): $\vec{i}$ вдоль $Ox$, $\vec{j}$ вдоль $Oy$, $\vec{k}$ вдоль $Oz$, $|\vec{i}| = |\vec{j}| = |\vec{k}| = 1$.
Обозначение системы: $Oxyz$.

Координатные плоскости. Три оси задают три координатные плоскости:

  • $Oxy$ — плоскость, проходящая через оси $Ox$ и $Oy$ (на рисунке — голубая);
  • $Oyz$ — плоскость через оси $Oy$ и $Oz$ (сиреневая);
  • $Oxz$ — плоскость через оси $Ox$ и $Oz$ (бирюзовая).

Как задаётся точка. Каждой точке $A$ пространства соответствует единственная тройка чисел $A(x, y, z)$ — её координаты:

  • $x$ — абсцисса (проекция на ось $Ox$);
  • $y$ — ордината (проекция на ось $Oy$);
  • $z$ — аппликата (проекция на ось $Oz$).
Точки на осях:
$A(x, 0, 0)$ — лежит на оси $Ox$;
$B(0, y, 0)$ — на оси $Oy$;
$C(0, 0, z)$ — на оси $Oz$.
Точки на координатных плоскостях:
$M(x, y, 0)$ — в плоскости $Oxy$;
$N(0, y, z)$ — в плоскости $Oyz$;
$P(x, 0, z)$ — в плоскости $Oxz$.
📌 Примеры:
$A(2,0,0)$ — точка на оси абсцисс;
$B(0,-3,0)$ — точка на оси ординат (в отрицательном направлении);
$C(0,0,5)$ — точка на оси аппликат;
$M(2,3,0)$ — точка в плоскости $Oxy$;
$K(0,-1,4)$ — точка в плоскости $Oyz$;
$T(2,0,4)$ — точка в плоскости $Oxz$;
$A(2,3,5)$ — точка с положительными координатами.

Единичный отрезок. На каждой оси выбирается один и тот же единичный отрезок. Концы единичных отрезков, отложенных из $O$ в положительном направлении, — это точки $(1,0,0)$, $(0,1,0)$, $(0,0,1)$. Векторы $\overrightarrow{O(1,0,0)} = \vec i$, $\overrightarrow{O(0,1,0)} = \vec j$, $\overrightarrow{O(0,0,1)} = \vec k$ — единичные.

🧭 Координатные векторы и разложение по ним

Координатные векторы (орты): $\vec{i}\{1,0,0\}$, $\vec{j}\{0,1,0\}$, $\vec{k}\{0,0,1\}$.

Разложение:

$\vec{a} = x\vec{i} + y\vec{j} + z\vec{k}$

Разложение по трём некомпланарным векторам: любой вектор $\vec{a}$ можно единственным образом разложить по трём некомпланарным векторам $\vec{p}$, $\vec{q}$, $\vec{r}$:

$\vec{a} = \alpha\vec{p} + \beta\vec{q} + \gamma\vec{r}$

где $\alpha$, $\beta$, $\gamma$ — единственные числа (коэффициенты разложения).

📌 Пример:
$\vec{a}\{3, -2, 5\}$ ⇒ $\vec{a} = 3\vec{i} - 2\vec{j} + 5\vec{k}$
📐 Компланарные векторы

Компланарные векторы — лежат в одной плоскости или параллельных плоскостях.

  • Любые два вектора всегда компланарны.
  • Если $\vec{c} = \alpha\vec{a} + \beta\vec{b}$, то они компланарны.
📌 Пример: Проверим, являются ли векторы $\vec{r}\{1, 1, 0\}$, $\vec{p}\{1, 0, 0\}$ и $\vec{q}\{0, 1, 0\}$ компланарными.

Шаг 1. Проверяем, можно ли выразить $\vec{r}$ через $\vec{p}$ и $\vec{q}$:
$\vec{r} = \alpha\vec{p} + \beta\vec{q}$
$\{1, 1, 0\} = \alpha\{1, 0, 0\} + \beta\{0, 1, 0\}$

Шаг 2. Составляем систему уравнений по координатам:
По $x$: $1 = \alpha \cdot 1 + \beta \cdot 0 \;\Rightarrow\; \alpha = 1$
По $y$: $1 = \alpha \cdot 0 + \beta \cdot 1 \;\Rightarrow\; \beta = 1$
По $z$: $0 = \alpha \cdot 0 + \beta \cdot 0 \;\Rightarrow\; 0 = 0$ (верно)

Шаг 3. Нашли коэффициенты $\alpha = 1$, $\beta = 1$.
Подставляем: $\vec{r} = 1 \cdot \vec{p} + 1 \cdot \vec{q}$
$\{1, 1, 0\} = \{1, 0, 0\} + \{0, 1, 0\}$
Равенство верно.

Ответ: векторы компланарны, так как $\vec{r}$ выражается через $\vec{p}$ и $\vec{q}$.
📏 Длина вектора и расстояние
Модуль:

$|\vec{a}| = \sqrt{x^2 + y^2 + z^2}$
Расстояние:

$d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2 + (z_2-z_1)^2}$
📐 Пример: Найти расстояние между точками $A(1, 2, 3)$ и $B(4, 6, 8)$.

Шаг 1. Записываем формулу и подставляем координаты:
$d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2 + (z_2-z_1)^2}$
$x_2 - x_1 = 4 - 1 = 3$
$y_2 - y_1 = 6 - 2 = 4$
$z_2 - z_1 = 8 - 3 = 5$

Шаг 2. Вычисляем:
$d = \sqrt{3^2 + 4^2 + 5^2} = \sqrt{9 + 16 + 25} = \sqrt{50}$

Шаг 3. Упрощаем:
$d = \sqrt{50} = \sqrt{25 \cdot 2} = 5\sqrt{2}$

Ответ: $d = 5\sqrt{2}$
🧩 Решение задач (3D)

Задача 1. Даны точки $A(1,2,3)$ и $B(4,6,8)$. Постройте вектор $\overrightarrow{AB}$ и разложите его по ортам $\vec{i}$, $\vec{j}$, $\vec{k}$.

Решение:
$\overrightarrow{AB} = \{4-1,\; 6-2,\; 8-3\} = \{3,\; 4,\; 5\}$

Разложение по ортам:
$\overrightarrow{AB} = 3\vec{i} + 4\vec{j} + 5\vec{k}$

На векторах — метки через каждую единицу: на оранжевом отрезке видно 3 точки (3 уложенных орта $\vec i$), на фиолетовом — 4 точки, на бирюзовом — 5 точек.
🧩 Задача 2. Координаты вектора MN

Даны точки $M(-1,0,2)$ и $N(3,-4,1)$. Найдите координаты вектора $\overrightarrow{MN}$ и его длину.

Решение:
$\overrightarrow{MN} = \{3-(-1),\; -4-0,\; 1-2\} = \{4,\; -4,\; -1\}$

$|\overrightarrow{MN}| = \sqrt{4^2 + (-4)^2 + (-1)^2} = \sqrt{16+16+1} = \sqrt{33}$
🧩 Задача 3. Компланарность векторов

Проверьте, компланарны ли векторы $\vec{a}\{1,0,0\}$, $\vec{b}\{0,1,0\}$, $\vec{c}\{1,1,0\}$. Если да — запишите разложение $\vec{c}$ через $\vec{a}$ и $\vec{b}$.

Решение:
Ищем $\alpha$, $\beta$ такие, что $\vec{c} = \alpha\vec{a} + \beta\vec{b}$:
$\{1,1,0\} = \alpha\{1,0,0\} + \beta\{0,1,0\}$
По $x$: $\alpha = 1$;   по $y$: $\beta = 1$;   по $z$: $0=0$ — верно.

$\vec{c} = \vec{a} + \vec{b}$, значит векторы компланарны (лежат в плоскости $z=0$).
