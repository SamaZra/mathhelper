📐 Неопределённый интеграл

📖 Зачем нужен неопределённый интеграл

В теме «Первообразная» мы научились отменять дифференцирование: по функции $f(x)$ находить такую $F(x)$, что $F'(x) = f(x)$. Таких функций бесконечно много — они отличаются на константу $C$.

Возникает вопрос: как записать все эти первообразные одной формулой? Для этого вводят специальное обозначение — неопределённый интеграл:

$\displaystyle \int f(x)\,dx = F(x) + C$

Знак $\int$ — это «вытянутая S» (от латинского summa — «сумма»). Именно так интеграл и работает: он «суммирует» бесконечно много бесконечно маленьких частей.

💡 Главная идея: неопределённый интеграл — это все первообразные сразу, записанные как $F(x) + C$. Именно поэтому в ответе всегда стоит $+ C$ — без него теряется бесконечное множество функций.
📘 Определение

Неопределённый интеграл функции \(f(x)\) — это совокупность всех первообразных данной функции.

Обозначается \(\int f(x)\,dx = F(x) + C\), где \(F'(x) = f(x)\), а \(C\) — произвольная постоянная.

Символ \(\int\) (вытянутая буква S) ввёл Лейбниц, он происходит от латинского «summa».

⚙️ Свойства неопределённого интеграла
Свойство 1 · интеграл суммы/разности
\(\int (f(x) \pm g(x))dx = \int f(x)dx \pm \int g(x)dx\)

Пример. Найти интеграл: \(\int (x^2 + \sin x)\,dx\)

Шаг 1. Разбиваем интеграл суммы на сумму интегралов:

\(\int (x^2 + \sin x)\,dx = \int x^2\,dx + \int \sin x\,dx\)

✓ По свойству 1: интеграл от суммы равен сумме интегралов. Каждое слагаемое интегрируем отдельно.

Шаг 2. Применяем табличные формулы к каждому интегралу:

\(\int x^2\,dx = \frac{x^{3}}{3}\)   и   \(\int \sin x\,dx = -\cos x\)

✓ Используем формулы: \(\int x^n dx = \frac{x^{n+1}}{n+1}\) и \(\int \sin x\,dx = -\cos x\)

Шаг 3. Складываем результаты и добавляем одну общую константу \(C\):

\(= \frac{x^3}{3} - \cos x + C\)

✓ Константу \(C\) пишем один раз в конце, а не после каждого интеграла — это одна произвольная постоянная.

Ответ: \(\frac{x^3}{3} - \cos x + C\)

Свойство 2 · вынесение постоянного множителя
\(\int a\cdot f(x)dx = a\cdot \int f(x)dx\)

Пример. Найти интеграл: \(\int 5\cos x\,dx\)

Шаг 1. Выносим постоянный множитель 5 за знак интеграла:

\(\int 5\cos x\,dx = 5\int \cos x\,dx\)

✓ По свойству 2: постоянный множитель можно вынести за знак интеграла. Число 5 не зависит от \(x\), поэтому оно «не участвует» в интегрировании.

Шаг 2. Интегрируем оставшуюся функцию по таблице:

\(5\int \cos x\,dx = 5\cdot \sin x + C\)

✓ Используем формулу \(\int \cos x\,dx = \sin x\). Множитель 5 просто умножается на результат.

Ответ: \(5\sin x + C\)

Свойство 3 · линейная замена (интегрирование \(f(kx+b)\)
\(\int f(kx+b)dx = \frac{1}{k}F(kx+b) + C\)

Пример. Найти интеграл: \(\int \sin(5x)\,dx\)

Шаг 1. Определяем, что это интеграл от сложной функции вида \(f(kx+b)\):

Здесь \(f(\cdot) = \sin(\cdot)\) — внешняя функция, а внутренняя линейная функция: \(kx+b = 5x\). Значит, \(k = 5\), \(b = 0\).

✓ Сравниваем с табличным интегралом \(\int \sin x\,dx = -\cos x + C\). Но там аргумент просто \(x\), а у нас \(5x\).

Шаг 2. Вспоминаем формулу свойства 3:

\(\int f(kx+b)\,dx = \frac{1}{k}F(kx+b) + C\)

✓ Где \(F\) — первообразная для \(f\). То есть сначала берём табличную первообразную, но вместо \(x\) подставляем \(kx+b\), а потом делим на \(k\).

Шаг 3. Находим табличную первообразную для \(\sin\):

\(F(x) = -\cos x\)

✓ Это мы знаем из таблицы: \(\int \sin x\,dx = -\cos x + C\).

Шаг 4. Подставляем \(kx+b = 5x\) вместо \(x\) и делим на \(k=5\):

\(\int \sin(5x)\,dx = \frac{1}{5}\cdot\bigl(-\cos(5x)\bigr) + C = -\frac{\cos(5x)}{5} + C\)

✓ Сначала записываем \(-\cos(5x)\), затем умножаем на \(\frac{1}{k} = \frac{1}{5}\). Именно поэтому появляется деление на 5.

Шаг 5. Проверка (по желанию):

\(\left(-\frac{\cos(5x)}{5}\right)' = -\frac{1}{5}\cdot\bigl(-\sin(5x)\bigr)\cdot 5 = \sin(5x)\)

✓ Производная совпала с подынтегральной функцией — ответ верный.

Ответ: \(-\frac{\cos(5x)}{5} + C\)

Свойство 4 · интеграл от нуля
\(\int 0 \cdot dx = C\)

\(\int 0\,dx = C\) (константа)

Свойство 5 · интеграл от дифференциала
\(\int dx = x + C\)

\(\int 1\,dx = x + C\)

📌 Метод непосредственного интегрирования

Пример 1. Найти интеграл: \(\int (3x^2 + 2x + 1)dx\)

Шаг 1. Разбиваем на сумму интегралов:

\(\int (3x^2 + 2x + 1)dx = \int 3x^2 dx + \int 2x dx + \int 1 dx\)

✓ Используем свойство 1: интеграл суммы равен сумме интегралов

Шаг 2. Выносим константы за знак интеграла:

\(= 3\int x^2 dx + 2\int x dx + \int 1 dx\)

✓ Используем свойство 2: \(\int a\cdot f(x)dx = a\cdot \int f(x)dx\)

Шаг 3. Применяем табличные формулы:

\(= 3\cdot\frac{x^3}{3} + 2\cdot\frac{x^2}{2} + x + C\)

✓ \(\int x^n dx = \frac{x^{n+1}}{n+1}\), \(\int 1 dx = x\)

Шаг 4. Упрощаем:

\(= x^3 + x^2 + x + C\)

Ответ: \(x^3 + x^2 + x + C\)

Пример 2. Найти интеграл: \(\int \frac{x^4 + 2x^3 - x}{x}dx\)

Шаг 1. Упрощаем подынтегральное выражение:

\(\int \frac{x^4 + 2x^3 - x}{x}dx = \int \left(\frac{x^4}{x} + \frac{2x^3}{x} - \frac{x}{x}\right)dx\)

✓ Почленно делим числитель на знаменатель

Шаг 2. Сокращаем дроби:

\(= \int (x^3 + 2x^2 - 1)dx\)

✓ \(\frac{x^4}{x}=x^3\), \(\frac{2x^3}{x}=2x^2\), \(\frac{x}{x}=1\)

Шаг 3. Интегрируем почленно:

\(= \int x^3 dx + 2\int x^2 dx - \int 1 dx\)

✓ Разбиваем на сумму интегралов и выносим константу 2

Шаг 4. Применяем табличные формулы:

\(= \frac{x^4}{4} + 2\cdot\frac{x^3}{3} - x + C\)

✓ \(\int x^3 dx = \frac{x^4}{4}\), \(\int x^2 dx = \frac{x^3}{3}\), \(\int 1 dx = x\)

Ответ: \(\frac{x^4}{4} + \frac{2x^3}{3} - x + C\)

Пример 3. Найти интеграл: \(\int 3x^2(2x - 4)dx\)

Шаг 1. Раскрываем скобки:

\(\int 3x^2(2x - 4)dx = \int (6x^3 - 12x^2)dx\)

✓ Умножаем: \(3x^2\cdot 2x = 6x^3\), \(3x^2\cdot(-4) = -12x^2\)

Шаг 2. Интегрируем почленно:

\(= 6\int x^3 dx - 12\int x^2 dx\)

✓ Выносим константы за знак интеграла

Шаг 3. Применяем табличные формулы:

\(= 6\cdot\frac{x^4}{4} - 12\cdot\frac{x^3}{3} + C\)

✓ \(\int x^3 dx = \frac{x^4}{4}\), \(\int x^2 dx = \frac{x^3}{3}\)

Шаг 4. Упрощаем:

\(= \frac{6x^4}{4} - 4x^3 + C = \frac{3x^4}{2} - 4x^3 + C\)

✓ Сокращаем: \(\frac{6}{4}=\frac{3}{2}\), \(\frac{12}{3}=4\)

Ответ: \(\frac{3x^4}{2} - 4x^3 + C\)

✍️ Примеры для самостоятельного решения
📝 Попробуйте решить каждый пример самостоятельно. Если возникнут трудности — откройте подсказку. Сверьте свой ответ с ответом. Помните: в конце всегда должна стоять константа \(C\)!
🔥 В примерах 6–10 встречаются сложные функции вида \(f(kx+b)\) — применяйте свойство 3: \(\int f(kx+b)\,dx = \frac{1}{k}F(kx+b) + C\).

Пример 1. Найти интеграл: \(\int (4x^3 - 2x + 7)\,dx\)

💡 Подсказка

Разбейте интеграл на сумму трёх интегралов по свойству 1. Затем вынесите постоянные множители 4 и 2 за знак интеграла (свойство 2). Примените формулу \(\int x^n dx = \frac{x^{n+1}}{n+1}\) и \(\int 1\,dx = x\).

✅ Ответ

\(x^4 - x^2 + 7x + C\)

Пример 2. Найти интеграл: \(\int (6x^2 + 4\cos x)\,dx\)

💡 Подсказка

Разбейте на два интеграла. Константы 6 и 4 вынесите за знак интеграла. Используйте табличные формулы \(\int x^2 dx = \frac{x^3}{3}\) и \(\int \cos x\,dx = \sin x\).

✅ Ответ

\(2x^3 + 4\sin x + C\)

Пример 3. Найти интеграл: \(\int \frac{x^3 - 4x^2 + 2x}{x}\,dx\)

💡 Подсказка

Сначала почленно разделите числитель на знаменатель: \(\frac{x^3}{x} = x^2\), \(\frac{4x^2}{x} = 4x\), \(\frac{2x}{x} = 2\). Затем интегрируйте получившийся многочлен почленно.

✅ Ответ

\(\frac{x^3}{3} - 2x^2 + 2x + C\)

Пример 4. Найти интеграл: \(\int 2x(x^2 + 3)\,dx\)

💡 Подсказка

Сначала раскройте скобки: \(2x \cdot x^2 = 2x^3\), \(2x \cdot 3 = 6x\). Затем интегрируйте почленно, вынося константы за знак интеграла.

✅ Ответ

\(\frac{x^4}{2} + 3x^2 + C\)

Пример 5. Найти интеграл: \(\int (5\sin x - 3e^x)\,dx\)

💡 Подсказка

Разбейте на два интеграла и вынесите константы. Используйте табличные формулы \(\int \sin x\,dx = -\cos x\) и \(\int e^x dx = e^x\). Следите за знаком минус!

✅ Ответ

\(-5\cos x - 3e^x + C\)

Пример 6. Найти интеграл: \(\int \cos(3x)\,dx\)

💡 Подсказка

Это сложная функция вида \(f(kx+b)\), где \(f(\cdot) = \cos(\cdot)\), \(k = 3\), \(b = 0\). Примените свойство 3: \(\int f(kx+b)\,dx = \frac{1}{k}F(kx+b) + C\). Табличная первообразная: \(\int \cos x\,dx = \sin x\). Не забудьте разделить на \(k = 3\).

✅ Ответ

\(\frac{\sin(3x)}{3} + C\)

Пример 7. Найти интеграл: \(\int e^{4x+1}\,dx\)

💡 Подсказка

Это сложная функция вида \(f(kx+b)\), где \(f(\cdot) = e^{(\cdot)}\), \(k = 4\), \(b = 1\). Примените свойство 3: \(\int f(kx+b)\,dx = \frac{1}{k}F(kx+b) + C\). Табличная первообразная: \(\int e^x dx = e^x\). Разделите на \(k = 4\).

✅ Ответ

\(\frac{e^{4x+1}}{4} + C\)

Пример 8. Найти интеграл: \(\int \frac{dx}{5x-2}\)

💡 Подсказка

Это сложная функция вида \(f(kx+b)\), где \(f(\cdot) = \frac{1}{\cdot}\), \(k = 5\), \(b = -2\). Примените свойство 3: \(\int f(kx+b)\,dx = \frac{1}{k}F(kx+b) + C\). Табличная первообразная: \(\int \frac{1}{x}dx = \ln|x|\). Разделите на \(k = 5\) и не забудьте модуль.

✅ Ответ

\(\frac{1}{5}\ln|5x-2| + C\)

Пример 9. Найти интеграл: \(\int (2x+3)^5\,dx\)

💡 Подсказка

Это сложная функция вида \(f(kx+b)\), где \(f(\cdot) = (\cdot)^5\), \(k = 2\), \(b = 3\). Примените свойство 3 (или табличную формулу для \((kx+b)^n\)): \(\int (kx+b)^n dx = \frac{(kx+b)^{n+1}}{k(n+1)} + C\). Здесь \(n = 5\), \(k = 2\).

✅ Ответ

\(\frac{(2x+3)^6}{12} + C\)

Пример 10. Найти интеграл: \(\int \bigl(3x^2 + \sin(2x) - e^{-x}\bigr)\,dx\)

💡 Подсказка

Разбейте на три интеграла по свойству 1: \(\int 3x^2\,dx + \int \sin(2x)\,dx - \int e^{-x}\,dx\).
• Первый — табличный: \(\int x^2 dx = \frac{x^3}{3}\), вынесите 3.
• Второй — сложная функция с \(k = 2\): \(\int \sin(2x)\,dx = -\frac{\cos(2x)}{2}\).
• Третий — сложная функция с \(k = -1\): \(\int e^{-x}\,dx = \frac{e^{-x}}{-1} = -e^{-x}\).
Будьте внимательны со знаками!

✅ Ответ

\(x^3 - \frac{\cos(2x)}{2} + e^{-x} + C\)

⚠️ Частые ошибки

❌ Забывают прибавить константу \(C\) — неопределённый интеграл = семейство функций, а не одна функция.

❌ Неправильно делят на коэффициент \(k\) — при интегрировании \(f(kx+b)\) всегда делим на \(k\): \(\int \sin(3x)dx = -\frac{\cos(3x)}{3} + C\).

❌ Путают знаки в тригонометрических интегралах — \(\int \sin x = -\cos x\), а \(\int \cos x = \sin x\).

✅ Проверяйте себя производной: \((F(x) + C)'\) должно равняться подынтегральной функции \(f(x)\).
