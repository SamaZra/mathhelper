Функция $y = \cos x$, её свойства и график

📖 От единичной окружности — к графику косинуса

До этого мы работали с углами и треугольниками. Но в математике есть мощный инструмент — функции. Давайте посмотрим, как косинус превращается из геометрического отрезка в полноценную функцию.

Представьте себе единичную окружность (радиус 1). Если мы будем крутить точку $M$ по этой окружности, то её абсцисса (координата $x$) будет постоянно меняться. Функция $y = \cos x$ — это машина, которая берёт угол поворота $x$ и выдаёт координату $x$ точки $M$.

  • Вход функции: угол поворота $x$ (в радианах).
  • Выход функции: абсцисса точки $M$, то есть $\cos x$.
💡 Как круг связан с графиком: Круг показывает, почему косинус меняется. А график показывает, как он меняется. Если мы «развернём» движение точки по окружности на горизонтальную ось, мы получим волнообразную кривую — косинусоиду.

Подвигайте ползунок угла $\alpha$ — точка на окружности и соответствующая точка на графике двигаются синхронно. Видно, как проекция точки на ось $OX$ превращается в координату $y$ графика.

Единичная окружность: точка $M(\cos\alpha; \sin\alpha)$
Косинусоида: $y = \cos x$ — «развёртка» окружности
α = 0,80 рад

Зачем это нужно? Косинус описывает всё, что колеблется: маятник, переменный ток, звуковую волну, приливы. Везде, где есть периодический процесс, появляется косинусоида. А ещё косинус — это связующее звено между геометрией (углы, стороны треугольников) и алгеброй (функции, графики, уравнения).

Нажимайте на свойства — на графике ниже подсветится соответствующий участок.

  • 1. Область определения
    $D(y) = \mathbb{R} = (-\infty; +\infty)$ — косинус определён для любого угла.
  • 2. Область значений
    $E(y) = [-1; 1]$ — значения косинуса всегда лежат в этом отрезке.
  • 3. Чётность
    $\cos(-x) = \cos x$ — функция чётная. График симметричен относительно оси $OY$.
  • 4. Период
    $T = 2\pi$, то есть $\cos(x + 2\pi) = \cos x$. График повторяется каждые $2\pi$.
  • 5. Нули функции
    $\cos x = 0$ при $x = \dfrac{\pi}{2} + \pi n$, $n \in \mathbb{Z}$.
  • 6. Промежутки знакопостоянства
    $\cos x > 0$ при $x \in \left(-\dfrac{\pi}{2} + 2\pi n; \dfrac{\pi}{2} + 2\pi n\right)$;
    $\cos x < 0$ при $x \in \left(\dfrac{\pi}{2} + 2\pi n; \dfrac{3\pi}{2} + 2\pi n\right)$, $n \in \mathbb{Z}$.
  • 7. Монотонность
    Возрастает на $\left[-\pi + 2\pi n; 2\pi n\right]$;
    убывает на $\left[2\pi n; \pi + 2\pi n\right]$, $n \in \mathbb{Z}$.
  • 8. Экстремумы (изучается позже)
    Максимум $\cos x = 1$ при $x = 2\pi n$; минимум $\cos x = -1$ при $x = \pi + 2\pi n$.
📈 График $y = \cos x$ косинусоида

График функции $y = \cos x$ называется косинусоидой. Это та же синусоида, но сдвинутая влево на $\dfrac{\pi}{2}$: $\cos x = \sin\left(x + \dfrac{\pi}{2}\right)$.

$y = \cos x$ — основной график (можно прокручивать)
📌 Как читать график:
• В точке $x = 0$ значение максимально: $\cos 0 = 1$.
• При $x = \dfrac{\pi}{2}$ график пересекает ось $OX$: $\cos\dfrac{\pi}{2} = 0$.
• При $x = \pi$ минимум: $\cos\pi = -1$.
• Дальше всё повторяется каждые $2\pi$.
🔧 Преобразования графика введите коэффициенты в формулу

Из базового графика $y = \cos x$ можно получить множество других, меняя коэффициенты в формуле:

Общий вид: y = A · cos( kx + φ ) + B

φ (радианы) можно вводить так: 0.5, -1.2, pi/2, π/3, 2*pi
A — Амплитуда (y = A·cos(...))
Растягивает или сжимает график по вертикали (по оси OY).
Если A > 1 — растяжение (график выше).
Если 0 < A < 1 — сжатие.
Если A < 0 — график переворачивается (отражение от оси OX).
k — Частота (y = cos(k·x ...))
Сжимает или растягивает график по горизонтали (по оси OX).
Если k > 1 — сжатие (график "чаще").
Если 0 < k < 1 — растяжение ("реже").
Период новой функции: T = 2π / |k|.
φ — Сдвиг по фазе (y = cos(x + φ))
Двигает график влево или вправо по оси OX.
Если φ > 0 — сдвиг влево (опережение).
Если φ < 0 — сдвиг вправо (запаздывание).
B — Вертикальный сдвиг (y = ... + B)
Двигает весь график вверх или вниз по оси OY.
Если B > 0 — сдвиг вверх.
Если B < 0 — сдвиг вниз.
Область значений становится [B - |A|; B + |A|].

📌 Пример: как из $y = \cos x$ получить $y = 2\cos(x - \pi/6)$?

Шаг 1. Сдвигаем график $y = \cos x$ вправо на $\pi/6$.
Шаг 2. Растягиваем по $OY$ в 2 раза (амплитуда становится 2).
Результат: $y = 2\cos(x - \pi/6)$.
📝 Примеры применения
Пример 1 (вычисление). Найти $\cos\dfrac{2\pi}{3}$.

Шаг 1. Приводим к острому углу. $\dfrac{2\pi}{3} = \pi - \dfrac{\pi}{3}$, вторая четверть.
Шаг 2. Формула приведения. $\cos\left(\pi - \dfrac{\pi}{3}\right) = -\cos\dfrac{\pi}{3}$.
Шаг 3. Табличное значение. $-\cos\dfrac{\pi}{3} = -\dfrac{1}{2}$.
Ответ: $-\dfrac{1}{2}$.
Пример 2 (уравнение). Решить $\cos x = \dfrac{1}{2}$.

Шаг 1. Общая формула. $x = \pm\arccos\dfrac{1}{2} + 2\pi n = \pm\dfrac{\pi}{3} + 2\pi n$.
Ответ: $x = \pm\dfrac{\pi}{3} + 2\pi n$, $n \in \mathbb{Z}$.
Пример 3 (чётность). Вычислить $\cos(-60°)$.

Решение. $\cos(-60°) = \cos 60° = \dfrac{1}{2}$.
Ответ: $\dfrac{1}{2}$.
🧮 Решение задач по материалам презентации
Задача №1. Найти пределы изменения функции $y = \cos t$ на отрезке $\left[\dfrac{\pi}{6}; \dfrac{\pi}{2}\right]$.

Решение. Функция монотонно убывает на указанном промежутке, значит, наибольшее значение принимает на левом конце отрезка $y\left(\dfrac{\pi}{6}\right) = \dfrac{\sqrt{3}}{2}$, а наименьшее — на правом конце $y\left(\dfrac{\pi}{2}\right) = 0$.
Ответ: $\max = \dfrac{\sqrt{3}}{2}$, $\min = 0$.
Задача №2. Найти наибольшее и наименьшее значение функции $y = \cos t$ на отрезке $\left[\dfrac{\pi}{3}; \dfrac{7\pi}{6}\right]$.

Решение. На данном промежутке функция немонотонна. Наибольшее значение — на левом конце $y\left(\dfrac{\pi}{3}\right) = \dfrac{1}{2}$, наименьшее — в точке минимума $y(\pi) = -1$.
Ответ: $\max = \dfrac{1}{2}$, $\min = -1$.
Задача №3. Решить уравнение $\cos x = x^2 + 1$.

Решение. Построим в одних координатных осях графики функций $y = \cos x$ и $y = x^2 + 1$. Графики имеют только одну общую точку $A(0; 1)$.
Ответ: $x = 0$.
Задача №4. Найти число корней уравнения $x^2 = \cos x$.

Решение. На промежутке $[-\pi; 0]$ функция $y = \cos x$ монотонно возрастает, функция $y = x^2$ монотонно убывает — значит, на этом промежутке графики имеют только одну общую точку. На промежутке $[0; \pi]$ функция $y = \cos x$ монотонно убывает, функция $y = x^2$ монотонно возрастает — значит, и на этом промежутке графики имеют только одну общую точку.
Ответ: два корня.
Задача №5. Построить график функции $y = \cos 3x$.

Решение. Косинус — чётная функция, строим график на участке $\left[0; \dfrac{\pi}{3}\right]$, затем симметрично отображаем относительно оси $y$ и получаем график на промежутке $\left[-\dfrac{\pi}{3}; \dfrac{\pi}{3}\right]$, длина которого равна периоду. График сжимается к оси $Oy$ в 3 раза.
Результат: косинусоида с периодом $T = \dfrac{2\pi}{3}$.
✏️ Задания для самостоятельного решения проверьте себя
1. Постройте графики функций:
1) $y = \cos x + 1$;
2) $y = \cos x - 1$;
3) $y = \cos\left(x + \dfrac{\pi}{2}\right)$;
4) $y = \cos\left(x - \dfrac{\pi}{3}\right)$.
2. Найти наибольшее и наименьшее значение функции $y = \cos x$ на отрезке $\left[0; \dfrac{4\pi}{3}\right]$.
Подсказка: проверьте значения на концах и в точке минимума $x = \pi$.
3. Определить область значений функции $y = -8\cos x + 3$.
Подсказка: $-1 \le \cos x \le 1$, значит $-8 \le -8\cos x \le 8$.
4. Определить чётность или нечётность функции $f(x) = x^5 \cdot \cos 6x$.
Подсказка: $f(-x) = (-x)^5 \cos(-6x) = -x^5 \cos 6x = -f(x)$.
5. Определить, возрастает или убывает функция $y = \cos x$ на отрезке $[-4\pi; -3\pi]$.
Подсказка: $-4\pi$ и $-3\pi$ — это те же точки, что $0$ и $\pi$ после сдвига на $4\pi$.
6. Найти наибольшее и наименьшее значения функции $y = \cos^4 2x - \sin^4 2x + 4$.
Подсказка: $\cos^4 a - \sin^4 a = \cos^2 a - \sin^2 a = \cos 2a$, значит $y = \cos 4x + 4$.
7. Определить наименьшее и наибольшее значения функции $y = \cos x$ на полуинтервале $\left(-\dfrac{4\pi}{3}; -\dfrac{\pi}{3}\right]$.
Подсказка: проверьте поведение на концах и в точке максимума $x = -\pi$.
⚠️ На что обратить внимание
  • Косинус чётный, синус — нет. $\cos(-x) = \cos x$, а $\sin(-x) = -\sin x$.
  • Область значений — $[-1; 1]$. Не бывает $\cos x = 2$.
  • В точке $0$ максимум. $\cos 0 = 1$, а не $0$.
  • Период $2\pi$, а не $\pi$.
