Простейшие задачи в координатах

📖 Зачем эти задачи нужны

У нас уже есть векторы и координаты. Что теперь? Пора научиться решать конкретные задачи, которые встречаются в реальной жизни.

Например:

  • Где находится середина отрезка между двумя городами?
  • Как найти расстояние между двумя точками, если известны их координаты?
  • Где находится центр масс треугольника (важно в механике и строительстве)?
  • Как разделить отрезок в заданном отношении (например, 2:1)?
💡 Все эти задачи решаются по простым формулам — и все они сводятся к одной идее: работа с координатами. Сейчас разберём каждую и покажем на 3D-моделях.
Задача 1. Координаты середины отрезка (база)
Если $A(x_1, y_1, z_1)$ и $B(x_2, y_2, z_2)$, то середина $M$ отрезка $AB$:

$$M\left( \frac{x_1 + x_2}{2},\; \frac{y_1 + y_2}{2},\; \frac{z_1 + z_2}{2} \right)$$

Обратная задача: если известны координаты середины $M$ и одного из концов отрезка, то координаты другого конца находятся по формулам:

$x_2 = 2x_M - x_1$
$y_2 = 2y_M - y_1$
$z_2 = 2z_M - z_1$

Пример: Даны точки $A(3, -2, 5)$ и $B(7, 4, -3)$. Найти координаты середины отрезка $AB$.

$x_M = \dfrac{3+7}{2}=5$
$y_M = \dfrac{-2+4}{2}=1$
$z_M = \dfrac{5+(-3)}{2}=1$

Ответ: $M(5,1,1)$
Задача 2. Длина вектора по его координатам (база)
Для вектора $\vec{a}\{x, y, z\}$:

$|\vec{a}| = \sqrt{x^2 + y^2 + z^2}$

Пример: Дан вектор $\vec{a}\{3, -4, 12\}$. Найти его длину.

$|\vec{a}| = \sqrt{3^2+(-4)^2+12^2}=$
$= \sqrt{9+16+144}= \sqrt{169}=13$

Для вектора $\overrightarrow{AB}$:
$\overrightarrow{AB} = \{x_2-x_1,\; y_2-y_1,\; z_2-z_1\}$
$|\overrightarrow{AB}| = \sqrt{(x_2-x_1)^2+(y_2-y_1)^2+(z_2-z_1)^2}$

Задача 3. Расстояние между двумя точками (база)
$d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2 + (z_2-z_1)^2}$

Пример: Найти расстояние между $A(1,2,3)$ и $B(4,6,8)$.

$d = \sqrt{(4-1)^2+(6-2)^2+(8-3)^2}=$
$= \sqrt{3^2+4^2+5^2}= \sqrt{50}=5\sqrt{2}$

Ещё пример: $P(2,-1,3)$, $Q(5,2,-1)$:

$d = \sqrt{(5-2)^2+(2-(-1))^2+(-1-3)^2}=$
$= \sqrt{3^2+3^2+(-4)^2}= \sqrt{34}$
Задача 4. Деление отрезка в заданном отношении ★

Если точка $M$ делит отрезок $AB$ в отношении $\lambda = \dfrac{AM}{MB}$, то:

$M\left( \dfrac{x_1 + \lambda x_2}{1 + \lambda},\; \dfrac{y_1 + \lambda y_2}{1 + \lambda},\; \dfrac{z_1 + \lambda z_2}{1 + \lambda} \right)$

При $\lambda = 1$ точка $M$ — середина отрезка.

Пример: Даны точки $A(1,2,3)$ и $B(7,8,9)$. Найти точку $M$, которая делит отрезок $AB$ в отношении $2:1$ ($\lambda = 2$).

$x_M = \dfrac{1 + 2 \cdot 7}{1 + 2} = \dfrac{15}{3} = 5$
$y_M = \dfrac{2 + 2 \cdot 8}{1 + 2} = \dfrac{18}{3} = 6$
$z_M = \dfrac{3 + 2 \cdot 9}{1 + 2} = \dfrac{21}{3} = 7$

Ответ: $M(5,6,7)$
Задача 5. Центр масс треугольника ★

Координаты центра масс (точки пересечения медиан) треугольника с вершинами $A(x_1,y_1,z_1)$, $B(x_2,y_2,z_2)$, $C(x_3,y_3,z_3)$:

$G\left( \dfrac{x_1+x_2+x_3}{3},\; \dfrac{y_1+y_2+y_3}{3},\; \dfrac{z_1+z_2+z_3}{3} \right)$

Пример: Дан треугольник с вершинами $A(1,2,3)$, $B(4,5,6)$, $C(7,8,9)$. Найти центр масс.

$x_G = \dfrac{1+4+7}{3} = 4$
$y_G = \dfrac{2+5+8}{3} = 5$
$z_G = \dfrac{3+6+9}{3} = 6$

Ответ: $G(4,5,6)$
Задачи посложнее (3D)

Задача 6. Точка $M$ — середина отрезка $AB$, где $A(2,-1,4)$ и $B(6,3,0)$. Найдите координаты середины $M$. Затем найдите точку $C$, симметричную $A$ относительно $M$.

Решение:
$x_M = \dfrac{2+6}{2} = 4$;   $y_M = \dfrac{-1+3}{2} = 1$;   $z_M = \dfrac{4+0}{2} = 2$ ⇒ $M(4,1,2)$.

Симметричная точка $C$: $M$ — середина $AC$, значит
$x_C = 2x_M - x_A = 8 - 2 = 6$;
$y_C = 2y_M - y_A = 2 - (-1) = 3$;
$z_C = 2z_M - z_A = 4 - 4 = 0$ ⇒ $C(6,3,0)$.

Заметим: $C$ совпала с $B$ — потому что $A$, $M$, $B$ лежат на одной прямой, и $M$ — середина $AB$.

Задача 7. Точка $C$ делит отрезок $AB$ в отношении $AC:CB = 1:3$, где $A(0,0,0)$, $B(8,4,12)$. Найдите координаты точки $C$.

Напоминание формулы. Если точка $M$ делит отрезок $AB$ в отношении $\lambda = \dfrac{AM}{MB}$, то её координаты: $$M\left( \dfrac{x_1 + \lambda x_2}{1 + \lambda},\; \dfrac{y_1 + \lambda y_2}{1 + \lambda},\; \dfrac{z_1 + \lambda z_2}{1 + \lambda} \right)$$
Решение.
Дано $AC:CB = 1:3$, значит $\lambda = \dfrac{AC}{CB} = \dfrac{1}{3}$.
Координаты $A(0,0,0)$, $B(8,4,12)$.

$x_C = \dfrac{0 + \frac13 \cdot 8}{1 + \frac13} = \dfrac{8/3}{4/3} = 2$
$y_C = \dfrac{0 + \frac13 \cdot 4}{1 + \frac13} = \dfrac{4/3}{4/3} = 1$
$z_C = \dfrac{0 + \frac13 \cdot 12}{1 + \frac13} = \dfrac{12/3}{4/3} = 3$

Ответ: $C(2,1,3)$.
Проверка. Найдём векторы $\overrightarrow{AC}$ и $\overrightarrow{CB}$:
$\overrightarrow{AC} = C - A = \{2-0,\; 1-0,\; 3-0\} = \{2,1,3\}$
$\overrightarrow{CB} = B - C = \{8-2,\; 4-1,\; 12-3\} = \{6,3,9\}$

Замечаем: $\overrightarrow{CB} = 3 \cdot \overrightarrow{AC}$:
$3 \cdot \{2,1,3\} = \{6,3,9\}$ ✓

Значит, отношение длин $AC : CB = 1 : 3$ выполнено.

Задача 8. Дан треугольник $A(1,1,1)$, $B(4,4,1)$, $C(1,4,5)$. Найдите длину медианы $AM$, где $M$ — середина $BC$.

Решение:
Середина $BC$:
$x_M = \dfrac{4+1}{2} = 2{,}5$;   $y_M = \dfrac{4+4}{2} = 4$;   $z_M = \dfrac{1+5}{2} = 3$ ⇒ $M(2{,}5;\,4;\,3)$.

Длина медианы $AM$:
$AM = \sqrt{(2{,}5-1)^2 + (4-1)^2 + (3-1)^2}$
$= \sqrt{1{,}5^2 + 3^2 + 2^2} = \sqrt{2{,}25 + 9 + 4} = \sqrt{15{,}25}$

Ответ: $AM = \sqrt{15{,}25} = \dfrac{\sqrt{61}}{2}$.

Задача 9. Даны точки $A(1,2,3)$, $B(2,4,1)$, $C(3,6,-1)$. Лежат ли они на одной прямой?

Идея. Три точки $A$, $B$, $C$ лежат на одной прямой тогда и только тогда, когда векторы $\overrightarrow{AB}$ и $\overrightarrow{AC}$ коллинеарны, то есть один получается из другого умножением на число:

$\overrightarrow{AC} = k \cdot \overrightarrow{AB}$   для некоторого $k$.
Решение.
Найдём координаты векторов:

$\overrightarrow{AB} = B - A = \{2-1,\; 4-2,\; 1-3\} = \{1,\; 2,\; -2\}$
$\overrightarrow{AC} = C - A = \{3-1,\; 6-2,\; -1-3\} = \{2,\; 4,\; -4\}$

Проверим пропорциональность координат:
$\dfrac{2}{1} = 2$;   $\dfrac{4}{2} = 2$;   $\dfrac{-4}{-2} = 2$ — все три отношения равны $2$.

Значит, $\overrightarrow{AC} = 2 \cdot \overrightarrow{AB}$.

Ответ: да, точки $A$, $B$, $C$ лежат на одной прямой. Более того, $B$ — середина отрезка $AC$, потому что $\overrightarrow{AC} = 2\overrightarrow{AB}$ (то есть $AB = BC$).
Дополнительно: как проверять коллинеарность.
Если $\overrightarrow{AB}\{p_1, p_2, p_3\}$ и $\overrightarrow{AC}\{q_1, q_2, q_3\}$, то условие коллинеарности: $$\dfrac{q_1}{p_1} = \dfrac{q_2}{p_2} = \dfrac{q_3}{p_3}$$ (при условии, что ни одна из координат $p_i \neq 0$).

Задача 10. Даны точки $A(1,0,2)$, $B(3,2,-1)$, $C(0,-1,3)$, $D(2,1,0)$. Докажите, что четырёхугольник $ABCD$ — параллелограмм.

Идея (признак параллелограмма). Четырёхугольник является параллелограммом тогда и только тогда, когда две противоположные стороны равны и параллельны.

В координатах это означает: $\overrightarrow{AB} = \overrightarrow{DC}$.
Решение.
Найдём векторы сторон $AB$ и $DC$:

$\overrightarrow{AB} = B - A = \{3-1,\; 2-0,\; -1-2\} = \{2,\; 2,\; -3\}$
$\overrightarrow{DC} = C - D = \{0-2,\; -1-1,\; 3-0\} = \{-2,\; -2,\; 3\}$

Сравниваем: $\overrightarrow{DC} = \{-2,-2,3\} = -\overrightarrow{AB}$.
Значит, $\overrightarrow{AB} = -\overrightarrow{DC} = \overrightarrow{CD}$.

Вывод: $\overrightarrow{AB} = \overrightarrow{CD}$, то есть стороны $AB$ и $CD$ равны и параллельны.

По признаку параллелограмма (если в четырёхугольнике две противоположные стороны равны и параллельны, то это параллелограмм):

Ответ: $ABCD$ — параллелограмм.
Альтернативный способ (через середины диагоналей).
В параллелограмме диагонали точкой пересечения делятся пополам, то есть середины диагоналей $AC$ и $BD$ совпадают.

Середина $AC$:
$\left(\dfrac{1+0}{2},\; \dfrac{0+(-1)}{2},\; \dfrac{2+3}{2}\right) = \left(0{,}5;\; -0{,}5;\; 2{,}5\right)$

Середина $BD$:
$\left(\dfrac{3+2}{2},\; \dfrac{2+1}{2},\; \dfrac{-1+0}{2}\right) = \left(2{,}5;\; 1{,}5;\; -0{,}5\right)$

Середины не совпали — этот способ к данному набору точек не подходит, потому что порядок вершин $ABCD$ не означает, что $AC$ и $BD$ — диагонали. Здесь работает проверка через $\overrightarrow{AB} = \overrightarrow{DC}$ (см. выше).
Шпаргалка:

Середина: $M\left(\dfrac{x_1+x_2}{2},\dfrac{y_1+y_2}{2},\dfrac{z_1+z_2}{2}\right)$
Расстояние: $d = \sqrt{(x_2-x_1)^2+(y_2-y_1)^2+(z_2-z_1)^2}$
Деление в отношении $\lambda$: $M\left(\dfrac{x_1+\lambda x_2}{1+\lambda},\dfrac{y_1+\lambda y_2}{1+\lambda},\dfrac{z_1+\lambda z_2}{1+\lambda}\right)$
Центр масс: $G\left(\dfrac{x_1+x_2+x_3}{3},\dfrac{y_1+y_2+y_3}{3},\dfrac{z_1+z_2+z_3}{3}\right)$
