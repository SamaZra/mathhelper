🔒 Использование ограниченности

📖 Что такое ограниченность?

Ограниченность — это свойство функции не выходить за определённые границы. Например, \(\sin x\) всегда между \(-1\) и \(1\), а \(x^2\) всегда \(\ge 0\).

🎯 Главная идея: Если одна функция не больше \(M\), а другая не меньше \(M\), то равенство возможно только в точке, где обе равны \(M\).
📋 Основные ограничения
📌 Таблица ограниченных функций
  • \(\sin x \in [-1; 1]\), \(\cos x \in [-1; 1]\)
  • \(x^2 \ge 0\), \(|x| \ge 0\), \(\sqrt{x} \ge 0\)
  • \(a^x > 0\) (при \(a > 0\))
  • \(\log_a x\) — может быть любым, но аргумент \(> 0\)
  • \(\frac{1}{x^2+1} \in (0; 1]\)
  • \(-x^2 \le 0\)
    • 📐 Пример 1. \(\sin x = x^2\) ограниченность синуса
    🔹 Шаг 1. Оцениваем каждую часть
    \(\sin x \le 1\) — синус не больше 1
    \(x^2 \ge 0\) — квадрат не меньше 0
    🔹 Шаг 2. Ищем возможные точки равенства
    💡 Так как \(\sin x \le 1\), а \(x^2 \ge 0\), равенство возможно только если \(x^2 \le 1\) (иначе \(x^2 > 1 \ge \sin x\)).
    Значит, \(x \in [-1; 1]\).
    🔹 Шаг 3. Проверяем
    \(x = 0\): \(\sin 0 = 0\), \(0^2 = 0\) → подходит
    \(x = \pm 1\): \(\sin 1 \approx 0.84\), \(1\) → не подходит
    💡 Других корней нет, так как при \(x \in (0; 1]\): \(\sin x < x^2\) (можно доказать или проверить графически).
    ✅ Ответ: \(x = 0\)
    💡 Ограниченность синуса сразу сузила поиск до отрезка \([-1; 1]\)!
    📐 Пример 2. \(\cos x = x^2\) классический пример
    🔹 Шаг 1. Оцениваем каждую часть
    \(\cos x \le 1\) — косинус не больше 1
    \(x^2 \ge 0\) — квадрат не меньше 0
    🔹 Шаг 2. Ищем возможные точки равенства
    💡 Так как \(\cos x \le 1\), а \(x^2 \ge 0\), нужно \(x^2 \le 1\) → \(x \in [-1; 1]\).
    🔹 Шаг 3. Проверяем
    \(x = 0\): \(\cos 0 = 1\), \(0\) → не подходит
    \(x = \pm 0.824\): \(\cos(0.824) \approx 0.679\), \(0.824^2 = 0.679\) → подходит
    ✅ Ответ: \(x \approx \pm 0.824\)
    💡 Ограниченность помогла найти корни, не решая сложное уравнение!
    📐 Пример 3. \(\sin x + \cos x > 1\) неравенство с ограниченными функциями
    🔹 Шаг 1. Преобразуем
    \(\sin x + \cos x = \sqrt{2}\sin\left(x + \frac{\pi}{4}\right)\)
    💡 \(\sin x + \cos x \in [-\sqrt{2}; \sqrt{2}]\)
    🔹 Шаг 2. Решаем
    \(\sqrt{2}\sin\left(x + \frac{\pi}{4}\right) > 1\)
    \(\sin\left(x + \frac{\pi}{4}\right) > \frac{1}{\sqrt{2}}\)
    \(x + \frac{\pi}{4} \in \left(\frac{\pi}{4} + 2\pi k;\; \frac{3\pi}{4} + 2\pi k\right)\)
    \(x \in (2\pi k;\; \frac{\pi}{2} + 2\pi k)\)
    ✅ Ответ: \(x \in (2\pi k;\; \frac{\pi}{2} + 2\pi k)\), \(k \in \mathbb{Z}\)
    💡 Зная ограниченность \(\sin x + \cos x\), мы свели задачу к простому тригонометрическому неравенству.
    📐 Пример 4. \(\sin^2 x + \cos^2 x + \sqrt{x^2+1} = 2\) метод мажорант с ограниченностью
    🔹 Шаг 1. Упрощаем
    \(\sin^2 x + \cos^2 x = 1\) — всегда.
    Получаем: \(1 + \sqrt{x^2+1} = 2\)
    \(\sqrt{x^2+1} = 1\)
    🔹 Шаг 2. Решаем
    \(x^2+1 = 1\) → \(x^2 = 0\) → \(x = 0\)
    ✅ Ответ: \(x = 0\)
    💡 Основная идея: \(\sqrt{x^2+1} \ge 1\), поэтому равенство \(= 1\) достигается только при \(x = 0\).
    📐 Пример 5. \(\sin x = x^2 + 1\) доказательство отсутствия решений
    🔹 Шаг 1. Оцениваем каждую часть
    \(\sin x \le 1\) — синус не больше 1
    \(x^2 + 1 \ge 1\) — квадрат + 1 не меньше 1
    🔹 Шаг 2. Анализируем
    💡 Равенство возможно только если \(\sin x = 1\) и \(x^2 + 1 = 1\).
    Из \(x^2 + 1 = 1\) → \(x = 0\).
    Но \(\sin 0 = 0 \neq 1\).
    ✅ Ответ: решений нет
    💡 Ограниченность помогла мгновенно доказать, что решений нет!
    📌 Когда применять ограниченность
    🎯 Признаки того, что нужна ограниченность:

    📌 В уравнении есть \(\sin x\), \(\cos x\) — их значения в \([-1; 1]\).
    📌 Есть \(x^2\), \(|x|\), \(\sqrt{x}\) — они \(\ge 0\).
    📌 Есть \(\frac{1}{x^2+1}\) — она в \((0; 1]\).
    📌 Нужно доказать, что решений нет.
    📌 Нужно сузить область поиска корней.

    ✅ Алгоритм:
    1. Найти максимальное значение \(f(x)\) (или минимальное).
    2. Найти минимальное значение \(g(x)\) (или максимальное).
    3. Если \(\max f < \min g\) → решений нет.
    4. Если \(\max f = \min g = M\) → решать систему \(f(x) = M\), \(g(x) = M\).
    5. Если \(\max f \ge \min g\) — искать пересечение.
