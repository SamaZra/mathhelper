Задачи математической статистики

📊 Что такое математическая статистика как из данных извлечь смысл

Представьте, что вы измеряете рост 30 одноклассников. У вас есть 30 чисел — это данные. Но как их осмыслить? Просто смотреть на список чисел неудобно. Нужны инструменты, которые помогут найти среднее, самое частое или центральное значение.

Этим и занимается математическая статистика — наука о сборе, обработке и анализе данных. Она помогает делать выводы о целом (генеральной совокупности), изучая только его часть (выборку).

Главная идея: статистика превращает сырые числа в понятные характеристики — среднее, моду, медиану. По ним можно сравнивать группы, находить закономерности и принимать решения.
Выборка и вариационный ряд откуда берутся данные

В статистике работают с двумя уровнями:

  • Генеральная совокупность — это все объекты, которые нас интересуют (например, все ученики школы, все детали в партии).
  • Выборка — это часть генеральной совокупности, которую мы реально измерили. Обычно именно по выборке делают выводы обо всей совокупности.

Чтобы данные было удобно анализировать, их упорядочивают по возрастанию — получается вариационный ряд. Это просто те же числа, но отсортированные.

Пример. Оценки: 4, 5, 3, 4, 5, 2, 3, 4, 5, 4.

Вариационный ряд: 2, 3, 3, 4, 4, 4, 4, 5, 5, 5.
Основные характеристики выборки среднее, мода, медиана, размах
1. Среднее арифметическое ( \(\bar{x}\) ) — это сумма всех значений, делённая на количество чисел. $$ \bar{x} = \frac{x_1 + x_2 + \dots + x_n}{n} $$
Отражает «типичный» уровень. Если числа 2, 3, 5, то среднее = (2+3+5)/3 = 3,33.
2. Мода ( Mo ) — значение, которое встречается в выборке чаще всего.
В ряду 2, 3, 3, 5 мода = 3 (оно встречается чаще). В ряду 2, 3, 5, 7 моды нет (все уникальны).
3. Медиана ( Me ) — число, стоящее в середине упорядоченного (отсортированного) ряда.
Если чисел нечётное количество (например, 5), медиана — это 3-е число. Если чётное (например, 10), медиана — среднее между 5-м и 6-м.
4. Размах ( R ) — разность между максимальным и минимальным значением. $$ R = x_{\max} - x_{\min} $$
Показывает ширину диапазона данных. Для ряда 2, 3, 7 размах = 7 − 2 = 5.
Что выбрать?
• Среднее — когда нужна общая оценка. Чувствительно к выбросам (одно огромное число может испортить картину).
• Мода — когда нужно самое частое значение (например, самый популярный размер обуви).
• Медиана — когда данные содержат выбросы и нужна устойчивая середина (например, зарплата: одна огромная зарплата не должна сильно сдвигать медиану).
• Размах — для быстрой оценки разброса (например, от 5°C до 25°C).
Пример обработки данных пошаговый расчёт всех характеристик
Условие: Даны оценки: 4, 5, 3, 4, 5, 2, 3, 4, 5, 4. Найти среднее, моду, медиану, размах.

Шаг 1. Вариационный ряд (по возрастанию):
2, 3, 3, 4, 4, 4, 4, 5, 5, 5.

Шаг 2. Среднее арифметическое:
\(\bar{x} = \frac{4+5+3+4+5+2+3+4+5+4}{10} = \frac{39}{10} = 3{,}9\).

Шаг 3. Мода:
Чаще всего встречается 4 (4 раза). Мода = 4.

Шаг 4. Медиана:
В ряду 10 чисел, значит, медиана — среднее между 5-м и 6-м числами. Оба равны 4.
Медиана = 4.

Шаг 5. Размах:
\(R = 5 - 2 = 3\).

Ответ: среднее = 3,9; мода = 4; медиана = 4; размах = 3.
Выборочная дисперсия ★ ЕГЭ мера разброса данных

Среднее арифметическое показывает «центр» данных, но не показывает, насколько сильно значения разбросаны. Для этого используется выборочная дисперсия:

$$ D_{\text{в}} = \frac{(x_1 - \bar{x})^2 + (x_2 - \bar{x})^2 + \dots + (x_n - \bar{x})^2}{n} $$

Где \(\bar{x}\) — среднее арифметическое, \(n\) — объём выборки.

Смысл: дисперсия — это средний квадрат отклонения значений от среднего. Чем больше дисперсия, тем сильнее разброс. Корень из дисперсии называется выборочным средним квадратическим отклонением.
Пример. Выборка: 2, 4, 6. Найти выборочную дисперсию.

Шаг 1. Среднее: \(\bar{x} = \frac{2+4+6}{3} = 4\).
Шаг 2. Отклонения: \((2-4)^2 = 4\), \((4-4)^2 = 0\), \((6-4)^2 = 4\).
Шаг 3. Дисперсия: \(D_{\text{в}} = \frac{4+0+4}{3} = \frac{8}{3} \approx 2{,}67\).
Ответ: \(D_{\text{в}} \approx 2{,}67\).
Доверительный интервал ★ ЕГЭ оценка точности среднего

Среднее по выборке — это лишь оценка истинного среднего генеральной совокупности. Насколько она точна? На этот вопрос отвечает доверительный интервал.

$$ \bar{x} \pm t \cdot \frac{s}{\sqrt{n}} $$

Где \(\bar{x}\) — выборочное среднее, \(s\) — выборочное среднее квадратическое отклонение, \(n\) — объём выборки, \(t\) — коэффициент (для уровня доверия 95% и больших \(n\) \(t \approx 2\)).

Пример. Выборочное среднее роста 100 студентов \(\bar{x} = 175\) см, \(s = 7\) см. Найти 95%-й доверительный интервал.

Решение: \(175 \pm 2 \cdot \frac{7}{\sqrt{100}} = 175 \pm 1{,}4\).
Ответ: \((173{,}6; 176{,}4)\) см с вероятностью 95%.
Задачи для самостоятельного решения 15 задач с подсказками
Как работать с подсказками: откройте подсказку, только если не получается решить. В ней нет прямого ответа, но есть направление мысли.

1. Дан ряд чисел: 7, 8, 5, 9, 6, 8, 10. Найдите среднее арифметическое.

Подсказка
Сложите все числа и разделите на их количество. Помните: важно не сбиться при подсчёте суммы.

2. Дан ряд чисел: 7, 8, 5, 9, 6, 8, 10. Найдите моду.

Подсказка
Мода — это самое частое значение. Посчитайте, сколько раз встречается каждое число, и выберите то, у которого частота максимальна.

3. Дан ряд чисел: 7, 8, 5, 9, 6, 8, 10. Найдите медиану.

Подсказка
Сначала упорядочьте ряд по возрастанию. Затем найдите центральное число (в этом ряду нечётное количество чисел — медиана одно число).

4. Дан ряд чисел: 3, 3, 3, 3, 3, 3, 3, 3, 3, 3. Найдите среднее, моду и медиану.

Подсказка
Если все числа одинаковые, то все характеристики совпадают с этим числом. Убедитесь в этом самостоятельно.

5. В классе 10 учеников. Их рост (в см): 150, 155, 160, 155, 165, 155, 160, 170, 155, 160. Найдите моду.

Подсказка
Посчитайте, сколько раз встречается каждое значение. Мода — то, которое встречается чаще всего.

6. Для данных из задачи 5 найдите медиану.

Подсказка
Упорядочьте значения по возрастанию. Количество чисел чётное (10). Медиана — это среднее арифметическое двух центральных чисел (5-го и 6-го).

7. Для данных из задачи 5 найдите среднее арифметическое и размах.

Подсказка
Среднее — это сумма всех значений, делённая на их количество. Размах — это разность между самым большим и самым маленьким значением.

8. Даны оценки по математике: 3, 4, 2, 5, 4, 4, 3, 5, 4, 2. Найдите среднее, моду и медиану.

Подсказка
Действуйте последовательно: сначала упорядочьте ряд, затем найдите среднее (сумма/10), моду (самое частое значение) и медиану (среднее 5-го и 6-го чисел).

9. В спортивной секции 8 человек. Их возраст: 12, 13, 12, 14, 15, 12, 14, 13. Найдите среднее арифметическое, моду и медиану.

Подсказка
Не забывайте упорядочивать данные для медианы. Среднее и мода вычисляются без этого шага.

10. В таблице приведены данные о количестве клиентов за неделю: 12, 18, 10, 15, 20, 10, 12. Найдите моду и медиану.

Подсказка
Посчитайте частоту каждого значения для моды. Для медианы сначала упорядочьте ряд (7 чисел — медиана одна, посередине).

11. В магазине продали за день 15 пакетов молока. Цены (в рублях): 60, 70, 65, 70, 80, 60, 75, 70, 65, 70, 80, 60, 70, 75, 70. Найдите среднее и моду.

Подсказка
Для среднего суммируйте все цены и разделите на количество пакетов (15). Для моды определите самую частую цену.

12. Для данных задачи 11 найдите медиану.

Подсказка
Упорядочьте 15 цен по возрастанию. Медиана — 8-е число (так как 15 нечётное, это ровно середина).

13. На соревнованиях спортсмены получили оценки: 7, 8, 6, 9, 7, 8, 10, 7, 9, 6, 7. Найдите все три характеристики (среднее, моду, медиану).

Подсказка
Данных 11 — нечётное. Медиана — 6-е число упорядоченного ряда. Среднее — сумма/11. Мода — самая частая оценка.

14. Ежедневно в течение 10 дней температура была: 20, 22, 21, 23, 22, 20, 24, 22, 23, 21. Найдите медиану и размах.

Подсказка
Для медианы: упорядочьте, найдите среднее 5-го и 6-го чисел. Размах — разность между максимумом и минимумом.

15. В группе 12 студентов. Их баллы за экзамен: 70, 85, 90, 75, 80, 85, 90, 95, 80, 75, 85, 80. Найдите среднее, моду, медиану.

Подсказка
Упорядочьте данные. Медиана — между 6-м и 7-м числами. Мода — самое частое значение. Среднее — сумма/12.
