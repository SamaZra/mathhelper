Функция $y = \sin x$, её свойства и график

📖 Как круг превращается в график

До этого мы работали с углами и треугольниками. Но в математике есть мощный инструмент — функции. Давайте посмотрим, как синус превращается из геометрического отрезка в полноценную функцию.

Представьте себе единичную окружность (радиус 1). Если мы будем крутить точку $M$ по этой окружности, то её высота (координата $y$) будет постоянно меняться. Функция $y = \sin x$ — это машина, которая берёт угол поворота $x$ и выдаёт высоту точки $M$.

  • Вход функции: угол поворота $x$ (в радианах).
  • Выход функции: ордината точки $M$, то есть $\sin x$.
💡 Как круг связан с графиком: Круг показывает, почему синус меняется. А график показывает, как он меняется. Если мы «развернём» движение точки по окружности на горизонтальную ось, мы получим волнообразную кривую — синусоиду.

Подвигайте ползунок угла $\alpha$ — точка на окружности и соответствующая точка на графике двигаются синхронно.

Единичная окружность: точка $M(\cos\alpha; \sin\alpha)$
Синусоида: $y = \sin x$ — «развёртка» окружности
α = 0,80 рад
📐 Свойства функции $y = \sin x$ нажмите на название — оно подсветится на графике ниже

Нажимайте на свойства — на графике ниже подсветится соответствующий участок.

  • 1. Область определения
    $D(y) = \mathbb{R} = (-\infty; +\infty)$ — синус определён для любого угла.
  • 2. Область значений
    $E(y) = [-1; 1]$ — значения синуса всегда лежат в этом отрезке.
  • 3. Нечётность
    $\sin(-x) = -\sin x$ — функция нечётная. График симметричен относительно начала координат.
  • 4. Период
    $T = 2\pi$, то есть $\sin(x + 2\pi) = \sin x$. График повторяется каждые $2\pi$.
  • 5. Нули функции
    $\sin x = 0$ при $x = \pi n$, $n \in \mathbb{Z}$.
  • 6. Промежутки знакопостоянства
    $\sin x > 0$ при $x \in \left(2\pi n; \pi + 2\pi n\right)$;
    $\sin x < 0$ при $x \in \left(\pi + 2\pi n; 2\pi + 2\pi n\right)$, $n \in \mathbb{Z}$.
  • 7. Монотонность
    Возрастает на $\left[-\dfrac{\pi}{2} + 2\pi n; \dfrac{\pi}{2} + 2\pi n\right]$;
    убывает на $\left[\dfrac{\pi}{2} + 2\pi n; \dfrac{3\pi}{2} + 2\pi n\right]$, $n \in \mathbb{Z}$.
  • 8. Экстремумы (изучается позже)
    Максимум $\sin x = 1$ при $x = \dfrac{\pi}{2} + 2\pi n$; минимум $\sin x = -1$ при $x = -\dfrac{\pi}{2} + 2\pi n$.
📈 График $y = \sin x$ синусоида

График функции $y = \sin x$ называется синусоидой. Это та же косинусоида, но сдвинутая вправо на $\dfrac{\pi}{2}$: $\sin x = \cos\left(x - \dfrac{\pi}{2}\right)$.

$y = \sin x$ — основной график (можно прокручивать)
📌 Как читать график:
• В точке $x = 0$ значение равно нулю: $\sin 0 = 0$.
• При $x = \dfrac{\pi}{2}$ максимум: $\sin\dfrac{\pi}{2} = 1$.
• При $x = \pi$ снова ноль: $\sin\pi = 0$.
• При $x = \dfrac{3\pi}{2}$ минимум: $\sin\dfrac{3\pi}{2} = -1$.
• Дальше всё повторяется каждые $2\pi$.
🔧 Преобразования графика введите коэффициенты в формулу

Из базового графика $y = \sin x$ можно получить множество других, меняя коэффициенты в формуле:

φ (радианы) можно вводить так: 0.5, -1.2, pi/2, π/3, 2*pi
A — Амплитуда (y = A·sin(...))
Растягивает или сжимает график по вертикали (по оси OY).
Если A > 1 — растяжение (график выше).
Если 0 < A < 1 — сжатие.
Если A < 0 — график переворачивается (отражение от оси OX).
k — Частота (y = sin(k·x ...))
Сжимает или растягивает график по горизонтали (по оси OX).
Если k > 1 — сжатие (график "чаще").
Если 0 < k < 1 — растяжение ("реже").
Период новой функции: T = 2π / |k|.
φ — Сдвиг по фазе (y = sin(x + φ))
Двигает график влево или вправо по оси OX.
Если φ > 0 — сдвиг влево (опережение).
Если φ < 0 — сдвиг вправо (запаздывание).
B — Вертикальный сдвиг (y = ... + B)
Двигает весь график вверх или вниз по оси OY.
Если B > 0 — сдвиг вверх.
Если B < 0 — сдвиг вниз.
Область значений становится [B - |A|; B + |A|].

📌 Пример: как из $y = \sin x$ получить $y = 2\sin(x - \pi/6)$?

Шаг 1. Сдвигаем график $y = \sin x$ вправо на $\pi/6$.
Шаг 2. Растягиваем по $OY$ в 2 раза (амплитуда становится 2).
Результат: $y = 2\sin(x - \pi/6)$.
📝 Примеры применения
Пример 1 (вычисление). Найти $\sin\dfrac{2\pi}{3}$.

Шаг 1. Приводим к острому углу. $\dfrac{2\pi}{3} = \pi - \dfrac{\pi}{3}$, вторая четверть.
Шаг 2. Формула приведения. $\sin\left(\pi - \dfrac{\pi}{3}\right) = \sin\dfrac{\pi}{3}$.
Шаг 3. Табличное значение. $\sin\dfrac{\pi}{3} = \dfrac{\sqrt{3}}{2}$.
Ответ: $\dfrac{\sqrt{3}}{2}$.
Пример 2 (уравнение). Решить $\sin x = \dfrac{1}{2}$.

Шаг 1. Общая формула. $x = (-1)^n\arcsin\dfrac{1}{2} + \pi n = (-1)^n\dfrac{\pi}{6} + \pi n$.
Ответ: $x = (-1)^n\dfrac{\pi}{6} + \pi n$, $n \in \mathbb{Z}$.
Пример 3 (нечётность). Вычислить $\sin(-30°)$.

Решение. $\sin(-30°) = -\sin 30° = -\dfrac{1}{2}$.
Ответ: $-\dfrac{1}{2}$.
🧮 Решение задач
Задача №1. Найти пределы изменения функции $y = \sin t$ на отрезке $\left[\dfrac{\pi}{6}; \dfrac{\pi}{2}\right]$.

Решение. Функция монотонно возрастает на указанном промежутке, значит, наименьшее значение — на левом конце $y\left(\dfrac{\pi}{6}\right) = \dfrac{1}{2}$, наибольшее — на правом $y\left(\dfrac{\pi}{2}\right) = 1$.
Ответ: $\min = \dfrac{1}{2}$, $\max = 1$.
Задача №2. Найти наибольшее и наименьшее значение функции $y = \sin t$ на отрезке $\left[\dfrac{\pi}{3}; \dfrac{7\pi}{6}\right]$.

Решение. На данном промежутке функция немонотонна: возрастает до $\dfrac{\pi}{2}$, затем убывает. Наибольшее значение — в точке максимума $y\left(\dfrac{\pi}{2}\right) = 1$, наименьшее — на правом конце $y\left(\dfrac{7\pi}{6}\right) = -\dfrac{1}{2}$.
Ответ: $\max = 1$, $\min = -\dfrac{1}{2}$.
Задача №3. Решить уравнение $\sin x = x^2 + 1$.

Решение. Правая часть $x^2 + 1 \ge 1$, а $\sin x \le 1$. Равенство возможно только при $x = 0$ и $\sin 0 = 1$ — противоречие.
Ответ: корней нет.
Задача №4. Найти число корней уравнения $x^2 = \sin x$.

Решение. При $x < 0$ правая часть $\sin x \le 0$, левая $x^2 \ge 0$ — корни возможны только при $x = 0$. Но $\sin 0 = 0 = 0^2$ — да, $x = 0$ подходит. На $(0; 1)$ $\sin x > x^2$ при малых $x$ и $\sin x < x^2$ при $x$ близком к 1 — есть ещё один корень. При $x > 1$ $x^2 > 1 \ge \sin x$ — корней нет.
Ответ: два корня ($x = 0$ и $x \approx 0{,}88$).
Задача №5. Построить график функции $y = \sin 3x$.

Решение. Синус — нечётная функция, строим график на участке $\left[0; \dfrac{\pi}{3}\right]$, затем симметрично отображаем относительно начала координат и получаем график на $\left[-\dfrac{\pi}{3}; \dfrac{\pi}{3}\right]$, длина которого равна периоду. График сжимается к оси $Oy$ в 3 раза.
Результат: синусоида с периодом $T = \dfrac{2\pi}{3}$.
✏️ Задания для самостоятельного решения проверьте себя
1. Постройте графики функций:
1) $y = \sin x + 1$;
2) $y = \sin x - 1$;
3) $y = \sin\left(x + \dfrac{\pi}{2}\right)$;
4) $y = \sin\left(x - \dfrac{\pi}{3}\right)$.
2. Найти наибольшее и наименьшее значение функции $y = \sin x$ на отрезке $\left[0; \dfrac{4\pi}{3}\right]$.
Подсказка: максимум в $x = \pi/2$, минимум — на правом конце $x = 4\pi/3$.
3. Определить область значений функции $y = -8\sin x + 3$.
Подсказка: $-1 \le \sin x \le 1$, значит $-8 \le -8\sin x \le 8$, и $-5 \le y \le 11$.
4. Определить чётность или нечётность функции $f(x) = x^5 \cdot \sin 6x$.
Подсказка: $f(-x) = (-x)^5 \sin(-6x) = (-x^5)(-\sin 6x) = x^5 \sin 6x = f(x)$ — функция чётная.
5. Определить, возрастает или убывает функция $y = \sin x$ на отрезке $\left[-4\pi; -3\pi\right]$.
Подсказка: $-4\pi$ и $-3\pi$ — те же точки, что $0$ и $\pi$ после сдвига на $4\pi$; на $[0; \pi]$ синус возрастает до $\pi/2$, затем убывает — значит, функция немонотонна.
6. Найти наибольшее и наименьшее значения функции $y = \sin^4 2x - \cos^4 2x + 4$.
Подсказка: $\sin^4 a - \cos^4 a = -\cos 2a$, значит $y = -\cos 4x + 4$. Наибольшее $= 5$, наименьшее $= 3$.
7. Определить наименьшее и наибольшее значения функции $y = \sin x$ на полуинтервале $\left(-\dfrac{4\pi}{3}; -\dfrac{\pi}{3}\right]$.
Подсказка: проверьте поведение на концах и в точке максимума $x = -\dfrac{3\pi}{2}$.
⚠️ На что обратить внимание
  • Синус нечётный, косинус — чётный. $\sin(-x) = -\sin x$, а $\cos(-x) = \cos x$.
  • Область значений — $[-1; 1]$. Не бывает $\sin x = 2$.
  • В точке $0$ ноль. $\sin 0 = 0$, а не $1$ (в отличие от косинуса).
  • Период $2\pi$, а не $\pi$.
  • График проходит через начало координат. Это следствие нечётности.
