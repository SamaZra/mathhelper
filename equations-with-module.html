|x| Уравнения с модулем (ЕГЭ)

📖 Что такое уравнение с модулем?

Модуль числа — это его расстояние до нуля: \(|a| = a\) при \(a \ge 0\), \(|a| = -a\) при \(a < 0\).

📌 Основные методы решения уравнений с модулем:
1️⃣ Раскрытие по определению — разбиение на два случая.
2️⃣ Метод интервалов — для суммы модулей.
3️⃣ Возведение в квадрат — для уравнений вида \(|f(x)| = g(x)\).
📐 Пример 1. \(|2x-1| = 3\) метод — раскрытие по определению
🔹 1. Что такое модуль?
💡 \(|a| = b\) означает, что \(a = b\) или \(a = -b\).
🔹 2. Раскрываем
\(2x-1 = 3\) или \(2x-1 = -3\)
\(2x = 4\) или \(2x = -2\)
\(x = 2\) или \(x = -1\)
🔹 3. Проверка
💡 Подставляем: \(|2 \cdot 2 - 1| = |3| = 3\), \(|-1| = 1\). Всё верно.
✅ Ответ: \(x = -1,\; x = 2\)
📐 Пример 2 (ЕГЭ). \(|x^2-4| = 3x\) метод — раскрытие по определению + ОДЗ
🔹 1. ОДЗ
💡 Правая часть \(3x\) должна быть \(\ge 0\), так как модуль неотрицателен.
\(3x \ge 0 \Rightarrow x \ge 0\)
🔹 2. Раскрываем модуль
💡 Модуль меняет знак в точках \(x = \pm 2\).
Случай 1: \(x \le -2\) или \(x \ge 2\)
\(x^2 - 4 = 3x\)
\(x^2 - 3x - 4 = 0\)
\((x-4)(x+1) = 0\)
\(x = 4\) или \(x = -1\)
💡 \(x = 4\) — подходит (≥ 2).
\(x = -1\) — не подходит (≤ -2, но \(x \ge 0\) из ОДЗ).
Случай 2: \(-2 < x < 2\)
\(-x^2 + 4 = 3x\)
\(-x^2 - 3x + 4 = 0\)
\(x^2 + 3x - 4 = 0\)
\((x+4)(x-1) = 0\)
\(x = -4\) или \(x = 1\)
💡 \(x = 1\) — подходит (\(0 < 1 < 2\)).
\(x = -4\) — не подходит (не входит в промежуток).
🔹 3. Проверка по ОДЗ
💡 \(x = 4\) и \(x = 1\) удовлетворяют \(x \ge 0\).
✅ Ответ: \(x = 1,\; x = 4\)
📐 Пример 3 (ЕГЭ). \(\left|\frac{x-1}{x+2}\right| = \frac{x}{x-3}\) метод — раскрытие + ОДЗ
🔹 1. ОДЗ
\(x \neq -2,\; x \neq 3\)
💡 Правая часть \(\frac{x}{x-3}\) должна быть \(\ge 0\).
\(\frac{x}{x-3} \ge 0\)
💡 Решаем методом интервалов: \(x \le 0\) или \(x > 3\).
🔹 2. Раскрываем модуль
💡 \(\left|\frac{x-1}{x+2}\right| = \frac{x}{x-3} \Rightarrow \frac{x-1}{x+2} = \pm \frac{x}{x-3}\)
Случай 1: \(\frac{x-1}{x+2} = \frac{x}{x-3}\)
\((x-1)(x-3) = x(x+2)\)
\(x^2 - 4x + 3 = x^2 + 2x\)
\(-6x + 3 = 0\)
\(x = 0.5\)
💡 Проверяем ОДЗ: \(0.5\) не подходит (нужно \(x \le 0\) или \(x > 3\)).
Случай 2: \(\frac{x-1}{x+2} = -\frac{x}{x-3}\)
\((x-1)(x-3) = -x(x+2)\)
\(x^2 - 4x + 3 = -x^2 - 2x\)
\(2x^2 - 2x + 3 = 0\)
💡 Дискриминант \(D = 4 - 24 = -20 < 0\) — корней нет.
✅ Ответ: \(\varnothing\) (решений нет)
📐 Пример 4 (ЕГЭ). \(|2^x - 8| = 2^x - 2\) метод — раскрытие + замена \(t = 2^x\)
🔹 1. Замена \(t = 2^x > 0\)
\(|t - 8| = t - 2\)
💡 Правая часть должна быть \(\ge 0 \Rightarrow t \ge 2\).
🔹 2. Раскрываем модуль
Случай 1: \(t \ge 8\)
\(t - 8 = t - 2\)
\(-8 = -2\) — противоречие
Случай 2: \(t < 8\)
\(-t + 8 = t - 2\)
\(-2t = -10\)
\(t = 5\)
💡 \(t = 5\) подходит: \(2 \le 5 < 8\).
🔹 3. Возвращаемся к \(x\)
\(2^x = 5 \Rightarrow x = \log_2 5\)
✅ Ответ: \(x = \log_2 5\)
📐 Пример 5 (ЕГЭ). \(|\log_2 x - 1| + |\log_2 x - 3| = 2\) метод — метод интервалов
🔹 1. ОДЗ
\(x > 0\)
🔹 2. Замена \(t = \log_2 x\)
\(|t-1| + |t-3| = 2\)
💡 Точки смены знака: \(t = 1\) и \(t = 3\).
🔹 3. Метод интервалов
1) \(t \le 1\)
\(|t-1| = -t+1,\; |t-3| = -t+3\)
\(-t+1 - t + 3 = 2\)
\(-2t + 4 = 2 \Rightarrow t = 1\)
2) \(1 < t \le 3\)
\(|t-1| = t-1,\; |t-3| = -t+3\)
\(t-1 - t + 3 = 2\)
\(2 = 2\) — верно для всех \(t \in (1; 3]\)
3) \(t > 3\)
\(|t-1| = t-1,\; |t-3| = t-3\)
\(t-1 + t-3 = 2\)
\(2t - 4 = 2 \Rightarrow t = 3\)
🔹 4. Объединяем
\(t \in [1; 3]\)
🔹 5. Возвращаемся к \(x\)
\(1 \le \log_2 x \le 3\)
\(2^1 \le x \le 2^3\)
\(2 \le x \le 8\)
✅ Ответ: \(x \in [2; 8]\)
📐 Пример 6 (ЕГЭ). \(|x^2-3x| + |x^2-3x-4| = 4\) метод — метод интервалов + замена
🔹 1. Замена \(t = x^2 - 3x\)
\(|t| + |t-4| = 4\)
💡 Точки смены знака: \(t = 0\) и \(t = 4\).
🔹 2. Метод интервалов
1) \(t \le 0\)
\(|t| = -t,\; |t-4| = -t+4\)
\(-t - t + 4 = 4\)
\(-2t = 0 \Rightarrow t = 0\)
2) \(0 < t \le 4\)
\(|t| = t,\; |t-4| = -t+4\)
\(t - t + 4 = 4\)
\(4 = 4\) — верно для всех \(t \in (0; 4]\)
3) \(t > 4\)
\(|t| = t,\; |t-4| = t-4\)
\(t + t - 4 = 4\)
\(2t = 8 \Rightarrow t = 4\)
🔹 3. Объединяем
\(t \in [0; 4]\)
🔹 4. Возвращаемся к \(x\)
\(0 \le x^2 - 3x \le 4\)
\(x^2 - 3x \ge 0\) и \(x^2 - 3x \le 4\)
\(x(x-3) \ge 0 \Rightarrow x \le 0\) или \(x \ge 3\)
\(x^2 - 3x - 4 \le 0 \Rightarrow (x-4)(x+1) \le 0 \Rightarrow -1 \le x \le 4\)
🔹 5. Пересекаем
\(x \in [-1; 0] \cup [3; 4]\)
✅ Ответ: \(x \in [-1; 0] \cup [3; 4]\)
📐 Пример 7 (ЕГЭ). \(|\sin x| + |\cos x| = \sqrt{2}\) метод — возведение в квадрат
🔹 1. Возводим в квадрат
💡 Так как обе части неотрицательны, можно возвести в квадрат.
\((|\sin x| + |\cos x|)^2 = (\sqrt{2})^2 = 2\)
\(\sin^2 x + \cos^2 x + 2|\sin x \cos x| = 2\)
\(1 + 2|\sin x \cos x| = 2\)
\(2|\sin x \cos x| = 1\)
\(|\sin x \cos x| = \frac{1}{2}\)
🔹 2. Используем формулу \(\sin 2x = 2\sin x \cos x\)
\(\left|\frac{\sin 2x}{2}\right| = \frac{1}{2}\)
\(|\sin 2x| = 1\)
🔹 3. Решаем
\(\sin 2x = \pm 1\)
\(2x = \frac{\pi}{2} + \pi k,\; k \in \mathbb{Z}\)
\(x = \frac{\pi}{4} + \frac{\pi k}{2},\; k \in \mathbb{Z}\)
✅ Ответ: \(x = \frac{\pi}{4} + \frac{\pi k}{2},\; k \in \mathbb{Z}\)
