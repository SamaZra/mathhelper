Тригонометрические неравенства

📖 Что такое тригонометрическое неравенство

Тригонометрическое неравенство — неравенство, содержащее переменную под знаком тригонометрической функции.

$\sin x > \dfrac{1}{2}$
$\cos x \leq -\dfrac{\sqrt{2}}{2}$
$\tg x < 1$
$\sin 2x \geq \dfrac{\sqrt{3}}{2}$

В отличие от уравнений, где ответ — набор отдельных точек, в неравенствах ответ — промежутки. И эти промежутки нужно «прочитать» по кругу.

💡 Главная идея: решение тригонометрических неравенств — это чтение дуг на единичной окружности. Уравнение — точки, неравенство — дуги. Всё остальное — та же логика, что и в уравнениях: находим границы (решаем равенство), отмечаем дугу, добавляем период.
🎯 Открыть интерактивный круг
📐 $\sin x > a$ и $\sin x < a$ дуга над/под горизонтальной прямой

Значения $\sin x$ — это проекции точек на ось $Oy$. Линия $y = a$ горизонтальна. Дуги, где $\sin x > a$, — те, что выше этой линии; где $\sin x < a$ — ниже.

Пример 1. $\sin x > \dfrac{1}{2}$.

Шаг 1. Границы. Решаем $\sin x = \dfrac{1}{2}$: $x_1 = \dfrac{\pi}{6}$, $x_2 = \dfrac{5\pi}{6}$.
Шаг 2. Дуга. Точки, где $\sin x > \dfrac{1}{2}$ — выше прямой $y = \dfrac{1}{2}$. Это дуга от $\dfrac{\pi}{6}$ до $\dfrac{5\pi}{6}$ (против часовой стрелки).
Шаг 3. Период. Добавляем $2\pi n$.
Ответ: $x \in \left(\dfrac{\pi}{6} + 2\pi n;\, \dfrac{5\pi}{6} + 2\pi n\right)$, $n \in \mathbb{Z}$.
Пример 2. $\sin x \leq -\dfrac{\sqrt{2}}{2}$.

Шаг 1. Границы. $\sin x = -\dfrac{\sqrt{2}}{2}$: $x_1 = \dfrac{5\pi}{4}$, $x_2 = \dfrac{7\pi}{4}$.
Шаг 2. Дуга. Ниже прямой $y = -\dfrac{\sqrt{2}}{2}$ — от $\dfrac{5\pi}{4}$ до $\dfrac{7\pi}{4}$.
Шаг 3. Период. Плюс $2\pi n$. Неравенство нестрогое — концы включены.
Ответ: $x \in \left[\dfrac{5\pi}{4} + 2\pi n;\, \dfrac{7\pi}{4} + 2\pi n\right]$, $n \in \mathbb{Z}$.
📐 $\cos x > a$ и $\cos x < a$ дуга справа/слева от вертикальной прямой

Значения $\cos x$ — проекции на ось $Ox$. Линия $x = a$ вертикальна. Дуги, где $\cos x > a$, — правее этой линии; где $\cos x < a$ — левее.

Пример 3. $\cos x < -\dfrac{1}{2}$.

Шаг 1. Границы. $\cos x = -\dfrac{1}{2}$: $x_1 = \dfrac{2\pi}{3}$, $x_2 = \dfrac{4\pi}{3}$.
Шаг 2. Дуга. Левее прямой $x = -\dfrac{1}{2}$ — дуга от $\dfrac{2\pi}{3}$ до $\dfrac{4\pi}{3}$.
Шаг 3. Период. Плюс $2\pi n$. Концы не включены (неравенство строгое).
Ответ: $x \in \left(\dfrac{2\pi}{3} + 2\pi n;\, \dfrac{4\pi}{3} + 2\pi n\right)$, $n \in \mathbb{Z}$.
Пример 4. $\cos x \geq \dfrac{\sqrt{3}}{2}$.

Шаг 1. Границы. $\cos x = \dfrac{\sqrt{3}}{2}$: $x_1 = \dfrac{\pi}{6}$, $x_2 = -\dfrac{\pi}{6}$ (или $\dfrac{11\pi}{6}$).
Шаг 2. Дуга. Правее прямой $x = \dfrac{\sqrt{3}}{2}$ — небольшой отрезок от $-\dfrac{\pi}{6}$ до $\dfrac{\pi}{6}$.
Шаг 3. Период. Неравенство нестрогое — концы включены.
Ответ: $x \in \left[-\dfrac{\pi}{6} + 2\pi n;\, \dfrac{\pi}{6} + 2\pi n\right]$, $n \in \mathbb{Z}$.
📐 $\tg x > a$ и $\tg x < a$ через линию тангенсов

Для тангенса удобно использовать линию тангенсов — касательную к окружности в точке $(1; 0)$. Отмечаем на ней значение $a$, проводим прямую из центра и читаем дугу.

Пример 5. $\tg x \leq 1$.

Шаг 1. Граница. $\tg x = 1 \Rightarrow x = \dfrac{\pi}{4} + \pi n$.
Шаг 2. Дуга в пределах одного периода. В промежутке $\left(-\dfrac{\pi}{2}; \dfrac{\pi}{2}\right)$: $\tg x \leq 1$ для $x \in \left(-\dfrac{\pi}{2}; \dfrac{\pi}{4}\right]$.
Шаг 3. Общий вид. Ответ: $x \in \left(-\dfrac{\pi}{2} + \pi n;\, \dfrac{\pi}{4} + \pi n\right]$, $n \in \mathbb{Z}$.
Пример 6. $\tg x > -\sqrt{3}$.

Шаг 1. Граница. $\tg x = -\sqrt{3} \Rightarrow x = -\dfrac{\pi}{3} + \pi n$.
Шаг 2. Дуга. В $\left(-\dfrac{\pi}{2}; \dfrac{\pi}{2}\right)$: $\tg x > -\sqrt{3}$ для $x \in \left(-\dfrac{\pi}{3}; \dfrac{\pi}{2}\right)$.
Шаг 3. Период. Ответ: $x \in \left(-\dfrac{\pi}{3} + \pi n;\, \dfrac{\pi}{2} + \pi n\right)$, $n \in \mathbb{Z}$.
📐 Неравенства с преобразованиями сведение к простейшим
Пример 7. $\sin 2x > \dfrac{\sqrt{3}}{2}$.

Шаг 1. Замена $t = 2x$. $\sin t > \dfrac{\sqrt{3}}{2} \Rightarrow t \in \left(\dfrac{\pi}{3} + 2\pi n;\, \dfrac{2\pi}{3} + 2\pi n\right)$.
Шаг 2. Возврат. $2x \in \left(\dfrac{\pi}{3} + 2\pi n;\, \dfrac{2\pi}{3} + 2\pi n\right)$.
Делим на 2: $x \in \left(\dfrac{\pi}{6} + \pi n;\, \dfrac{\pi}{3} + \pi n\right)$.
Ответ: $x \in \left(\dfrac{\pi}{6} + \pi n;\, \dfrac{\pi}{3} + \pi n\right)$, $n \in \mathbb{Z}$.
Пример 8. $\cos\left(x - \dfrac{\pi}{4}\right) \leq \dfrac{\sqrt{2}}{2}$.

Шаг 1. Замена $t = x - \dfrac{\pi}{4}$. $\cos t \leq \dfrac{\sqrt{2}}{2} \Rightarrow t \in \left[\dfrac{\pi}{4} + 2\pi n;\, \dfrac{7\pi}{4} + 2\pi n\right]$.
Шаг 2. Возврат. $x - \dfrac{\pi}{4} \in \left[\dfrac{\pi}{4} + 2\pi n;\, \dfrac{7\pi}{4} + 2\pi n\right]$.
$x \in \left[\dfrac{\pi}{2} + 2\pi n;\, 2\pi + 2\pi n\right]$.
Ответ: $x \in \left[\dfrac{\pi}{2} + 2\pi n;\, 2\pi + 2\pi n\right]$, $n \in \mathbb{Z}$.
⚠️ Типичные ошибки
ОшибкаПочему неверноКак правильно
В ответе пишут отдельные точки вместо дуг Неравенство — это множество решений, а не набор точек. Писать промежутки с периодом
Забывают про период Тригонометрические функции периодичны, без $2\pi n$ или $\pi n$ ответ неполный. У sin/cos — $2\pi n$, у tg/ctg — $\pi n$
Путают, где дуга «+», а где «−» Для $\sin$ — читаем выше/ниже прямой, для $\cos$ — правее/левее. Без круга легко перепутать. Всегда рисовать круг или линию тангенсов
Неверно ставят скобки (включён/не включён конец) Для строгих неравенств концы не входят (круглые скобки), для нестрогих — входят (квадратные). Строгие → ( ), нестрогие → [ ]
После замены $t = 2x$ забывают разделить на 2 Отвечаем в терминах $x$, а не $t$. Нужно вернуться к исходной переменной. Обязательный обратный переход
📋 Сводная таблица
$\sin x > a$ ($-1 < a < 1$): $x \in (\arcsin a + 2\pi n;\, \pi - \arcsin a + 2\pi n)$

$\sin x < a$ ($-1 < a < 1$): $x \in (-\pi - \arcsin a + 2\pi n;\, \arcsin a + 2\pi n)$

$\cos x > a$ ($-1 < a < 1$): $x \in (-\arccos a + 2\pi n;\, \arccos a + 2\pi n)$

$\cos x < a$ ($-1 < a < 1$): $x \in (\arccos a + 2\pi n;\, 2\pi - \arccos a + 2\pi n)$

$\tg x > a$: $x \in \left(\arctg a + \pi n;\, \dfrac{\pi}{2} + \pi n\right)$

$\tg x < a$: $x \in \left(-\dfrac{\pi}{2} + \pi n;\, \arctg a + \pi n\right)$

Важно: для нестрогих ($\geq$, $\leq$) скобки становятся квадратными. Для $\sin x > 1$ и $\sin x < -1$ решений нет.
