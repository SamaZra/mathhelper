🧩 Разложение на множители

📖 Что такое разложение на множители?

Разложение на множители — это метод, при котором многочлен представляется в виде произведения более простых выражений. Это позволяет решать уравнения, приравнивая каждый множитель к нулю.

🎯 Главная идея: Если уравнение можно представить как произведение = 0, то каждый множитель можно приравнять к нулю отдельно.
📋 Алгоритм
📌 Алгоритм разложения на множители Пошагово
  • Шаг 1. Перенести все члены уравнения в левую часть.
  • Шаг 2. Вынести общий множитель за скобку, если это возможно.
  • Шаг 3. Применить формулы сокращённого умножения, если возможно.
  • Шаг 4. Использовать группировку для сложных многочленов.
  • Шаг 5. Приравнять каждый множитель к нулю и решить полученные уравнения.
  • Шаг 6. Проверить корни по ОДЗ.
    • 📐 Пример 1. \(x^3 - 4x = 0\) вынесение общего множителя
    🔹 Шаг 1. Видим, что \(x\) есть в каждом члене.
    Выносим \(x\) за скобку: \(x(x^2 - 4) = 0\)
    🔹 Шаг 2. Применяем формулу разности квадратов
    \(x^2 - 4 = (x-2)(x+2)\)
    Получаем: \(x(x-2)(x+2) = 0\)
    🔹 Шаг 3. Приравниваем каждый множитель к нулю
    \(x = 0\) или \(x-2 = 0\) или \(x+2 = 0\)
    \(x = 0\) или \(x = 2\) или \(x = -2\)
    ✅ Ответ: \(x = -2,\; 0,\; 2\)
    💡 Вынесение общего множителя — самый простой вид разложения.
    📐 Пример 2. \(4x^2 - 9 = 0\) разность квадратов
    🔹 Шаг 1. Видим разность квадратов
    \(4x^2 - 9 = (2x)^2 - 3^2\)
    🔹 Шаг 2. Применяем формулу \(a^2 - b^2 = (a-b)(a+b)\)
    \((2x-3)(2x+3) = 0\)
    🔹 Шаг 3. Приравниваем каждый множитель к нулю
    \(2x-3 = 0\) → \(x = \frac{3}{2}\)
    \(2x+3 = 0\) → \(x = -\frac{3}{2}\)
    ✅ Ответ: \(x = \pm \frac{3}{2}\)
    💡 Формулы сокращённого умножения — это «кирпичики» для разложения.
    📐 Пример 3. \(x^2 - 5x + 6 = 0\) разложение квадратного трёхчлена
    🔹 Шаг 1. Находим корни квадратного трёхчлена
    \(x^2 - 5x + 6 = 0\)
    \(D = 25 - 24 = 1\)
    \(x_1 = \frac{5+1}{2} = 3\), \(x_2 = \frac{5-1}{2} = 2\)
    🔹 Шаг 2. Используем формулу \(ax^2+bx+c = a(x-x_1)(x-x_2)\)
    \(x^2 - 5x + 6 = (x-3)(x-2)\)
    🔹 Шаг 3. Приравниваем к нулю
    \((x-3)(x-2) = 0\)
    \(x = 3\) или \(x = 2\)
    ✅ Ответ: \(x = 2,\; 3\)
    💡 Любой квадратный трёхчлен можно разложить по корням.
    📐 Пример 4. \(x^3 + 2x^2 - x - 2 = 0\) группировка
    🔹 Шаг 1. Группируем члены
    \((x^3 + 2x^2) + (-x - 2) = 0\)
    🔹 Шаг 2. Выносим общие множители в каждой группе
    \(x^2(x+2) - 1(x+2) = 0\)
    🔹 Шаг 3. Выносим общий множитель \((x+2)\)
    \((x+2)(x^2 - 1) = 0\)
    🔹 Шаг 4. Раскладываем разность квадратов
    \((x+2)(x-1)(x+1) = 0\)
    🔹 Шаг 5. Приравниваем каждый множитель к нулю
    \(x = -2\), \(x = 1\), \(x = -1\)
    ✅ Ответ: \(x = -2,\; -1,\; 1\)
    💡 Группировка помогает разложить многочлены степени 3 и выше.
    📐 Пример 5. \(x^4 - 5x^2 + 4 = 0\) биквадратное уравнение через разложение
    🔹 Шаг 1. Замечаем, что это биквадратное уравнение
    Можно разложить как квадратное относительно \(x^2\):
    \((x^2)^2 - 5(x^2) + 4 = 0\)
    🔹 Шаг 2. Находим корни относительно \(t = x^2\)
    \(t^2 - 5t + 4 = 0\) → \((t-1)(t-4) = 0\)
    \(t = 1\) или \(t = 4\)
    🔹 Шаг 3. Возвращаемся к \(x\)
    \(x^2 = 1\) → \(x = \pm 1\)
    \(x^2 = 4\) → \(x = \pm 2\)
    ✅ Ответ: \(x = \pm 1,\; \pm 2\)
    💡 Разложение через замену \(t = x^2\) — частый приём в ЕГЭ.
    📐 Пример 6. \(\frac{x^2-4}{x-2} = 0\) разложение в дробном уравнении
    🔹 Шаг 1. Находим ОДЗ
    \(x \neq 2\)
    🔹 Шаг 2. Раскладываем числитель
    \(x^2 - 4 = (x-2)(x+2)\)
    🔹 Шаг 3. Сокращаем дробь (при \(x \neq 2\))
    \(\frac{(x-2)(x+2)}{x-2} = x+2\)
    🔹 Шаг 4. Решаем уравнение \(x+2 = 0\)
    \(x = -2\)
    🔹 Шаг 5. Проверяем ОДЗ
    💡 \(x = -2 \neq 2\) → подходит.
    ✅ Ответ: \(x = -2\)
    💡 В дробных уравнениях разложение помогает сократить и упростить.
    📌 Основные приёмы разложения
    🎯 Запомните эти приёмы:

    📌 Вынесение общего множителя: \(ab + ac = a(b+c)\)
    📌 Формулы сокращённого умножения:
      • \(a^2 - b^2 = (a-b)(a+b)\)
      • \(a^2 + 2ab + b^2 = (a+b)^2\)
      • \(a^2 - 2ab + b^2 = (a-b)^2\)
      • \(a^3 \pm b^3 = (a \pm b)(a^2 \mp ab + b^2)\)
    📌 Группировка: \(ab + ac + db + dc = (a+d)(b+c)\)
    📌 Разложение квадратного трёхчлена: \(ax^2+bx+c = a(x-x_1)(x-x_2)\)
    📌 Биквадратное: \(ax^4 + bx^2 + c = a(x^2 - x_1^2)(x^2 - x_2^2)\)
