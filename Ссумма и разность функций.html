Сумма и разность функций

📖 Теория: преобразование суммы в произведение

Формулы суммы и разности функций (или преобразование суммы в произведение) позволяют представить сумму или разность синусов или косинусов в виде произведения.

Они используются для:

  • Упрощения тригонометрических выражений
  • Вычисления значений функций
  • Решение тригонометрических уравнений (разложение на множители)

Вывод: Эти формулы получаются из формул сложения путём замены переменных:

\(\alpha = \dfrac{u+v}{2}\), \(\beta = \dfrac{u-v}{2}\). Тогда \(\sin u + \sin v = 2\sin\dfrac{u+v}{2}\cos\dfrac{u-v}{2}\).

🔗 См. также: Сумма и разность углов · Произведение функций

\(\sin\alpha + \sin\beta = 2\sin\dfrac{\alpha+\beta}{2}\cos\dfrac{\alpha-\beta}{2}\)

\(\sin\alpha - \sin\beta = 2\sin\dfrac{\alpha-\beta}{2}\cos\dfrac{\alpha+\beta}{2}\)

\(\cos\alpha + \cos\beta = 2\cos\dfrac{\alpha+\beta}{2}\cos\dfrac{\alpha-\beta}{2}\)

\(\cos\alpha - \cos\beta = -2\sin\dfrac{\alpha+\beta}{2}\sin\dfrac{\alpha-\beta}{2}\)

📝 Примеры применения

Пример 1. Преобразовать в произведение: \(\sin 40^\circ + \sin 20^\circ\).

Решение:

Используем формулу \(\sin\alpha + \sin\beta = 2\sin\dfrac{\alpha+\beta}{2}\cos\dfrac{\alpha-\beta}{2}\):

\(\sin 40^\circ + \sin 20^\circ = 2\sin\dfrac{40^\circ + 20^\circ}{2}\cos\dfrac{40^\circ - 20^\circ}{2} = 2\sin 30^\circ\cos 10^\circ =\)

\(= 2 \cdot \dfrac{1}{2} \cdot \cos 10^\circ = \cos 10^\circ\).

Ответ: \(\cos 10^\circ\).

Пример 2. Преобразовать в произведение: \(\cos 3\alpha - \cos 5\alpha\).

Решение:

Используем формулу \(\cos\alpha - \cos\beta = -2\sin\dfrac{\alpha+\beta}{2}\sin\dfrac{\alpha-\beta}{2}\):

\(\cos 3\alpha - \cos 5\alpha = -2\sin\dfrac{3\alpha + 5\alpha}{2}\sin\dfrac{3\alpha - 5\alpha}{2} =\)

\(= -2\sin 4\alpha\sin(-\alpha) = 2\sin 4\alpha\sin\alpha\).

Ответ: \(2\sin 4\alpha\sin\alpha\).

Пример 3. Упростить: \(\dfrac{\sin 70^\circ + \sin 10^\circ}{\cos 70^\circ + \cos 10^\circ}\).

Решение:

Используем формулы суммы синусов и суммы косинусов:

\(\sin 70^\circ + \sin 10^\circ = 2\sin 40^\circ\cos 30^\circ\)

\(\cos 70^\circ + \cos 10^\circ = 2\cos 40^\circ\cos 30^\circ\)

Делим: \(\dfrac{2\sin 40^\circ\cos 30^\circ}{2\cos 40^\circ\cos 30^\circ} = \dfrac{\sin 40^\circ}{\cos 40^\circ} = \tg 40^\circ\).

Ответ: \(\tg 40^\circ\).

Пример 4. Решить уравнение: \(\sin 5x + \sin 3x = 0\).

Решение:

Используем формулу суммы синусов:

\(\sin 5x + \sin 3x = 2\sin 4x\cos x = 0\)

\(\sin 4x = 0 \Rightarrow 4x = \pi n \Rightarrow x = \dfrac{\pi n}{4}\)

\(\cos x = 0 \Rightarrow x = \dfrac{\pi}{2} + \pi n\)

Ответ: \(x = \dfrac{\pi n}{4}\), \(x = \dfrac{\pi}{2} + \pi n\), \(n \in \mathbb{Z}\).
