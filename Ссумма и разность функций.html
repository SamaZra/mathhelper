Сумма и разность тригонометрических функций

📖 Зачем преобразовывать сумму в произведение

Этот раздел — «обратный» к предыдущему. Теперь мы заменяем сумму или разность двух тригонометрических функций произведением. Это бывает нужно, когда:

  • Нужно упростить выражение вида $\sin\alpha + \sin\beta$.
  • Нужно решить уравнение — произведение удобнее: если оно равно нулю, то каждый множитель равен нулю.
  • Нужно доказать тождество.

Все четыре формулы получаются из формул сложения заменой переменных: $\alpha = \dfrac{u+v}{2}$, $\beta = \dfrac{u-v}{2}$. После подстановки и сложения двух формул получаем готовые выражения.

💡 Главная идея: сумма — «плохо» (сложно решать). Произведение — «хорошо»: если произведение равно нулю, задача распадается на простые уравнения.
📐 Формулы суммы и разности

$\sin\alpha + \sin\beta = 2\sin\dfrac{\alpha+\beta}{2}\cos\dfrac{\alpha-\beta}{2}$

$\sin\alpha - \sin\beta = 2\sin\dfrac{\alpha-\beta}{2}\cos\dfrac{\alpha+\beta}{2}$

$\cos\alpha + \cos\beta = 2\cos\dfrac{\alpha+\beta}{2}\cos\dfrac{\alpha-\beta}{2}$

$\cos\alpha - \cos\beta = -2\sin\dfrac{\alpha+\beta}{2}\sin\dfrac{\alpha-\beta}{2}$

💡 Мнемоника:
• Синус + синус — «два синуса на косинус» (полусумма и полуразность).
• Косинус + косинус — «два косинуса на косинус».
• Косинус − косинус — «минус два синуса на синус».
• Синус − синус — как «синус + синус», но порядок «полуразность-полусумма».
📝 Примеры применения
Пример 1. Преобразовать в произведение: $\sin 40° + \sin 20°$.

Решение. По формуле $\sin\alpha + \sin\beta$:
$\sin 40° + \sin 20° = 2\sin\dfrac{40°+20°}{2}\cos\dfrac{40°-20°}{2} = 2\sin 30°\cos 10° = \cos 10°$.
💡 $\sin 30° = \dfrac{1}{2}$ — поэтому двойка сократилась.
Ответ: $\cos 10°$.
Пример 2. Преобразовать: $\cos 3\alpha - \cos 5\alpha$.

Решение. По формуле $\cos\alpha - \cos\beta = -2\sin\dfrac{\alpha+\beta}{2}\sin\dfrac{\alpha-\beta}{2}$:
$\cos 3\alpha - \cos 5\alpha = -2\sin 4\alpha \sin(- \alpha) = 2\sin 4\alpha \sin \alpha$.
💡 $\sin(-\alpha) = -\sin\alpha$ — два минуса дали плюс.
Ответ: $2\sin 4\alpha \sin\alpha$.
Пример 3 (упрощение дроби). Упростить: $\dfrac{\sin 70° + \sin 10°}{\cos 70° + \cos 10°}$.

Шаг 1. Числитель. $\sin 70° + \sin 10° = 2\sin 40° \cos 30°$.
Шаг 2. Знаменатель. $\cos 70° + \cos 10° = 2\cos 40° \cos 30°$.
Шаг 3. Делим. $\dfrac{2\sin 40° \cos 30°}{2\cos 40° \cos 30°} = \dfrac{\sin 40°}{\cos 40°} = \tg 40°$.
Ответ: $\tg 40°$.
Пример 4 (решение уравнения). Решить $\sin 5x + \sin 3x = 0$.

Шаг 1. Преобразуем в произведение. $\sin 5x + \sin 3x = 2\sin 4x \cos x = 0$.
Шаг 2. Произведение равно нулю. $\sin 4x = 0 \Rightarrow 4x = \pi n \Rightarrow x = \dfrac{\pi n}{4}$.
$\cos x = 0 \Rightarrow x = \dfrac{\pi}{2} + \pi n$.
💡 Вот в чём сила метода: уравнение распалось на два простых.
Ответ: $x = \dfrac{\pi n}{4}$ или $x = \dfrac{\pi}{2} + \pi n$, $n \in \mathbb{Z}$.
⚠️ На что обратить внимание
  • Минус в $\cos - \cos$. Формула начинается с минуса: $-2\sin \cdot \sin$. Частая ошибка — забыть этот минус.
  • Порядок в «полуразности». Всегда $\dfrac{\alpha-\beta}{2}$ (не наоборот), даже если это даёт отрицательный угол. Синус от отрицательного угла можно раскрыть по нечётности.
  • Произведение → сумма, потом сумма → произведение. Иногда для решения нужно дважды использовать эти формулы — сначала в одну сторону, потом в другую. Это нормально.
