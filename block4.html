Скалярное произведение векторов

Скалярное произведение
Определение: $\vec{a}\cdot\vec{b} = |\vec{a}|\cdot|\vec{b}|\cdot\cos\varphi$, где $\varphi = \angle(\vec{a},\vec{b})$
В координатах: $\vec{a}\{x_1,y_1,z_1\},\; \vec{b}\{x_2,y_2,z_2\}$ ⇒ $\vec{a}\cdot\vec{b} = x_1x_2 + y_1y_2 + z_1z_2$
Косинус угла и ортогональность
Косинус угла:

$\cos\varphi = \dfrac{\vec{a}\cdot\vec{b}}{|\vec{a}|\cdot|\vec{b}|}$

$\cos\varphi = \dfrac{x_1x_2 + y_1y_2 + z_1z_2}{\sqrt{x_1^2+y_1^2+z_1^2}\;\sqrt{x_2^2+y_2^2+z_2^2}}$
Условие ортогональности: $\vec{a} \perp \vec{b} \;\Longleftrightarrow\; \vec{a}\cdot\vec{b} = 0$

Знак скалярного произведения определяет вид угла между векторами:

$\vec{a}\cdot\vec{b} > 0 \;\Rightarrow\;$ угол острый ($\varphi < 90^\circ$)

$\vec{a}\cdot\vec{b} = 0 \;\Rightarrow\;$ угол прямой ($\varphi = 90^\circ$)

$\vec{a}\cdot\vec{b} < 0 \;\Rightarrow\;$ угол тупой ($\varphi > 90^\circ$)
Примеры
Пример 1 (ортогональны):

Даны векторы: $\vec{m}\{1,2,2\}$, $\vec{n}\{2,1,-2\}$

Вычисляем скалярное произведение:
$\vec{m}\cdot\vec{n} = 1·2+2·1+2·(-2)=2+2-4=0$

Так как $\vec{m}\cdot\vec{n}=0$, векторы ортогональны: $\vec{m}\perp\vec{n}$, $\varphi=90^\circ$
Пример 2 (острый угол):

Даны векторы: $\vec{u}\{3,0,4\}$, $\vec{v}\{1,2,2\}$

Вычисляем скалярное произведение:
$\vec{u}\cdot\vec{v}=3·1+0·2+4·2=11$

Находим модули векторов:
$|\vec{u}|=\sqrt{3^2+0^2+4^2}=5$
$|\vec{v}|=\sqrt{1^2+2^2+2^2}=3$

Вычисляем косинус угла:
$\cos\varphi = \dfrac{11}{5·3} = \dfrac{11}{15} \approx 0.7333$

$\varphi \approx 42.8^\circ$ — острый угол
Решение задач (3D)

Задача 1. Найдите угол между векторами $\vec{u}\{3,0,4\}$ и $\vec{v}\{1,2,2\}$.

Решение:
$\vec{u}\cdot\vec{v} = 3\cdot1 + 0\cdot2 + 4\cdot2 = 11$
$|\vec{u}| = \sqrt{9+0+16} = 5$,   $|\vec{v}| = \sqrt{1+4+4} = 3$

$\cos\varphi = \dfrac{11}{5\cdot3} = \dfrac{11}{15} \approx 0{,}733$
$\varphi \approx 42{,}8^\circ$

Так как $\vec{u}\cdot\vec{v} > 0$, угол острый.

Задача 2. При каком $x$ векторы $\vec{a}\{x,2,3\}$ и $\vec{b}\{1,-1,1\}$ ортогональны?

Решение:
Условие ортогональности: $\vec{a}\cdot\vec{b} = 0$.

$x\cdot1 + 2\cdot(-1) + 3\cdot1 = 0$
$x - 2 + 3 = 0$
$x = -1$

Ответ: при $x = -1$: $\vec{a}\{-1,2,3\}$, $\vec{b}\{1,-1,1\}$, $\vec{a}\cdot\vec{b} = -1-2+3 = 0$, угол $90^\circ$.

Задача 3. Даны точки $A(1,2,3)$, $B(3,0,1)$, $C(2,1,0)$. Найдите угол $\angle BAC$.

Решение:
$\overrightarrow{AB} = \{3-1,\; 0-2,\; 1-3\} = \{2,\; -2,\; -2\}$
$\overrightarrow{AC} = \{2-1,\; 1-2,\; 0-3\} = \{1,\; -1,\; -3\}$

$\overrightarrow{AB}\cdot\overrightarrow{AC} = 2\cdot1 + (-2)\cdot(-1) + (-2)\cdot(-3) = 2+2+6 = 10$

$|\overrightarrow{AB}| = \sqrt{4+4+4} = 2\sqrt3$
$|\overrightarrow{AC}| = \sqrt{1+1+9} = \sqrt{11}$

$\cos\varphi = \dfrac{10}{2\sqrt3 \cdot \sqrt{11}} = \dfrac{10}{2\sqrt{33}} = \dfrac{5}{\sqrt{33}} \approx 0{,}870$

Ответ: $\varphi = \angle BAC \approx 29{,}5^\circ$.

Задача 4. Найдите скалярное произведение векторов $\vec{a}\{2,-1,3\}$ и $\vec{b}\{1,4,-2\}$. Определите вид угла между ними.

Решение:
$\vec{a}\cdot\vec{b} = 2\cdot1 + (-1)\cdot4 + 3\cdot(-2) = 2 - 4 - 6 = -8$

Так как $\vec{a}\cdot\vec{b} < 0$, угол между векторами — тупой ($\varphi > 90^\circ$).

Для справки: $|\vec{a}| = \sqrt{14}$, $|\vec{b}| = \sqrt{21}$, $\cos\varphi = -\dfrac{8}{\sqrt{294}} \approx -0{,}467$, $\varphi \approx 117{,}8^\circ$.

Задача 5. Даны векторы $\vec{a}\{2,-1,2\}$ и $\vec{b}\{1,2,-2\}$. Найдите проекцию вектора $\vec{a}$ на направление вектора $\vec{b}$.

Напоминание. Проекция вектора $\vec{a}$ на вектор $\vec{b}$:

$\text{пр}_{\vec{b}}\,\vec{a} = \dfrac{\vec{a}\cdot\vec{b}}{|\vec{b}|}$

Решение:
$\vec{a}\cdot\vec{b} = 2\cdot1 + (-1)\cdot2 + 2\cdot(-2) = 2 - 2 - 4 = -4$
$|\vec{b}| = \sqrt{1+4+4} = 3$

$\text{пр}_{\vec{b}}\,\vec{a} = \dfrac{-4}{3} \approx -1{,}333$

Знак минус означает, что проекция направлена противоположно вектору $\vec{b}$.
Шпаргалка:
$\vec{a}\cdot\vec{b} = x_1x_2+y_1y_2+z_1z_2$
$\cos\varphi = \dfrac{\vec{a}\cdot\vec{b}}{|\vec{a}||\vec{b}|}$
$\vec{a}\perp\vec{b} \Leftrightarrow \vec{a}\cdot\vec{b}=0$
$\text{пр}_{\vec{b}}\,\vec{a} = \dfrac{\vec{a}\cdot\vec{b}}{|\vec{b}|}$
