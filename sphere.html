Сфера / Шар

📐 3D-модель сферы
🟠 Радиус (R) = OA 🔵 Диаметр (D) = AB

Интерактивная модель: вращайте и масштабируйте. Красные линии — меридиан и параллель (экватор).

📖 Определение
  • Сфера — поверхность всех точек пространства на расстоянии \(R\) от центра.
  • Шар — тело, ограниченное сферой.
  • Шар — тело вращения полукруга вокруг диаметра.
🔷 Элементы
  • Центр O, радиус \(R = OA\), диаметр \(D = AB = 2R\)
  • Поверхность — сфера, объём — шар
📌 Взаимное расположение сферы и плоскости
  • \(d < R\) — сечение по окружности радиуса \(r = \sqrt{R^2 - d^2}\).
  • \(d = R\) — касание.
  • \(d > R\) — нет общих точек.
🟠 Радиус сферы R 🔴 Расстояние до плоскости d 🔵 Радиус сечения r = √(R²−d²)
📏 Расстояние от центра до плоскости: 0.70·R 📐 Радиус сечения: 0.857·R
📊 d < R — плоскость пересекает сферу, сечение — окружность

💡 Вращайте сцену мышью (или пальцем). Плоскость (бирюзовая с рамкой) пересекает сферу — образуется синяя окружность.

🧮 Формулы
\[ S_{\text{сферы}} = 4\pi R^{2} = \pi D^{2} \]
\[ V_{\text{шара}} = \frac{4}{3}\pi R^{3} = \frac{1}{6}\pi D^{3} \]

Взаимное расположение двух сфер:

  • Не пересекаются: расстояние между центрами \( d > R_1 + R_2 \) или \( d < |R_1 - R_2| \).
  • Касаются внешне: расстояние между центрами \( d = R_1 + R_2 \).
  • Касаются внутренне: расстояние между центрами \( d = |R_1 - R_2| \).
  • Пересекаются по окружности: \( |R_1 - R_2| < d < R_1 + R_2 \).
Шаровой сегмент, сектор, слой
ШАРОВОЙ СЕГМЕНТ
⚪ Шар 🟠 Сегмент
• Объём: \(V = \pi h^2\left(R - \frac{h}{3}\right)\)
• Площадь сферической поверхности: \(S = 2\pi R h\)
• Полная поверхность (с основанием): \(S_{\text{полн}} = \pi(2Rh + r^2)\), где \(r = \sqrt{h(2R-h)}\)
ШАРОВОЙ СЕКТОР
⚪ Шар 🟠 Сектор (конус + сегмент)
• Объём: \(V = \frac{2}{3}\pi R^2 h\)
• Площадь полной поверхности: \(S = \pi R(2h + r)\)
ШАРОВОЙ СЛОЙ
⚪ Сферический пояс 🟠 Шаровой слой
• Объём: \(V = \frac{\pi h}{6}\left(3r_1^2 + 3r_2^2 + h^2\right)\)
• Площадь сферической поверхности: \(S = 2\pi R h\)
• Высота слоя \(h\), радиусы оснований \(r_1, r_2\)
📐 Уравнение сферы
\[ (x - x_0)^2 + (y - y_0)^2 + (z - z_0)^2 = R^2 \]

Где что находится:

  • \( x, y, z \) — координаты любой точки, принадлежащей сфере.
  • \( x_0, y_0, z_0 \) — координаты центра сферы (точки \(O\)).
  • \( R \) — радиус сферы (расстояние от центра до любой точки сферы).

Если центр сферы находится в начале координат (, то есть \( x_0 = 0, y_0 = 0, z_0 = 0 \)), то уравнение принимает вид:

\[ x^2 + y^2 + z^2 = R^2 \]
📋 Свойства
  • Любое сечение шара плоскостью — круг.
  • Касательная плоскость ⟂ радиусу в точке касания.
  • Сфера имеет наименьшую площадь среди тел заданного объёма.
📝 Задачи с решениями
📘 Задача №1. Сечение сферы
Условие: Радиус сферы \(R = 13\) см. Плоскость пересекает сферу на расстоянии \(d = 5\) см от центра. Найдите радиус окружности сечения \(r\).
Дано:
\(R = 13\) см,
\(d = 5\) см.
Найти: \(r\).
Решение:
1. Сечение сферы плоскостью — это окружность. Радиус этой окружности \(r\), расстояние от центра до плоскости \(d\) и радиус сферы \(R\) образуют прямоугольный треугольник.
2. По теореме Пифагора: \(R^2 = r^2 + d^2\).
3. Выразим радиус сечения: \(r = \sqrt{R^2 - d^2}\).
4. Подставим значения: \(r = \sqrt{13^2 - 5^2} = \sqrt{169 - 25} = \sqrt{144} = 12\) см.
✅ Ответ: \(r = 12\) см.
📘 Задача №2. Уравнение сферы
Условие: Запишите уравнение сферы, если известны координаты её центра \( O(-1; 2; 3) \) и координаты точки \( A(2; -1; 3) \), которая лежит на этой сфере.
Дано:
Центр \( O(-1; 2; 3) \),
Точка на сфере \( A(2; -1; 3) \).
Найти: Уравнение сферы.
Решение:
1. Найдём радиус сферы \( R \) как расстояние от центра \( O \) до точки \( A \):
\( R = \sqrt{(x_A - x_O)^2 + (y_A - y_O)^2 + (z_A - z_O)^2} \).
2. Подставим координаты: \( R = \sqrt{(2 - (-1))^2 + (-1 - 2)^2 + (3 - 3)^2} = \sqrt{3^2 + (-3)^2 + 0^2} = \sqrt{18} \).
3. Значит, \( R^2 = 18 \).
4. Общее уравнение сферы: \( (x - x_0)^2 + (y - y_0)^2 + (z - z_0)^2 = R^2 \).
5. Подставим координаты центра и \( R^2 \): \( (x - (-1))^2 + (y - 2)^2 + (z - 3)^2 = 18 \).
✅ Ответ: \( (x + 1)^2 + (y - 2)^2 + (z - 3)^2 = 18 \)
📘 Задача №3. Взаимное расположение сфер
Условие: Две сферы с радиусами \(R_1 = 5\) см и \(R_2 = 8\) см касаются внешне. Найдите расстояние между их центрами. А если бы они касались внутренне?
Дано:
\(R_1 = 5\) см,
\(R_2 = 8\) см.
Найти: \(d_{внеш}\) и \(d_{внутр}\).
Решение:
1. Внешнее касание: Расстояние между центрами равно сумме радиусов.
\(d_{внеш} = R_1 + R_2 = 5 + 8 = 13\) см.
2. Внутреннее касание: Расстояние между центрами равно разности радиусов.
\(d_{внутр} = |R_2 - R_1| = |8 - 5| = 3\) см.
✅ Ответ: \(d_{внеш} = 13\) см, \(d_{внутр} = 3\) см.
📘 Задача №4. Площадь сечения и объём
Условие: В шаре на расстоянии \(d = 8\) см от центра проведено сечение, площадь которого равна \(36\pi\) см². Найдите радиус шара и его объём.
Дано:
\(d = 8\) см,
\(S_{сеч} = 36\pi\) см².
Найти: \(R\) и \(V\).
Решение:
1. Площадь сечения (круга) равна \(S = \pi r^2\). Отсюда найдём радиус сечения \(r\):
\(36\pi = \pi r^2 \Rightarrow r^2 = 36 \Rightarrow r = 6\) см.
2. По теореме Пифагора найдём радиус шара \(R\):
\(R^2 = d^2 + r^2 = 8^2 + 6^2 = 64 + 36 = 100 \Rightarrow R = 10\) см.
3. Найдём объём шара:
\(V = \frac{4}{3}\pi R^3 = \frac{4}{3}\pi \cdot 10^3 = \frac{4000\pi}{3}\) см³.
✅ Ответ: \(R = 10\) см, \(V = \frac{4000\pi}{3}\) см³.
