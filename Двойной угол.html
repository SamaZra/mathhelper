Двойной аргумент

📖 Теория: формулы двойного аргумента

Формулы двойного аргумента — это частный случай формул сложения, когда \(\alpha = \beta\).

Вывод из формул сложения:

  • \(\sin 2\alpha = \sin(\alpha + \alpha) = 2\sin\alpha\cos\alpha\)
  • \(\cos 2\alpha = \cos(\alpha + \alpha) = \cos^2\alpha - \sin^2\alpha\)
  • \(\tg 2\alpha = \tg(\alpha + \alpha) = \dfrac{2\tg\alpha}{1 - \tg^2\alpha}\)

Они широко используются для:

  • Упрощения тригонометрических выражений
  • Решение тригонометрических уравнений
  • Вычисления значений функций
  • Интегрирования

\(\sin 2\alpha = 2\sin\alpha\cos\alpha\)

\(\cos 2\alpha = \cos^2\alpha - \sin^2\alpha\)

\(\cos 2\alpha = 2\cos^2\alpha - 1\)

\(\cos 2\alpha = 1 - 2\sin^2\alpha\)

\(\tg 2\alpha = \dfrac{2\tg\alpha}{1 - \tg^2\alpha}\)

\(\ctg 2\alpha = \dfrac{\ctg^2\alpha - 1}{2\ctg\alpha}\)

🔗 Связь с половинным аргументом:

Из формул двойного аргумента можно получить формулы половинного аргумента:

  • \(\sin^2\dfrac{\alpha}{2} = \dfrac{1 - \cos\alpha}{2}\)
  • \(\cos^2\dfrac{\alpha}{2} = \dfrac{1 + \cos\alpha}{2}\)
  • \(\tg\dfrac{\alpha}{2} = \dfrac{1 - \cos\alpha}{\sin\alpha} = \dfrac{\sin\alpha}{1 + \cos\alpha}\)

Подробнее см. раздел Половинный аргумент.

📝 Примеры применения

Пример 1. Вычислить \(\sin 2\alpha\), если \(\sin\alpha = \dfrac{3}{5}\) и \(\alpha \in (0^\circ, 90^\circ)\).

Решение:

Найдём \(\cos\alpha\) из основного тождества:

\(\cos\alpha = \sqrt{1 - \sin^2\alpha}\)

\(= \sqrt{1 - \dfrac{9}{25}} = \sqrt{\dfrac{16}{25}} = \dfrac{4}{5}\).

Используем формулу \(\sin 2\alpha = 2\sin\alpha\cos\alpha\):

\(\sin 2\alpha = 2 \cdot \dfrac{3}{5} \cdot \dfrac{4}{5} = \dfrac{24}{25}\).

Ответ: \(\dfrac{24}{25}\).

Пример 2. Упростить: \(\dfrac{\sin 2\alpha}{\sin\alpha}\).

Решение:

Используем формулу \(\sin 2\alpha = 2\sin\alpha\cos\alpha\):

\(\dfrac{\sin 2\alpha}{\sin\alpha} = \dfrac{2\sin\alpha\cos\alpha}{\sin\alpha} = 2\cos\alpha\).

Ответ: \(2\cos\alpha\).

Пример 3. Выразить \(\cos 2\alpha\) через \(\sin\alpha\).

Решение:

Используем формулу \(\cos 2\alpha = 1 - 2\sin^2\alpha\):

\(\cos 2\alpha = 1 - 2\sin^2\alpha\).

Ответ: \(\cos 2\alpha = 1 - 2\sin^2\alpha\).

Пример 4. Вычислить \(\cos 2\alpha\), если \(\cos\alpha = \dfrac{5}{13}\) и \(\alpha \in (0^\circ, 90^\circ)\).

Решение:

Используем формулу \(\cos 2\alpha = 2\cos^2\alpha - 1\):

\(\cos 2\alpha = 2 \cdot \left(\dfrac{5}{13}\right)^2 - 1\)

\(= 2 \cdot \dfrac{25}{169} - 1 = \dfrac{50}{169} - 1 = -\dfrac{119}{169}\).

Ответ: \(-\dfrac{119}{169}\).

Пример 5. Упростить: \(\dfrac{1 - \cos 2\alpha}{\sin 2\alpha}\).

Решение:

Используем формулы \(\cos 2\alpha = 1 - 2\sin^2\alpha\) и \(\sin 2\alpha = 2\sin\alpha\cos\alpha\):

\(\dfrac{1 - \cos 2\alpha}{\sin 2\alpha} = \dfrac{1 - (1 - 2\sin^2\alpha)}{2\sin\alpha\cos\alpha}\)

\(= \dfrac{2\sin^2\alpha}{2\sin\alpha\cos\alpha} = \dfrac{\sin\alpha}{\cos\alpha} = \tg\alpha\).

Ответ: \(\tg\alpha\).

Пример 6. Вычислить \(\tg 2\alpha\), если \(\tg\alpha = 2\).

Решение:

Используем формулу \(\tg 2\alpha = \dfrac{2\tg\alpha}{1 - \tg^2\alpha}\):

\(\tg 2\alpha = \dfrac{2 \cdot 2}{1 - 2^2} = \dfrac{4}{1 - 4} = -\dfrac{4}{3}\).

Ответ: \(-\dfrac{4}{3}\).

Пример 7. Вычислить \(\ctg 2\alpha\), если \(\ctg\alpha = 3\).

Решение:

Используем формулу \(\ctg 2\alpha = \dfrac{\ctg^2\alpha - 1}{2\ctg\alpha}\):

\(\ctg 2\alpha = \dfrac{3^2 - 1}{2 \cdot 3} = \dfrac{9 - 1}{6} = \dfrac{4}{3}\).

Ответ: \(\dfrac{4}{3}\).

Пример 8. Выразить \(\sin 2\alpha\) через \(\tg\alpha\).

Решение:

Используем формулы:

\(\sin 2\alpha = 2\sin\alpha\cos\alpha = \dfrac{2\tg\alpha}{1 + \tg^2\alpha}\).

💡 Вывод: \(\sin\alpha = \dfrac{\tg\alpha}{\sqrt{1+\tg^2\alpha}}\), \(\cos\alpha = \dfrac{1}{\sqrt{1+\tg^2\alpha}}\) → \(\sin 2\alpha = \dfrac{2\tg\alpha}{1+\tg^2\alpha}\).

Ответ: \(\sin 2\alpha = \dfrac{2\tg\alpha}{1 + \tg^2\alpha}\).
