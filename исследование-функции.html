📐 Исследование функции с помощью производной

📖 Алгоритм исследования функции
  1. Найти область определения \(D(f)\).

    Исключаем точки, где знаменатель равен нулю, подкоренное выражение отрицательно.

  2. Найти производную \(f'(x)\).

    Используем таблицу производных и правила дифференцирования.

  3. Найти критические точки: \(f'(x) = 0\) или \(f'(x)\) не существует.

    Решаем уравнение, находим точки, принадлежащие области определения.

  4. Определить промежутки возрастания и убывания.

    Метод интервалов: если \(f'(x) > 0\) — возрастает, если \(f'(x) < 0\) — убывает.

  5. Найти точки экстремума и значения функции в них.

    Смена знака с «+» на «−» — максимум, с «−» на «+» — минимум.

  6. Найти точки пересечения с осями координат.

    С осью \(Oy\): \(x = 0\). С осью \(Ox\): \(f(x) = 0\).

  7. Построить график функции.

    На основе полученных данных строим эскиз графика.

📌 Область определения \(D(f)\)
🔹 Многочлены — \(D(f)=\mathbb{R}\)
Пример: \(f(x)=x^3-3x\), \(D=(-\infty;+\infty)\)
🔹 Дроби \(\frac{P(x)}{Q(x)}\) — \(Q(x)\neq0\)
Пример: \(f(x)=\frac{1}{x}\), \(x\neq0\) → \(D=(-\infty;0)\cup(0;+\infty)\)
🔹 Корни чётной степени \(\sqrt[2n]{g(x)}\) — \(g(x)\geq0\)
Пример: \(f(x)=\sqrt{x}\), \(x\geq0\) → \(D=[0;+\infty)\)
🔹 Логарифмы \(\log_a g(x)\) — \(g(x)>0\)
Пример: \(f(x)=\ln x\), \(x>0\) → \(D=(0;+\infty)\)
🔹 Тригонометрические — \(\sin x,\cos x\): \(\mathbb{R}\); \(\tan x\): \(x\neq\frac{\pi}{2}+\pi k\)
Пример: \(f(x)=\tan x\), \(x\neq\frac{\pi}{2}+\pi k\)
🔹 Комбинации — пересечение областей всех частей
Пример: \(f(x)=\frac{\sqrt{x}}{x-1}\) → \(x\geq0\), \(x\neq1\) → \(D=[0;1)\cup(1;+\infty)\)
🔹 Показательные \(a^x\) — \(D(f)=\mathbb{R}\) (при \(a>0, a\neq1\))
Пример: \(f(x)=2^x\), \(D=\mathbb{R}\)
📖 Пример 1: \(f(x)=x^3-3x\)
🔹 1. Область определения \(D(f)\)
\(f(x)=x^3-3x\) — это многочлен.
💡 Многочлен — это выражение вида \(a_nx^n+a_{n-1}x^{n-1}+...+a_0\). Его можно вычислить при любом значении \(x\).
\(D(f)=\mathbb{R}=(-\infty;+\infty)\)

🔹 2. Производная \(f'(x)\)
\(f'(x)=(x^3)'-(3x)'\)
💡 Используем правило: \((x^n)'=n\cdot x^{n-1}\). Для \(x^3\): \(3x^{2}\). Для \(3x\): \(3\cdot1\cdot x^0=3\).
\(f'(x)=3x^2-3=3(x^2-1)\)

🔹 3. Критические точки
\(f'(x)=0\) → \(3x^2-3=0\) → \(3(x^2-1)=0\) → \(x^2=1\)
\(x=-1\) и \(x=1\)
💡 Критические точки — это точки, где производная равна нулю или не существует. Здесь она существует везде, так как это многочлен.
Обе точки принадлежат области определения.

🔹 4. Метод интервалов
💡 Метод интервалов: разбиваем числовую прямую критическими точками и определяем знак производной на каждом промежутке.
🔹 5. Промежутки монотонности
💡 Если \(f'(x)>0\) — функция возрастает (график идёт вверх). Если \(f'(x)<0\) — убывает (график идёт вниз).
\((-\infty;-1)\): \(f'(x)>0\) → возрастает ↗
\((-1;1)\): \(f'(x)<0\) → убывает ↘
\((1;+\infty)\): \(f'(x)>0\) → возрастает ↗

🔹 6. Точки экстремума
💡 Если производная меняет знак с \(+\) на \(-\), это максимум (вершина горки). Если с \(-\) на \(+\), это минимум (дно ямки).
\(x=-1\): \(+\) → \(-\) → максимум
\(f(-1)=(-1)^3-3(-1)=-1+3=2\) → \((-1;2)\)
\(x=1\): \(-\) → \(+\) → минимум
\(f(1)=1^3-3\cdot1=1-3=-2\) → \((1;-2)\)

🔹 7. Точки пересечения с осями
💡 С осью \(Oy\): подставляем \(x=0\). С осью \(Ox\): решаем \(f(x)=0\).
\(Oy\): \(f(0)=0\) → \((0;0)\)
\(Ox\): \(x^3-3x=0\) → \(x(x^2-3)=0\) → \(x=0,\;\pm\sqrt{3}\)
\((-\sqrt{3};0)\), \((0;0)\), \((\sqrt{3};0)\)

✅ Ответ: максимум \((-1;2)\), минимум \((1;-2)\).
📖 Пример 2: \(f(x)=x+\frac{1}{x}\)
🔹 1. Область определения \(D(f)\)
\(f(x)=x+\frac{1}{x}\) — есть дробь \(\frac{1}{x}\).
💡 Знаменатель дроби НЕ может быть равен нулю! На ноль делить нельзя.
\(x\neq0\)
\(D(f)=(-\infty;0)\cup(0;+\infty)\)

🔹 2. Производная \(f'(x)\)
\(f'(x)=1-\frac{1}{x^2}\)
💡 Производная \(x\) равна \(1\). Производная \(\frac{1}{x}=x^{-1}\) равна \(-x^{-2}=-\frac{1}{x^2}\).
\(f'(x)=\frac{x^2-1}{x^2}=\frac{(x-1)(x+1)}{x^2}\)

🔹 3. Критические точки
\(f'(x)=0\) → \(\frac{x^2-1}{x^2}=0\) → \(x^2-1=0\) → \(x=\pm1\)
\(x=-1\) и \(x=1\)
💡 Точка \(x=0\) не входит в область определения — там вертикальная асимптота (график уходит в бесконечность).

🔹 4. Метод интервалов
🔹 5. Промежутки монотонности
\((-\infty;-1)\): \(f'(x)>0\) → возрастает ↗
\((-1;0)\): \(f'(x)<0\) → убывает ↘
\((0;1)\): \(f'(x)<0\) → убывает ↘
\((1;+\infty)\): \(f'(x)>0\) → возрастает ↗

🔹 6. Точки экстремума
\(x=-1\): \(+\) → \(-\) → максимум
\(f(-1)=-1+\frac{1}{-1}=-1-1=-2\) → \((-1;-2)\)
\(x=1\): \(-\) → \(+\) → минимум
\(f(1)=1+\frac{1}{1}=2\) → \((1;2)\)

🔹 7. Точки пересечения с осями
\(Oy\): \(x=0\) не входит в ОДЗ → вертикальная асимптота \(x=0\)
\(Ox\): \(x+\frac{1}{x}=0\) → \(x^2+1=0\) → корней нет
💡 Дискриминант отрицательный, значит график НЕ пересекает ось \(Ox\).

✅ Ответ: максимум \((-1;-2)\), минимум \((1;2)\).
📖 Пример 3: \(f(x)=\sin x\)
🔹 1. Область определения \(D(f)\)
\(f(x)=\sin x\) — тригонометрическая функция.
💡 Синус определён при любом значении \(x\). Его можно посчитать для любого числа.
\(D(f)=\mathbb{R}=(-\infty;+\infty)\)

🔹 2. Производная \(f'(x)\)
💡 Производная синуса — это косинус: \((\sin x)'=\cos x\). Это табличная формула.
\(f'(x)=\cos x\)

🔹 3. Критические точки
\(\cos x=0\) → \(x=\frac{\pi}{2}+\pi k,\;k\in\mathbb{Z}\)
💡 Косинус равен нулю в точках \(\frac{\pi}{2}\), \(\frac{3\pi}{2}\), \(-\frac{\pi}{2}\) и так далее (каждые \(\pi\) радиан).
Для наглядности рассмотрим отрезок \([-\pi;\pi]\).

🔹 4. Метод интервалов (на \([-\pi;\pi]\))
🔹 5. Промежутки монотонности (на \([-\pi;\pi]\))
💡 \(\cos x>0\) — синус возрастает. \(\cos x<0\) — синус убывает.
\((-\pi;-\frac{\pi}{2})\): \(\cos x<0\) → убывает ↘
\((-\frac{\pi}{2};\frac{\pi}{2})\): \(\cos x>0\) → возрастает ↗
\((\frac{\pi}{2};\pi)\): \(\cos x<0\) → убывает ↘

🔹 6. Точки экстремума (на \([-\pi;\pi]\))
\(x=-\frac{\pi}{2}\): \(-\) → \(+\) → минимум
\(\sin(-\frac{\pi}{2})=-1\) → \((-\frac{\pi}{2};-1)\)
\(x=\frac{\pi}{2}\): \(+\) → \(-\) → максимум
\(\sin(\frac{\pi}{2})=1\) → \((\frac{\pi}{2};1)\)

🔹 7. Точки пересечения с осями
\(Oy\): \(\sin0=0\) → \((0;0)\)
\(Ox\): \(\sin x=0\) → \(x=\pi k,\;k\in\mathbb{Z}\)
💡 Синус равен нулю в точках \(0\), \(\pm\pi\), \(\pm2\pi\) и так далее.

✅ Ответ: минимумы \((-\frac{\pi}{2}+2\pi k;-1)\), максимумы \((\frac{\pi}{2}+2\pi k;1)\).
⚠️ Пример 4: \(f(x)=x^3\) — нет экстремума!
⚠️ ВАЖНО! Если производная равна нулю в точке, это НЕ ОБЯЗАТЕЛЬНО означает экстремум! Там может быть точка перегиба.
🔹 1. Область определения \(D(f)\)
\(f(x)=x^3\) — многочлен.
\(D(f)=\mathbb{R}=(-\infty;+\infty)\)

🔹 2. Производная \(f'(x)\)
\(f'(x)=3x^2\)
💡 Правило: \((x^3)'=3x^2\).

🔹 3. Критические точки
\(3x^2=0\) → \(x=0\)
💡 Квадрат числа может быть равен нулю только если само число равно нулю.
\(x=0\)

🔹 4. Метод интервалов
🔹 5. Промежутки монотонности
\((-\infty;0)\): \(3x^2>0\) → возрастает ↗
\((0;+\infty)\): \(3x^2>0\) → возрастает ↗
💡 \(x^2\) всегда положителен (кроме \(x=0\), где он равен нулю). Поэтому производная везде ≥0.

🔹 6. Смена знака производной
Слева от \(x=0\): \(f'(x)>0\)
Справа от \(x=0\): \(f'(x)>0\)
Знак НЕ меняется: \(+\) → \(+\)
💡 Для экстремума нужно, чтобы знак МЕНЯЛСЯ. Здесь он не меняется, значит экстремума нет!
⚠️ Это точка перегиба, а не экстремум!

🔹 7. Точки пересечения с осями
\(f(0)=0\) → \((0;0)\)

✅ Ответ: экстремумов нет, \(x=0\) — точка перегиба.
⭐ Пример 5: задача с параметром (ЕГЭ)
🔹 Условие задачи
При каких значениях параметра \(a\) функция
\(f(x)=x^3-3ax^2+3x\)
возрастает на всей области определения?

🔹 1. Область определения
\(f(x)=x^3-3ax^2+3x\) — это многочлен.
\(D(f)=\mathbb{R}=(-\infty;+\infty)\)
💡 Многочлен определён при любых \(x\), независимо от \(a\).

🔹 2. Производная
\(f'(x)=3x^2-6ax+3=3(x^2-2ax+1)\)
💡 Производная \(x^3\) → \(3x^2\). Производная \(-3ax^2\) → \(-6ax\). Производная \(3x\) → \(3\).

🔹 3. Условие возрастания
💡 Чтобы функция возрастала на всей области определения, нужно чтобы \(f'(x)\geq0\) для всех \(x\).
\(x^2-2ax+1\geq0\) для всех \(x\).

🔹 4. Квадратный трёхчлен
💡 Квадратный трёхчлен \(x^2-2ax+1\) неотрицателен при всех \(x\), если его дискриминант ≤ 0 (ветви параболы направлены вверх).
\(D=(-2a)^2-4\cdot1\cdot1=4a^2-4=4(a^2-1)\)
\(4(a^2-1)\leq0\) → \(a^2-1\leq0\) → \(-1\leq a\leq1\)
💡 Если \(a\) находится в этом промежутке, парабола либо касается оси \(Ox\), либо находится выше неё.

✅ Ответ: \(a\in[-1;1]\).
