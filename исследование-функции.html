📐 Исследование функции с помощью производной

Алгоритм · Примеры · Графики
📖 Зачем исследовать функцию от трамплинов до прибыли компании

Представь трамплин для лыжников: сначала подъём, потом спуск, потом снова подъём. Вершина трамплина — это максимум, низина — минимум. А ещё есть места, где меняется выпуклость — как перегиб дороги.

Производная — это «универсальный компас», который показывает, куда движется функция: вверх, вниз или меняет направление. А вторая производная подсказывает, как именно кривая выгибается.

💡 Главная идея: полное исследование функции — это последовательность из 9 шагов, где каждый шаг опирается на предыдущий: ОДЗ → производная → критические точки → знаки → экстремумы → вторая производная → асимптоты → точки пересечения → график.
📖 Алгоритм исследования функции 9 шагов от ОДЗ до графика
1️⃣ Найти область определения \(D(f)\) Исключаем точки, где знаменатель равен нулю, подкоренное выражение отрицательно. 2️⃣ Найти производную \(f'(x)\) Используем таблицу производных и правила дифференцирования. 3️⃣ Найти критические точки: \(f'(x) = 0\) или не существует Решаем уравнение, находим точки, принадлежащие области определения. 4️⃣ Определить промежутки возрастания и убывания Метод интервалов: если \(f'(x) > 0\) — возрастает, если \(f'(x) < 0\) — убывает. 5️⃣ Найти точки экстремума и значения функции в них Смена знака с «+» на «−» — максимум, с «−» на «+» — минимум. 6️⃣ Найти вторую производную \(f''(x)\) Определить промежутки выпуклости и точки перегиба. 7️⃣ Найти асимптоты Вертикальные — через ОДЗ, горизонтальные и наклонные — по степеням. 8️⃣ Найти точки пересечения с осями координат С осью \(Oy\): \(x = 0\). С осью \(Ox\): \(f(x) = 0\). 9️⃣ Построить график функции На основе полученных данных строим эскиз графика.
📌 Область определения \(D(f)\) справочник по типовым случаям
🔹 Многочлены — \(D(f) = \mathbb{R}\)
Пример: \(f(x) = x^3 - 3x\) → \(D = (-\infty; +\infty)\) 🔹 Дроби \(\frac{P(x)}{Q(x)}\) → \(Q(x) \neq 0\)
Пример: \(f(x) = \frac{1}{x}\) → \(x \neq 0\) → \(D = (-\infty; 0) \cup (0; +\infty)\) 🔹 Корни чётной степени \(\sqrt[2n]{g(x)}\) → \(g(x) \ge 0\)
Пример: \(f(x) = \sqrt{x}\) → \(x \ge 0\) → \(D = [0; +\infty)\) 🔹 Логарифмы \(\log_a g(x)\) → \(g(x) > 0\)
Пример: \(f(x) = \ln x\) → \(x > 0\) → \(D = (0; +\infty)\) 🔹 Тригонометрические — \(\sin x, \cos x\) → \(\mathbb{R}\); \(\tan x\) → \(x \neq \frac{\pi}{2} + \pi k\)
Пример: \(f(x) = \tan x\) → \(x \neq \frac{\pi}{2} + \pi k\) 🔹 Комбинации — пересечение областей всех частей
Пример: \(f(x) = \frac{\sqrt{x}}{x-1}\) → \(x \ge 0\), \(x \neq 1\) → \(D = [0; 1) \cup (1; +\infty)\) 🔹 Показательные \(a^x\) → \(D(f) = \mathbb{R}\) (\(a > 0, a \neq 1\))
Пример: \(f(x) = 2^x\) → \(D = \mathbb{R}\)
📖 Пример 1: \(f(x) = x^3 - 3x\) многочлен: максимум, минимум, перегиб
🔹 1. Область определения \(D(f)\)
\(f(x) = x^3 - 3x\) — это многочлен.
💡 Многочлен определён при любом значении \(x\).
\(D(f) = \mathbb{R} = (-\infty; +\infty)\)
🔹 2. Производная \(f'(x)\)
\(f'(x) = 3x^2 - 3 = 3(x-1)(x+1)\)
🔹 3. Критические точки: \(f'(x) = 0\)
\(x = -1\) и \(x = 1\)
🔹 4. Метод интервалов
На \((-\infty; -1)\): \(f'(x) > 0\) → возрастает
На \((-1; 1)\): \(f'(x) < 0\) → убывает
На \((1; +\infty)\): \(f'(x) > 0\) → возрастает
🔹 5. Точки экстремума
\(x = -1\): \(+ \to -\) → максимум, \(f(-1) = 2\)
\(x = 1\): \(- \to +\) → минимум, \(f(1) = -2\)
🔹 6. Вторая производная \(f''(x)\)
\(f''(x) = 6x\), \(f''(x) = 0\) при \(x = 0\)
На \((-\infty; 0)\): \(f''(x) < 0\) → выпукла вверх (∩)
На \((0; +\infty)\): \(f''(x) > 0\) → выпукла вниз (∪)
Точка перегиба: \((0; 0)\)
🔹 7. Асимптоты
У многочлена асимптот нет.
🔹 8. Точки пересечения с осями
С \(Oy\): \((0; 0)\)
С \(Ox\): \(x(x^2 - 3) = 0\) → \((-\sqrt{3}; 0)\), \((0; 0)\), \((\sqrt{3}; 0)\)
🔹 9. График
🔴 Максимум \((-1; 2)\)  ·  🟢 Минимум \((1; -2)\)  ·  🟡 Точка перегиба \((0; 0)\)
✅ Ответ: максимум \((-1; 2)\), минимум \((1; -2)\), точка перегиба \((0; 0)\)
📖 Пример 2: \(f(x) = x + \frac{1}{x}\) дробно-рациональная + асимптоты
🔹 1. Область определения \(D(f)\)
\(x \neq 0\) → \(D(f) = (-\infty; 0) \cup (0; +\infty)\)
🔹 2. Производная \(f'(x)\)
\(f'(x) = 1 - \frac{1}{x^2} = \frac{(x-1)(x+1)}{x^2}\)
🔹 3. Критические точки
\(x = \pm 1\) (точка \(x = 0\) не входит в ОДЗ)
🔹 4. Метод интервалов
На \((-\infty; -1)\): \(f'(x) > 0\) → возрастает
На \((-1; 0)\): \(f'(x) < 0\) → убывает
На \((0; 1)\): \(f'(x) < 0\) → убывает
На \((1; +\infty)\): \(f'(x) > 0\) → возрастает
🔹 5. Точки экстремума
\(x = -1\): максимум, \(f(-1) = -2\)
\(x = 1\): минимум, \(f(1) = 2\)
🔹 6. Вторая производная \(f''(x)\)
\(f''(x) = \frac{2}{x^3}\)
На \((-\infty; 0)\): \(f''(x) < 0\) → выпукла вверх
На \((0; +\infty)\): \(f''(x) > 0\) → выпукла вниз
🔹 7. Асимптоты
\(x = 0\) — вертикальная асимптота
\(y = x\) — наклонная асимптота
🔹 8. Точки пересечения с осями
Нет пересечений с осями
🔹 9. График
🔴 Максимум \((-1; -2)\)  ·  🟢 Минимум \((1; 2)\)  ·  ⚫ Асимптоты \(x = 0\), \(y = x\)
✅ Ответ: максимум \((-1; -2)\), минимум \((1; 2)\), асимптоты \(x = 0\), \(y = x\)
📖 Пример 3: \(f(x) = \sin x\) периодическая функция
🔹 1. Область определения \(D(f)\)
\(D(f) = \mathbb{R}\)
🔹 2. Производная \(f'(x)\)
\(f'(x) = \cos x\)
🔹 3. Критические точки
\(x = \frac{\pi}{2} + \pi k,\ k \in \mathbb{Z}\)
🔹 4. Метод интервалов (на \([-\pi; \pi]\))
На \((-\pi; -\frac{\pi}{2})\): \(\cos x < 0\) → убывает
На \((-\frac{\pi}{2}; \frac{\pi}{2})\): \(\cos x > 0\) → возрастает
На \((\frac{\pi}{2}; \pi)\): \(\cos x < 0\) → убывает
🔹 5. Точки экстремума
\(x = -\frac{\pi}{2}\): минимум, \(y = -1\)
\(x = \frac{\pi}{2}\): максимум, \(y = 1\)
🔹 6. Вторая производная \(f''(x)\)
\(f''(x) = -\sin x\), точки перегиба \((\pi k; 0)\)
🔹 7. Асимптоты
Асимптот нет
🔹 8. Точки пересечения с осями
\((0; 0)\), \((\pi k; 0)\)
🔹 9. График
🔴 Максимум \((\frac{\pi}{2}; 1)\)  ·  🟢 Минимум \((-\frac{\pi}{2}; -1)\)  ·  🟡 Точки перегиба \((\pi k; 0)\)
✅ Ответ: максимумы \((\frac{\pi}{2} + 2\pi k; 1)\), минимумы \((-\frac{\pi}{2} + 2\pi k; -1)\), точки перегиба \((\pi k; 0)\)
⚠️ Пример 4: \(f(x) = x^3\) экстремума нет, есть точка перегиба
⚠️ ВАЖНО! Если производная равна нулю в точке, это НЕ ОБЯЗАТЕЛЬНО означает экстремум!
🔹 1. ОДЗ
\(D(f) = \mathbb{R}\)
🔹 2. Производная \(f'(x) = 3x^2\) 🔹 3. Критические точки: \(x = 0\) 🔹 4. Метод интервалов
На \((-\infty; 0)\): \(f'(x) > 0\) → возрастает
На \((0; +\infty)\): \(f'(x) > 0\) → возрастает
🔹 5. Точки экстремума
Знак не меняется → экстремума нет
🔹 6. Вторая производная
\(f''(x) = 6x\), знак меняется → точка перегиба \((0; 0)\)
🔹 9. График
🟡 Точка перегиба \((0; 0)\)  ·  ⚠️ Экстремумов нет
✅ Ответ: экстремумов нет, \(x = 0\) — точка перегиба
⭐ Пример 5: задача с параметром (ЕГЭ) при каких \(a\) функция возрастает всюду
⭐ Условие: при каких \(a\) функция \(f(x) = x^3 - 3ax^2 + 3x\) возрастает на всей области определения?

🔹 1. ОДЗ и производная
\(D(f) = \mathbb{R}\), \(f'(x) = 3(x^2 - 2ax + 1)\)
🔹 2. Условие возрастания
\(x^2 - 2ax + 1 \ge 0\) при всех \(x\)
🔹 3. Дискриминант
\(D = 4(a^2 - 1) \le 0\) → \(-1 \le a \le 1\)
✅ Ответ: \(a \in [-1; 1]\)
📖 Пример 6: \(f(x) = x^3 - 3x^2\) полное исследование с выпуклостью
🔹 1. ОДЗ
\(D(f) = \mathbb{R}\)
🔹 2. Производная
\(f'(x) = 3x(x - 2)\)
🔹 3. Критические точки
\(x = 0\) и \(x = 2\)
🔹 4. Метод интервалов
На \((-\infty; 0)\): \(f'(x) > 0\) → возрастает
На \((0; 2)\): \(f'(x) < 0\) → убывает
На \((2; +\infty)\): \(f'(x) > 0\) → возрастает
🔹 5. Точки экстремума
\(x = 0\): максимум \((0; 0)\)
\(x = 2\): минимум \((2; -4)\)
🔹 6. Вторая производная
\(f''(x) = 6(x - 1)\), точка перегиба \((1; -2)\)
🔹 7. Асимптоты
У многочлена асимптот нет.
🔹 8. Точки пересечения с осями
\((0; 0)\), \((3; 0)\)
🔹 9. График
🔴 Максимум \((0; 0)\)  ·  🟢 Минимум \((2; -4)\)  ·  🟡 Точка перегиба \((1; -2)\)
✅ Ответ: максимум \((0; 0)\), минимум \((2; -4)\), точка перегиба \((1; -2)\)
📖 Пример 7: \(f(x) = \frac{x^2}{x-1}\) полное исследование с асимптотами
🔹 1. ОДЗ
\(x \neq 1\) → \(D(f) = (-\infty; 1) \cup (1; +\infty)\)
🔹 2. Производная
\(f'(x) = \frac{x(x-2)}{(x-1)^2}\)
🔹 3. Критические точки
\(x = 0\) и \(x = 2\)
🔹 4. Метод интервалов
На \((-\infty; 0)\): \(f'(x) > 0\) → возрастает
На \((0; 1)\): \(f'(x) < 0\) → убывает
На \((1; 2)\): \(f'(x) < 0\) → убывает
На \((2; +\infty)\): \(f'(x) > 0\) → возрастает
🔹 5. Точки экстремума
\(x = 0\): максимум \((0; 0)\)
\(x = 2\): минимум \((2; 4)\)
🔹 6. Вторая производная
\(f''(x) = \frac{2}{(x-1)^3}\) → перегибов нет
🔹 7. Асимптоты
\(x = 1\) — вертикальная
\(y = x + 1\) — наклонная
🔹 8. Точки пересечения с осями
\((0; 0)\) — единственная
🔹 9. График
🔴 Максимум \((0; 0)\)  ·  🟢 Минимум \((2; 4)\)  ·  ⚫ Асимптоты \(x = 1\), \(y = x+1\)
✅ Ответ: максимум \((0; 0)\), минимум \((2; 4)\), асимптоты \(x = 1\), \(y = x+1\)
⚠️ Типичные ошибки что чаще всего путают
ОшибкаПочему неверноКак правильно
Считают, что если \(f'(x_0)=0\), то это экстремум Производная может не менять знак (пример: \(y=x^3\), \(x=0\) — перегиб). Проверять смену знака
Забывают про ОДЗ при поиске критических точек Точки разрыва не входят в ОДЗ и не могут быть экстремумами. Сначала ОДЗ, потом критические точки
Путают выпуклость вверх и вниз \(f''(x) < 0\) — выпукла вверх (∩), \(f''(x) > 0\) — выпукла вниз (∪). Запомнить: минус — «грустная» ∩
Ищут асимптоты у многочленов Многочлены не имеют асимптот. Асимптоты — только у дробей и функций с корнем
📊 Сводная таблица
1. ОДЗ → исключаем точки разрыва.

2. \(f'(x) > 0\) → возрастает; \(f'(x) < 0\) → убывает.

3. Экстремум — только при смене знака \(f'(x)\).

4. \(f''(x) < 0\) → выпукла вверх (∩); \(f''(x) > 0\) → выпукла вниз (∪).

5. Асимптоты — только у дробей и функций с корнем.

6. В ответе указывать и точку, и значение: \((x_{\max}; f(x_{\max}))\).
