В папке с файлами открыть PowerShell. Скопируйте и выполните в PowerShell

# Переходим в папку
cd C:\Users\11\OneDrive\Документы\GitHub\mathhelper

# Находим ВСЕ html-файлы (включая подпапки)
$files = Get-ChildItem -Path . -Filter *.html -Recurse

Write-Host "📁 Найдено HTML-файлов: $($files.Count)" -ForegroundColor Yellow

foreach ($file in $files) {
    $content = Get-Content $file.FullName -Raw -Encoding UTF8
    
    # Проверяем
    if ($content -match 'src="file:///android_asset/es5/tex-chtml\.js"') {
        $content = $content -replace 'src="file:///android_asset/es5/tex-chtml\.js"', 'src="https://cdn.jsdelivr.net/npm/mathjax@3/es5/tex-chtml.js"'
        $content = $content -replace "src='file:///android_asset/es5/tex-chtml\.js'", "src='https://cdn.jsdelivr.net/npm/mathjax@3/es5/tex-chtml.js'"
        
        [System.IO.File]::WriteAllText($file.FullName, $content, [System.Text.UTF8Encoding]::new($false))
        Write-Host "✅ $($file.Name)" -ForegroundColor Green
    }
}

Write-Host "`n✅ Готово!" -ForegroundColor Cyan

Для будущих обновлений:
Когда в следующий раз будете обновлять сайт, просто поменяйте цифру в обоих местах:

В manifest.json: "start_url": "index.html?v=1.0.1"

В index.html: <link rel="manifest" href="manifest.json?v=1.0.1">

Цифры должны совпадать! Можно использовать v=1.0.0, v=1.0.1, v=1.0.2, v=2.0.0 и т.д.
