📈 Наибольшее и наименьшее значение функции

Определение · Случаи · Алгоритм · Примеры · Экстремумы
📖 Зачем искать наибольшее и наименьшее от самой высокой точки маршрута до максимальной прибыли

Представь, что ты идёшь по горной тропе. Важно знать, где ты поднимешься выше всего и где опустишься ниже всего. Математика делает то же самое: ищет самое большое и самое маленькое значение функции на заданном отрезке.

💡 Главная идея: наибольшее и наименьшее значения на отрезке ищут среди критических точек и концов отрезка. Из найденных чисел выбирают самое большое и самое маленькое.
📖 Определение что такое наибольшее и наименьшее значение

Наибольшее значение функции \(f(x)\) на отрезке \([a, b]\) — это самое большое из всех значений функции на этом отрезке.

Наименьшее значение функции \(f(x)\) на отрезке \([a, b]\) — это самое маленькое из всех значений функции на этом отрезке.

Непрерывная на отрезке функция обязательно достигает своего наибольшего и наименьшего значений.

📊 Случай 1. Функция только возрастает или только убывает наибольшее и наименьшее — на концах отрезка
Случай 1
Ось \(Oy\) проходит через точку \(a\)  ·  синяя линия — наибольшее  ·  красная — наименьшее

Если функция на отрезке \([a, b]\) только возрастает или только убывает, то наибольшее и наименьшее значения достигаются на концах отрезка — в точках \(a\) и \(b\).

На рисунке функция возрастает. Значит:
• наибольшее значение — в правом конце \(b\),
• наименьшее значение — в левом конце \(a\) (в начале координат).

Внутренняя точка \(c\) — просто точка внутри отрезка. Здесь ни максимума, ни минимума нет — это не экстремум.

Как определить: если \(f'(x) > 0\) на всём отрезке, функция возрастает. Если \(f'(x) < 0\) — убывает.
📊 Случай 2. Внутри отрезка есть экстремумы наибольшее и наименьшее — в критических точках или на концах
Случай 2
Синяя линия — наибольшее значение  ·  красная — наименьшее

Если внутри отрезка \([a, b]\) есть критические точки, в них может быть максимум или минимум функции — это экстремумы.

Тогда наибольшее и наименьшее значения могут достигаться:
• в критических точках внутри отрезка (\(c\) и \(n\)),
• или на концах \(a\) и \(b\).

На рисунке:
• в точке \(c\) — max (функция принимает наибольшее значение),
• в точке \(n\) — min (функция принимает наименьшее значение).

📐 Алгоритм нахождения 4 шага
  1. Найти производную \(f'(x)\).
  2. Найти критические точки внутри отрезка \([a, b]\) — где \(f'(x) = 0\) или \(f'(x)\) не существует.
  3. Вычислить значения функции в этих точках и на концах отрезка \(a\) и \(b\).
  4. Из полученных чисел выбрать самое большое и самое маленькое.
💡 Пример 1. \(f(x) = x^3 - 3x\) на \([-2, 2]\) экстремумы внутри отрезка
Условие. Найти наибольшее и наименьшее значения функции \(f(x) = x^3 - 3x\) на отрезке \([-2, 2]\).

Шаг 1. Находим производную. \(f'(x) = (x^3)' - (3x)' = 3x^2 - 3 = 3(x-1)(x+1)\). Шаг 2. Находим критические точки. \(3(x-1)(x+1) = 0 \Rightarrow x = -1,\ x = 1\).
Обе точки принадлежат отрезку \([-2, 2]\). Шаг 3. Вычисляем значения. \(f(-2) = -2,\quad f(-1) = 2,\quad f(1) = -2,\quad f(2) = 2\). Шаг 4. Сравниваем. Наибольшее \(= 2\) (при \(x = -1\) и \(x = 2\)). Наименьшее \(= -2\) (при \(x = -2\) и \(x = 1\)). Ответ: наибольшее значение \(= 2\), наименьшее значение \(= -2\).
💡 Пример 2. \(f(x) = \sin x\) на \([0, \pi]\) max внутри, min на концах
Условие. Найти наибольшее и наименьшее значения функции \(f(x) = \sin x\) на отрезке \([0, \pi]\).

Шаг 1. Производная. \(f'(x) = \cos x\). Шаг 2. Критические точки. \(\cos x = 0 \Rightarrow x = \dfrac{\pi}{2}\). Шаг 3. Значения. \(f(0) = 0,\quad f\!\left(\dfrac{\pi}{2}\right) = 1,\quad f(\pi) = 0\). Шаг 4. Сравнение. Наибольшее \(= 1\), наименьшее \(= 0\). Ответ: наибольшее \(= 1\), наименьшее \(= 0\).
💡 Пример 3. \(f(x) = x^2 + 2x + 1\) на \([-3, 1]\) min внутри, max на концах
Условие. Найти наибольшее и наименьшее значения функции \(f(x) = x^2 + 2x + 1\) на отрезке \([-3, 1]\).

Шаг 1. Производная. \(f'(x) = 2x + 2\). Шаг 2. Критические точки. \(2x + 2 = 0 \Rightarrow x = -1\). Шаг 3. Значения. \(f(-3) = 4,\quad f(-1) = 0,\quad f(1) = 4\). Шаг 4. Сравнение. Наибольшее \(= 4\), наименьшее \(= 0\). Ответ: наибольшее \(= 4\), наименьшее \(= 0\).
⚡ Пример 4. Найти наименьшее значение через точку минимума отрезок [1; 4], метод интервалов на параболе

Иногда нужно найти только наименьшее значение функции. Тогда не обязательно проверять все критические точки и концы — достаточно найти точку минимума. Если точка минимума лежит внутри отрезка, значение функции в ней и будет наименьшим на всём отрезке.

💡 Почему так можно? До точки минимума функция убывает — значит, все значения левее неё больше \(f(x_{\min})\). После точки минимума функция возрастает — значит, все значения правее неё тоже больше \(f(x_{\min})\). Значит, \(f(x_{\min})\) — самое маленькое значение на отрезке. Проверять концы не нужно.
Задание. Найти наименьшее значение функции \(f(x) = x^3 - 3x^2\) на отрезке \([1; 4]\).

Шаг 1. Находим производную. \(f'(x) = 3x^2 - 6x = 3x(x - 2)\). Шаг 2. Находим критические точки. \(3x(x - 2) = 0 \Rightarrow x = 0\) и \(x = 2\).
Точка \(x = 0\) не входит в отрезок \([1; 4]\) — отбрасываем её.
На отрезке остаётся только одна критическая точка: \(x = 2\). Шаг 3. Метод интервалов: определяем знак производной на \([1; 4]\). Производная \(f'(x) = 3x(x-2)\) — парабола с ветвями вверх и корнями \(x = 0\) и \(x = 2\). На отрезке \([1; 4]\):
• \(f'(x) < 0\) при \(x \in (1; 2)\) — функция убывает,
• \(f'(x) > 0\) при \(x \in (2; 4)\) — функция возрастает.
Шаг 4. Определяем точку минимума. В точке \(x = 2\) производная меняет знак с − на + — это точка минимума. На графике она выделена оранжевым.
Значит, именно здесь функция принимает наименьшее значение на отрезке \([1; 4]\). 💡 До \(x = 2\) функция убывает — значения выше. После \(x = 2\) функция возрастает — значения тоже выше. Значит, значение в точке минимума самое маленькое. Шаг 5. Вычисляем значение в точке минимума. \(f(2) = 2^3 - 3 \cdot 2^2 = 8 - 12 = -4\). Шаг 6. Делаем вывод. Точка минимума \(x = 2\) лежит внутри отрезка \([1; 4]\). Значит, значение \(f(2) = -4\) и есть наименьшее значение функции на этом отрезке. Концы проверять не нужно. Проверка. \(f(2) = 8 - 12 = -4\) — верно. Ответ: наименьшее значение функции \(= -4\) (достигается при \(x = 2\)).
⚡ Короткое правило: когда нужно только наименьшее значение:
1. Найти критические точки и отобрать те, что попали в отрезок.
2. По методу интервалов найти точку минимума (смена знака \(f'\) с − на +).
3. Если точка минимума внутри отрезка — её значение и есть наименьшее. Концы проверять не нужно.
⚠️ Частые ошибки что чаще всего путают

❌ Называют концы отрезка максимумом или минимумом. Концы — это не экстремумы.

❌ Путают точку минимума и наименьшее значение. Точка минимума — это \(x\), а наименьшее значение — это \(y = f(x_{\min})\).

❌ Проверяют концы, когда точка минимума внутри отрезка. Это лишнее — если функция убывает до точки минимума и возрастает после, значение в точке минимума и есть наименьшее на отрезке.

❌ Не отбрасывают критические точки, не попавшие в отрезок. Например, \(x = 0\) в примере 4 не входит в \([1; 4]\) — её нужно исключить.

✅ Помните: если точка минимума внутри отрезка — её значение и есть наименьшее. Если вне — смотрим на ближайший конец.
