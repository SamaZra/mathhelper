Деление многочленов уголком

Правило · Алгоритм · Примеры · Калькулятор
📖 Что такое деление уголком?

Деление многочленов уголком (или деление столбиком) — это способ разделить один многочлен на другой, подобно тому, как мы делим числа в столбик.

📌 Когда применяется:
• Для нахождения наклонной асимптоты графика функции
• Для упрощения рациональных выражений
• Для решения уравнений высших степеней

Что такое деление многочленов?

Разделить многочлен \(P(x)\) на многочлен \(Q(x)\) — значит найти такие многочлены \(C(x)\) (частное) и \(R(x)\) (остаток), что:

$$ P(x) = Q(x) \cdot C(x) + R(x) $$

где степень \(R(x)\) < степени \(Q(x)\).

Алгоритм деления уголком пошаговая инструкция
Как делить многочлены уголком:

1️⃣ Записать делимое и делитель в порядке убывания степеней.
💡 Если какой-то степени нет, ставим 0.
2️⃣ Разделить старший член делимого на старший член делителя.
💡 Это будет первый член частного.
3️⃣ Умножить делитель на полученный член частного.
💡 Записываем под делимым.
4️⃣ Вычесть полученное произведение из делимого.
💡 Получаем новый остаток.
5️⃣ Повторять шаги 2–4, пока степень остатка не станет меньше степени делителя.
💡 Когда степень остатка < степени делителя — деление закончено.
6️⃣ Записать ответ: частное + остаток.
💡 Ответ: \(P(x) = Q(x) \cdot C(x) + R(x)\).
📐 Пример 1. \((2x^3 + 3x^2 - 5x + 1) : (x - 2)\) с подробным пошаговым решением
Шаг 1. Записываем делимое и делитель:
Делимое: \(2x^3 + 3x^2 - 5x + 1\)
Делитель: \(x - 2\)
Шаг 2. Делим старший член:
\(\frac{2x^3}{x} = 2x^2\)
Шаг 3. Умножаем делитель на \(2x^2\):
\(2x^2 \cdot (x - 2) = 2x^3 - 4x^2\)
Шаг 4. Вычитаем:
\((2x^3 + 3x^2) - (2x^3 - 4x^2) = 7x^2\)
Сносим \(-5x\): \(7x^2 - 5x\)
Шаг 5. Делим дальше:
\(\frac{7x^2}{x} = 7x\)
\(7x \cdot (x - 2) = 7x^2 - 14x\)
\((7x^2 - 5x) - (7x^2 - 14x) = 9x\)
Сносим \(+1\): \(9x + 1\)
Шаг 6. Делим дальше:
\(\frac{9x}{x} = 9\)
\(9 \cdot (x - 2) = 9x - 18\)
\((9x + 1) - (9x - 18) = 19\)
Ответ:
Частное: \(2x^2 + 7x + 9\)
Остаток: \(19\)
\(2x^3 + 3x^2 - 5x + 1 = (x - 2)(2x^2 + 7x + 9) + 19\)
частное вычитаемое остаток делитель делимое
📐 Пример 2. \((x^3 - 2x^2 - 5x + 6) : (x - 3)\) деление без остатка
Шаг 1. Записываем делимое и делитель:
Делимое: \(x^3 - 2x^2 - 5x + 6\)
Делитель: \(x - 3\)
Шаг 2. Делим:
\(\frac{x^3}{x} = x^2\)
\(x^2 \cdot (x - 3) = x^3 - 3x^2\)
\((x^3 - 2x^2) - (x^3 - 3x^2) = x^2\)
Сносим \(-5x\): \(x^2 - 5x\)
Шаг 3. Делим дальше:
\(\frac{x^2}{x} = x\)
\(x \cdot (x - 3) = x^2 - 3x\)
\((x^2 - 5x) - (x^2 - 3x) = -2x\)
Сносим \(+6\): \(-2x + 6\)
Шаг 4. Делим дальше:
\(\frac{-2x}{x} = -2\)
\(-2 \cdot (x - 3) = -2x + 6\)
\((-2x + 6) - (-2x + 6) = 0\)
💡 Остаток равен 0 → деление без остатка.
Ответ:
Частное: \(x^2 + x - 2\)
Остаток: \(0\)
\(x^3 - 2x^2 - 5x + 6 = (x - 3)(x^2 + x - 2)\)
частное вычитаемое остаток делитель делимое
