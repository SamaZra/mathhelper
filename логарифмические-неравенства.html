Логарифмические неравенства

📖 Что такое логарифмическое неравенство

С логарифмическими уравнениями мы уже разобрались: там было важно, чтобы аргумент был положительным. С неравенствами — ещё интереснее. Появляется новая ловушка: знак неравенства зависит от основания. При одном основании он сохраняется, при другом — переворачивается.

$\log_2 x > 3$
$\log_{0{,}5}(x+1) \leq 2$
$\log_3(x-1) < \log_3(2x+3)$
$\log_2^2 x - 3\log_2 x + 2 \geq 0$

Хочешь интуицию? Смотри: при $a > 1$ функция $y = \log_a x$ возрастает. Значит, большему аргументу соответствует больший логарифм — и знак не меняется. При $0 < a < 1$ всё наоборот: функция убывает, и знак переворачивается.

💡 Два правила, которые решают всё:
• Основание $a > 1$ — знак сохраняется
• Основание $0 < a < 1$ — знак меняется
• И всегда ОДЗ: аргумент $> 0$.
📐 Основание больше 1 $a > 1$ — функция возрастает

Когда основание $a > 1$, логарифмическая функция возрастает. Значит, чем больше аргумент, тем больше логарифм. Поэтому знак неравенства между логарифмами совпадает со знаком между аргументами.

Если $a > 1$, то $\log_a f(x) > \log_a g(x) \Leftrightarrow \begin{cases} f(x) > g(x) \\ f(x) > 0 \\ g(x) > 0 \end{cases}$
знак неравенства сохраняется
💡 Почему так? Функция $y = \log_a x$ при $a > 1$ монотонно возрастает. Это значит: из $\log_a f > \log_a g$ следует $f > g$. Никаких «переворотов» не происходит.
Пример 1. $\log_2(x-1) > 3$

Шаг 1. ОДЗ. $x-1 > 0 \Rightarrow x > 1$.
💡 Под знаком логарифма может стоять только положительное число. Это ОДЗ.
Шаг 2. Представим $3$ как логарифм по основанию $2$. $3 = \log_2 8$, так как $2^3 = 8$.
Неравенство: $\log_2(x-1) > \log_2 8$.
Шаг 3. Основание $2 > 1$ — знак сохраняется. $x-1 > 8 \Rightarrow x > 9$.
Шаг 4. Пересекаем с ОДЗ. $x > 9$ (условие $x > 1$ выполняется автоматически).

Шаг 5. Числовая прямая.
Ответ: $x \in (9; +\infty)$.
Пример 2. $\log_3(x-1) < \log_3(2x+3)$

Шаг 1. ОДЗ. $x-1 > 0 \Rightarrow x > 1$
$2x+3 > 0 \Rightarrow x > -1{,}5$
Общая ОДЗ: $x > 1$.
Шаг 2. Основание $3 > 1$ — знак сохраняется. $x-1 < 2x+3 \Rightarrow -x < 4 \Rightarrow x > -4$.
💡 Обрати внимание: при переносе $x-1 < 2x+3$ получаем $-x < 4$, то есть $x > -4$. Знак меняется, потому что делим на $-1$.
Шаг 3. Пересекаем с ОДЗ. $x > 1$.

Шаг 4. Числовая прямая.
Ответ: $x \in (1; +\infty)$.
📐 Основание от 0 до 1 $0 < a < 1$ — функция убывает

Когда основание $0 < a < 1$, логарифмическая функция убывает. Чем больше аргумент, тем меньше логарифм. Поэтому знак неравенства между логарифмами меняется на противоположный при переходе к аргументам.

Если $0 < a < 1$, то $\log_a f(x) > \log_a g(x) \Leftrightarrow \begin{cases} f(x) < g(x) \\ f(x) > 0 \\ g(x) > 0 \end{cases}$
знак неравенства меняется
💡 Почему так? Функция $y = \log_a x$ при $0 < a < 1$ убывает. Это значит: большему аргументу соответствует меньшее значение логарифма. Поэтому при отбрасывании логарифмов знак переворачивается.
Пример 3. $\log_{0{,}5}(x+1) \leq 2$

Шаг 1. ОДЗ. $x+1 > 0 \Rightarrow x > -1$.
Шаг 2. Представим $2$ как логарифм по основанию $0{,}5$. $2 = \log_{0{,}5}(0{,}25)$, так как $(0{,}5)^2 = 0{,}25$.
Неравенство: $\log_{0{,}5}(x+1) \leq \log_{0{,}5}(0{,}25)$.
Шаг 3. Основание $0{,}5 \in (0; 1)$ — знак меняется. $x+1 \geq 0{,}25 \Rightarrow x \geq -0{,}75$.
💡 Было $\leq$, стало $\geq$ — потому что функция убывает.
Шаг 4. Пересекаем с ОДЗ. $x \geq -0{,}75$ (условие $x > -1$ выполняется).

Шаг 5. Числовая прямая.
Ответ: $x \in [-0{,}75; +\infty)$.
Пример 4. $\log_{\frac{1}{3}}(2x-1) > \log_{\frac{1}{3}}(x+3)$

Шаг 1. ОДЗ. $2x-1 > 0 \Rightarrow x > 0{,}5$
$x+3 > 0 \Rightarrow x > -3$
Общая ОДЗ: $x > 0{,}5$.
Шаг 2. Основание $\dfrac{1}{3} \in (0; 1)$ — знак меняется. $2x-1 < x+3 \Rightarrow x < 4$.
💡 Было $>$, стало $<$ — потому что функция убывает.
Шаг 3. Пересекаем с ОДЗ. $0{,}5 < x < 4$.

Шаг 4. Числовая прямая.
Ответ: $x \in (0{,}5; 4)$.
📐 Метод замены переменной сведение к квадратному неравенству

Если логарифм встречается дважды — например, $\log_2 x$ и $\log_2^2 x$, — это подсказка: сделайте замену $t = \log_a x$. Тогда неравенство превратится в квадратное.

💡 Главное правило: после замены решаем квадратное неравенство относительно $t$, а затем возвращаемся к $x$. Не забудьте про ОДЗ: $x > 0$.
Пример 5. $\log_2^2 x - 3\log_2 x + 2 \geq 0$

Шаг 1. ОДЗ. $x > 0$.
Шаг 2. Замена $t = \log_2 x$. $t^2 - 3t + 2 \geq 0$.
Корни: $t_1 = 1$, $t_2 = 2$. Парабола ветвями вверх: $t \leq 1$ или $t \geq 2$.
Шаг 3. Возврат к $x$. $\log_2 x \leq 1 \Rightarrow 0 < x \leq 2$ (основание $2 > 1$ — знак сохраняется).
$\log_2 x \geq 2 \Rightarrow x \geq 4$.

Шаг 4. Числовая прямая.
Ответ: $x \in (0; 2] \cup [4; +\infty)$.
Пример 6. $\log_{0{,}5}^2 x + \log_{0{,}5} x - 2 \leq 0$

Шаг 1. ОДЗ. $x > 0$. Замена $t = \log_{0{,}5} x$.
Шаг 2. $t^2 + t - 2 \leq 0$. Корни: $t_1 = -2$, $t_2 = 1$. Решение: $-2 \leq t \leq 1$.
Шаг 3. Возврат к $x$. $-2 \leq \log_{0{,}5} x \leq 1$.
$\log_{0{,}5} x \geq -2 = \log_{0{,}5} 4$ — знак меняется: $x \leq 4$.
$\log_{0{,}5} x \leq 1 = \log_{0{,}5} 0{,}5$ — знак меняется: $x \geq 0{,}5$.
Пересечение с ОДЗ: $0{,}5 \leq x \leq 4$.

Шаг 4. Числовая прямая.
Ответ: $x \in [0{,}5; 4]$.
📐 Логарифмы с разными основаниями приведение к одному основанию

Если основания разные, сначала приводим все логарифмы к одному основанию по формуле перехода: $\log_a b = \dfrac{\log_c b}{\log_c a}$.

Пример 7. $\log_2 x + \log_4 x < 3$

Шаг 1. ОДЗ. $x > 0$.
Шаг 2. Приводим к основанию $2$. $\log_4 x = \dfrac{\log_2 x}{\log_2 4} = \dfrac{\log_2 x}{2}$.
$\log_2 x + \dfrac{1}{2}\log_2 x < 3 \Rightarrow \dfrac{3}{2}\log_2 x < 3 \Rightarrow \log_2 x < 2$.
Шаг 3. Основание $2 > 1$ — знак сохраняется: $x < 4$.
С учётом ОДЗ: $0 < x < 4$.

Шаг 4. Числовая прямая.
Ответ: $x \in (0; 4)$.
⚠️ Типичные ошибки

Эти ошибки встречаются чаще всего. Проверь себя — не допускаешь ли ты их?

ОшибкаПочему неверноКак правильно
Забыли поменять знак при $0 < a < 1$ Функция убывает, поэтому знак неравенства переворачивается. $0 < a < 1$: знак меняется на противоположный
Не учли ОДЗ Аргумент логарифма должен быть строго положительным. Всегда писать $f(x) > 0$, $g(x) > 0$
Привели к общему основанию и забыли про знак Если новое основание $< 1$, знак тоже меняется. Следить за знаком основания при каждом переходе
После замены $t = \log_a x$ забыли вернуться к $x$ Ответ должен быть в терминах исходной переменной $x$, а не $t$. Обязательный обратный переход
Считают, что $\log_a x > 0$ при любом $x > 0$ Логарифм может быть отрицательным: например, $\log_2 0{,}5 = -1$. Помнить: $\log_a x > 0 \Leftrightarrow x > 1$ при $a > 1$
📊 Сводная таблица
1. $\log_a f > \log_a g$, $a > 1$ — знак сохраняется: $f > g$

2. $\log_a f > \log_a g$, $0 < a < 1$ — знак меняется: $f < g$

3. Всегда проверяем ОДЗ: $f > 0$, $g > 0$

4. $\log_a^2 x + b\log_a x + c \geq 0$ — замена $t = \log_a x$

5. Разные основания — приводим к одному по формуле $\log_a b = \dfrac{\log_c b}{\log_c a}$

6. $\log_a x > b \Leftrightarrow$ при $a > 1$: $x > a^b$; при $0 < a < 1$: $0 < x < a^b$
