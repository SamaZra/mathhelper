|x| Неравенства с модулем (ЕГЭ)

📖 Что такое неравенство с модулем?

Неравенство с модулем — это неравенство, содержащее переменную под знаком модуля.

📌 Основные методы решения неравенств с модулем:
1️⃣ Формулы — \(|x| < a \iff -a < x < a\) (при \(a > 0\)).
2️⃣ Метод интервалов — для суммы модулей.
3️⃣ Раскрытие по определению — разбиение на два случая.
📐 Пример 1. \(|2x-1| < 3\) метод — формула \(|x| < a\)
🔹 1. Используем формулу
💡 \(|2x-1| < 3 \iff -3 < 2x-1 < 3\)
\(-3 < 2x-1 < 3\)
\(-2 < 2x < 4\)
\(-1 < x < 2\)
✅ Ответ: \(x \in (-1; 2)\)
📐 Пример 2 (ЕГЭ). \(|x^2-4x| < 3\) метод — метод интервалов
🔹 1. Используем формулу
💡 \(|x^2-4x| < 3 \iff -3 < x^2-4x < 3\)
\(x^2-4x < 3\) и \(x^2-4x > -3\)
🔹 2. Решаем первое неравенство
\(x^2-4x-3 < 0\)
\(x = 2 \pm \sqrt{7}\)
💡 Корни: \(2-\sqrt{7} \approx -0.65\), \(2+\sqrt{7} \approx 4.65\)
\(x \in (2-\sqrt{7}; 2+\sqrt{7})\)
🔹 3. Решаем второе неравенство
\(x^2-4x+3 > 0\)
\((x-1)(x-3) > 0\)
\(x \in (-\infty; 1) \cup (3; +\infty)\)
🔹 4. Пересекаем
\(x \in (2-\sqrt{7}; 1) \cup (3; 2+\sqrt{7})\)
✅ Ответ: \(x \in (2-\sqrt{7}; 1) \cup (3; 2+\sqrt{7})\)
📐 Пример 3 (ЕГЭ). \(\left|\frac{x+1}{x-1}\right| \le \frac{2x}{x+3}\) метод — раскрытие + ОДЗ + метод интервалов
🔹 1. ОДЗ
\(x \neq 1,\; x \neq -3\)
💡 Правая часть \(\frac{2x}{x+3}\) должна быть \(\ge 0\).
\(\frac{2x}{x+3} \ge 0\)
💡 Решаем методом интервалов: \(x \le -3\) или \(x \ge 0\).
🔹 2. Раскрываем модуль
💡 \(\left|\frac{x+1}{x-1}\right| \le \frac{2x}{x+3} \Rightarrow -\frac{2x}{x+3} \le \frac{x+1}{x-1} \le \frac{2x}{x+3}\)
🔹 3. Решаем левое неравенство
\(-\frac{2x}{x+3} \le \frac{x+1}{x-1}\)
\(\frac{x+1}{x-1} + \frac{2x}{x+3} \ge 0\)
\(\frac{(x+1)(x+3) + 2x(x-1)}{(x-1)(x+3)} \ge 0\)
\(\frac{x^2+4x+3 + 2x^2-2x}{(x-1)(x+3)} \ge 0\)
\(\frac{3x^2+2x+3}{(x-1)(x+3)} \ge 0\)
💡 \(3x^2+2x+3 > 0\) при всех \(x\) (дискриминант \(D = 4-36 < 0\)).
\((x-1)(x+3) > 0 \Rightarrow x \in (-\infty; -3) \cup (1; +\infty)\)
🔹 4. Решаем правое неравенство
\(\frac{x+1}{x-1} \le \frac{2x}{x+3}\)
\(\frac{x+1}{x-1} - \frac{2x}{x+3} \le 0\)
\(\frac{(x+1)(x+3) - 2x(x-1)}{(x-1)(x+3)} \le 0\)
\(\frac{x^2+4x+3 - 2x^2+2x}{(x-1)(x+3)} \le 0\)
\(\frac{-x^2+6x+3}{(x-1)(x+3)} \le 0\)
\(\frac{x^2-6x-3}{(x-1)(x+3)} \ge 0\)
💡 Корни числителя: \(x = 3 \pm 2\sqrt{3}\)
\(x \in [-0.46; 1) \cup [6.46; +\infty)\)
🔹 5. Пересекаем с ОДЗ
💡 ОДЗ: \(x \le -3\) или \(x \ge 0\)
\(x \in [0; 1) \cup [3+2\sqrt{3}; +\infty)\)
✅ Ответ: \(x \in [0; 1) \cup [3+2\sqrt{3}; +\infty)\)
📐 Пример 4 (ЕГЭ). \(|2^{x+1} - 4| \le 2^x\) метод — замена \(t = 2^x\)
🔹 1. Замена \(t = 2^x > 0\)
\(|2t - 4| \le t\)
🔹 2. Раскрываем модуль
💡 \(|2t-4| \le t \iff -t \le 2t-4 \le t\)
\(-t \le 2t-4\) и \(2t-4 \le t\)
\(-3t \le -4 \Rightarrow t \ge \frac{4}{3}\)
\(t \le 4\)
\(\frac{4}{3} \le t \le 4\)
🔹 3. Возвращаемся к \(x\)
\(\frac{4}{3} \le 2^x \le 4\)
\(\log_2 \frac{4}{3} \le x \le 2\)
✅ Ответ: \(x \in [\log_2 \frac{4}{3}; 2]\)
📐 Пример 5 (ЕГЭ). \(|\log_3 x - 2| + |\log_3 x + 1| \le 3\) метод — метод интервалов
🔹 1. ОДЗ
\(x > 0\)
🔹 2. Замена \(t = \log_3 x\)
\(|t-2| + |t+1| \le 3\)
💡 Точки смены знака: \(t = -1\) и \(t = 2\).
🔹 3. Метод интервалов
1) \(t \le -1\)
\(|t-2| = -t+2,\; |t+1| = -t-1\)
\(-t+2 - t - 1 \le 3\)
\(-2t + 1 \le 3 \Rightarrow t \ge -1\)
💡 С учётом \(t \le -1\): \(t = -1\).
2) \(-1 < t \le 2\)
\(|t-2| = -t+2,\; |t+1| = t+1\)
\(-t+2 + t+1 \le 3\)
\(3 \le 3\) — верно для всех \(t \in (-1; 2]\)
3) \(t > 2\)
\(|t-2| = t-2,\; |t+1| = t+1\)
\(t-2 + t+1 \le 3\)
\(2t - 1 \le 3 \Rightarrow t \le 2\)
💡 С учётом \(t > 2\): решений нет.
🔹 4. Объединяем
\(t \in [-1; 2]\)
🔹 5. Возвращаемся к \(x\)
\(-1 \le \log_3 x \le 2\)
\(\frac{1}{3} \le x \le 9\)
✅ Ответ: \(x \in [\frac{1}{3}; 9]\)
📐 Пример 6 (ЕГЭ). \(\left|x^2-5x+6\right| + \left|x^2-5x+4\right| < 2\) метод — метод интервалов + замена
🔹 1. Замена \(t = x^2-5x\)
\(|t+6| + |t+4| < 2\)
💡 Точки смены знака: \(t = -6\) и \(t = -4\).
🔹 2. Метод интервалов
1) \(t \le -6\)
\(|t+6| = -t-6,\; |t+4| = -t-4\)
\(-t-6 - t - 4 < 2\)
\(-2t - 10 < 2 \Rightarrow t > -6\)
💡 С учётом \(t \le -6\): решений нет.
2) \(-6 < t \le -4\)
\(|t+6| = t+6,\; |t+4| = -t-4\)
\(t+6 - t - 4 < 2\)
\(2 < 2\) — неверно → решений нет.
3) \(t > -4\)
\(|t+6| = t+6,\; |t+4| = t+4\)
\(t+6 + t+4 < 2\)
\(2t + 10 < 2 \Rightarrow t < -4\)
💡 С учётом \(t > -4\): решений нет.
🔹 3. Итог
💡 Решений нет, так как минимальное значение суммы модулей равно 2 (при \(t \in [-6; -4]\)).
✅ Ответ: \(\varnothing\) (решений нет)
📐 Пример 7 (ЕГЭ). \(|\sin x - \cos x| \le \frac{1}{2}\) метод — преобразование + метод интервалов
🔹 1. Преобразуем \(\sin x - \cos x\)
💡 \(\sin x - \cos x = \sqrt{2}\sin(x - \frac{\pi}{4})\)
\(\sqrt{2}\left|\sin\left(x - \frac{\pi}{4}\right)\right| \le \frac{1}{2}\)
\(\left|\sin\left(x - \frac{\pi}{4}\right)\right| \le \frac{1}{2\sqrt{2}}\)
🔹 2. Решаем
💡 \(|\sin t| \le a \iff -a \le \sin t \le a\)
\(-\frac{1}{2\sqrt{2}} \le \sin\left(x - \frac{\pi}{4}\right) \le \frac{1}{2\sqrt{2}}\)
💡 \(\arcsin\frac{1}{2\sqrt{2}} = \alpha\), где \(\alpha \approx 0.36\) рад.
\(-\alpha \le x - \frac{\pi}{4} \le \alpha\) (на основном промежутке)
\(\frac{\pi}{4} - \alpha + 2\pi k \le x \le \frac{\pi}{4} + \alpha + 2\pi k\)
и \(\frac{3\pi}{4} - \alpha + 2\pi k \le x \le \frac{3\pi}{4} + \alpha + 2\pi k\)
✅ Ответ: \(x \in [\frac{\pi}{4} - \alpha + 2\pi k; \frac{\pi}{4} + \alpha + 2\pi k] \cup [\frac{3\pi}{4} - \alpha + 2\pi k; \frac{3\pi}{4} + \alpha + 2\pi k]\), где \(\alpha = \arcsin\frac{1}{2\sqrt{2}}\)
