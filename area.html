📐 Площадь криволинейной трапеции

📐 Определение

Криволинейная трапеция — фигура, ограниченная графиком функции \(y = f(x)\), прямыми \(x = a\), \(x = b\) и осью \(Ox\), где \(f(x) \ge 0\) на отрезке \([a; b]\).

\(S = \int_a^b f(x)\,dx\)
\(\displaystyle \int_a^b f(x)\,dx = F(x)\Big|_a^b = F(b) - F(a)\), где \(F'(x) = f(x)\)

Геометрический смысл определённого интеграла:

Определённый интеграл \(\displaystyle \int_a^b f(x)\,dx\) численно равен площади криволинейной трапеции, ограниченной графиком \(y = f(x)\), осью \(Ox\) и прямыми \(x = a\), \(x = b\).

📌 Интеграл «суммирует» бесконечно много бесконечно тонких прямоугольников, из которых состоит фигура, и даёт точное значение площади.

🔬 Визуализация: как интеграл считает площадь
Главная идея метода:
Если закрашенную фигуру под графиком разбить на прямоугольники, то площадь всей фигуры можно приближённо найти как сумму площадей этих прямоугольников.

Ключевой момент: Чем больше прямоугольников мы возьмём, тем точнее их сумма будет приближаться к точной площади фигуры.

Интеграл — это и есть предел такой суммы, когда число прямоугольников стремится к бесконечности.

📋 Частные случаи
1. Фигура ограничена двумя функциями (между кривыми)
\(S = \int_a^b (f(x) - g(x))\,dx\),
где \(f(x) \ge g(x)\) на \([a,b]\)
Решение: \(S = \int_0^1 (x - x^2)\,dx = \left[\frac{x^2}{2} - \frac{x^3}{3}\right]_0^1 = \frac{1}{2} - \frac{1}{3} = \frac{1}{6}\) кв. ед.
2. Фигура состоит из нескольких частей
\(S = S_1 + S_2 = \int_a^c f(x)\,dx + \int_c^b g(x)\,dx\)
где \(f(x)\) — верхняя на \([a,c]\), \(g(x)\) — верхняя на \([c,b]\)
Решение: \(f(x)=x^2,\; g(x)=x^2-4x+3\). Пересечение: \(x^2 = x^2-4x+3 \Rightarrow x=0.75\).
\(S = \int_0^{0.75} x^2\,dx + \int_{0.75}^{1} (x^2-4x+3)\,dx = \left[\frac{x^3}{3}\right]_0^{0.75} + \left[\frac{x^3}{3} - 2x^2 + 3x\right]_{0.75}^{1} = 0.140625 + 1.109375 = 1.25\) кв. ед.
3. Фигура расположена под осью \(Ox\) (\(f(x) \le 0\))
\(S = -\int_a^b f(x)\,dx\)
Решение: \(S = -\int_{-2}^{2} (x^2 - 4)\,dx = \int_{-2}^{2} (4 - x^2)\,dx = \left[4x - \frac{x^3}{3}\right]_{-2}^{2} = \frac{32}{3}\) кв. ед.
📌 Пример с графиком
По графику найти площадь закрашенной фигуры:
На графике изображена парабола \(y = 4 - x^2\). Закрашенная область ограничена параболой и осью \(Ox\).
Шаг 1. По графику определяем пределы интегрирования
Парабола пересекает ось \(Ox\) в точках \(x = -2\) и \(x = 2\). Значит, \(a = -2\), \(b = 2\).
Шаг 2. По графику видим, что функция выше оси \(Ox\)
На отрезке \([-2, 2]\) парабола \(y = 4 - x^2 \ge 0\). Площадь равна интегралу от функции.
Шаг 3. Записываем интеграл
\(S = \int_{-2}^{2} (4 - x^2)\,dx\)
Шаг 4. Находим первообразную
\(F(x) = 4x - \frac{x^3}{3}\)
Шаг 5. Вычисляем по формуле Ньютона-Лейбница
\(F(2) = 4 \cdot 2 - \frac{8}{3} = 8 - \frac{8}{3} = \frac{16}{3}\)
\(F(-2) = 4 \cdot (-2) - \frac{(-2)^3}{3} = -8 + \frac{8}{3} = -\frac{16}{3}\)
\(S = F(2) - F(-2) = \frac{16}{3} - \left(-\frac{16}{3}\right) = \frac{32}{3}\)
Ответ: \(S = \frac{32}{3}\) кв. ед.
📌 Пример без графика
Найти площадь фигуры, ограниченной линиями:
\(y = x^2 - 3x\), \(y = 0\)
Шаг 1. Находим точки пересечения с осью \(Ox\)
\(x^2 - 3x = 0 \;\Rightarrow\; x(x - 3) = 0\)
\(\Rightarrow\; x_1 = 0,\; x_2 = 3\)
Пределы интегрирования: \(a = 0\), \(b = 3\).
Шаг 2. Определяем знак функции на отрезке \([0, 3]\)
При \(x = 1\): \(1^2 - 3 \cdot 1 = -2 < 0\).
Функция отрицательна.
Так как \(f(x) \le 0\), площадь равна интегралу со знаком минус.
Шаг 3. Записываем формулу площади
\(S = -\int_0^3 (x^2 - 3x)\,dx = \int_0^3 (3x - x^2)\,dx\)
Шаг 4. Находим первообразную
\(F(x) = \frac{3x^2}{2} - \frac{x^3}{3}\)
Шаг 5. Вычисляем по формуле Ньютона-Лейбница
\(F(3) = \frac{3 \cdot 9}{2} - \frac{27}{3} = \frac{27}{2} - 9 = 13,5 - 9 = 4,5\)
\(F(0) = 0\)
\(S = F(3) - F(0) = 4,5 - 0 = 4,5\)
Ответ: \(S = 4,5\) кв. ед.
📌 Пример: площадь между двумя кривыми
Найти площадь фигуры, ограниченной линиями:
\(y = x^2\), \(y = 2x\)
Шаг 1. Находим точки пересечения кривых
\(x^2 = 2x \;\Rightarrow\; x^2 - 2x = 0 \;\Rightarrow\; x(x - 2) = 0\)
\(\Rightarrow\; x_1 = 0,\; x_2 = 2\)
Пределы интегрирования: \(a = 0\), \(b = 2\).
Шаг 2. Определяем, какая функция выше на отрезке \([0, 2]\)
При \(x = 1\): \(y_1 = 1^2 = 1\), \(y_2 = 2 \cdot 1 = 2\).
Значит, \(2x \ge x^2\) на \([0, 2]\).
Верхняя функция: \(f(x) = 2x\), нижняя: \(g(x) = x^2\).
Шаг 3. Записываем формулу площади между кривыми
\(S = \int_a^b (f(x) - g(x))\,dx = \int_0^2 (2x - x^2)\,dx\)
Шаг 4. Находим первообразную
\(F(x) = 2 \cdot \frac{x^2}{2} - \frac{x^3}{3} = x^2 - \frac{x^3}{3}\)
Шаг 5. Вычисляем по формуле Ньютона-Лейбница
\(F(2) = 2^2 - \frac{2^3}{3} = 4 - \frac{8}{3} = \frac{12}{3} - \frac{8}{3} = \frac{4}{3}\)
\(F(0) = 0 - 0 = 0\)
\(S = F(2) - F(0) = \frac{4}{3} - 0 = \frac{4}{3}\)
Ответ: \(S = \frac{4}{3}\) кв. ед.

💡 Геометрический смысл:

Площадь фигуры, заключённой между параболой \(y = x^2\) и прямой \(y = 2x\) на отрезке \([0, 2]\).

⚠️ Советы, чтобы не ошибиться
📐 Всегда начинайте с чертежа. Набросок поможет увидеть, где графики пересекаются, какая функция выше на каком участке, есть ли точки, где функция меняет знак. Без чертежа легко пропустить важные детали!
🔍 Проверяйте пределы интегрирования. Часто ошибка кроется в том, что границы найдены неверно (например, не все точки пересечения учтены). Убедитесь, что нашли все корни уравнения \(f(x)=g(x)\).
✅ Помните: площадь всегда положительна. Если в процессе вычислений получился отрицательный результат — скорее всего, нужно взять модуль или пересмотреть порядок функций в разности. Площадь — это мера, она не может быть отрицательной!
📌 Определяйте, какая функция выше. На каждом участке интегрирования верхняя функция должна быть первой в разности. Если ошибиться — знак площади изменится. Проверяйте знак разности \(f(x)-g(x)\) на отрезке.
🧮 Не забывайте про модуль, если функция ниже оси \(Ox\). Интеграл от отрицательной функции даст отрицательное число, а площадь — положительная. Используйте формулу \(S = -\int_a^b f(x)\,dx\) для \(f(x)\le 0\).
✏️ Записывайте решение по шагам. Последовательность: 1) найти точки пересечения, 2) определить верх/низ, 3) записать интеграл, 4) вычислить первообразную, 5) подставить пределы. Аккуратная запись помогает избежать арифметических ошибок.
💻 Проверяйте ответ с помощью геометрического смысла. Если площадь получается слишком большой или маленькой — пересмотрите решение. Например, площадь под параболой на \([-2;2]\) должна быть больше площади треугольника, но меньше площади прямоугольника.
