Тригонометрические уравнения, сводящиеся к алгебраическим

📖 Идея: тригонометрию — в алгебру

Многие тригонометрические уравнения выглядят сложно, но стоит сделать замену переменной — и они превращаются в знакомые квадратные, кубические, дробно-рациональные. Например:

$\sin^2 x + \sin x - 2 = 0$   →   замена $t = \sin x$, получаем $t^2 + t - 2 = 0$
$2\cos^2 x - 3\cos x + 1 = 0$   →   $2t^2 - 3t + 1 = 0$
$\tg^2 x - 4\tg x + 3 = 0$   →   $t^2 - 4t + 3 = 0$

После нахождения корней $t$ нужно вернуться к $x$ — решить простейшие тригонометрические уравнения.

💡 Главная идея: любое уравнение, в котором одна и та же тригонометрическая функция встречается несколько раз (например, $\sin x$ и $\sin^2 x$), можно свести к алгебраическому заменой $t = \sin x$.
📐 Замена $t = \sin x$ или $t = \cos x$ квадратные уравнения относительно синуса или косинуса
💡 Ограничение: после замены пишем $t \in [-1; 1]$, потому что синус и косинус не выходят за эти границы. Корни вне отрезка — отбрасываем.
Пример 1. $2\sin^2 x - 3\sin x + 1 = 0$.

Шаг 1. Замена. $t = \sin x$, $t \in [-1; 1]$. Уравнение: $2t^2 - 3t + 1 = 0$.
Шаг 2. Решаем. $D = 9 - 8 = 1$, $t_1 = 1$, $t_2 = \dfrac{1}{2}$. Оба в $[-1; 1]$ — подходят.
Шаг 3. Обратная замена. $\sin x = 1 \Rightarrow x = \dfrac{\pi}{2} + 2\pi n$.
$\sin x = \dfrac{1}{2} \Rightarrow x = \dfrac{\pi}{6} + 2\pi n$ или $x = \dfrac{5\pi}{6} + 2\pi n$.
Ответ: $x = \dfrac{\pi}{2} + 2\pi n$; $x = \dfrac{\pi}{6} + 2\pi n$; $x = \dfrac{5\pi}{6} + 2\pi n$, $n \in \mathbb{Z}$.
Пример 2. $2\cos^2 x + \cos x - 1 = 0$.

Шаг 1. Замена. $t = \cos x$, $t \in [-1; 1]$. $2t^2 + t - 1 = 0$.
Шаг 2. Решаем. $D = 1 + 8 = 9$, $t_1 = \dfrac{1}{2}$, $t_2 = -1$. Оба в $[-1; 1]$.
Шаг 3. Обратная замена. $\cos x = \dfrac{1}{2} \Rightarrow x = \pm\dfrac{\pi}{3} + 2\pi n$.
$\cos x = -1 \Rightarrow x = \pi + 2\pi n$.
💡 Формула для $\cos x = -1$ — частный случай, записывается коротко.
Ответ: $x = \pm\dfrac{\pi}{3} + 2\pi n$; $x = \pi + 2\pi n$, $n \in \mathbb{Z}$.
📐 Замена $t = \tg x$ или $t = \ctg x$
💡 Ограничение: для $\tg$ и $\ctg$ $t \in \mathbb{R}$ — без ограничений. Но нужно следить за ОДЗ самого тангенса: $\cos x \neq 0$.
Пример 3. $\tg^2 x - 4\tg x + 3 = 0$.

Шаг 1. ОДЗ. $\cos x \neq 0$, то есть $x \neq \dfrac{\pi}{2} + \pi n$.
Шаг 2. Замена. $t = \tg x$, $t \in \mathbb{R}$. $t^2 - 4t + 3 = 0$.
Шаг 3. Корни. $t_1 = 1$, $t_2 = 3$.
Шаг 4. Обратная замена. $\tg x = 1 \Rightarrow x = \dfrac{\pi}{4} + \pi n$.
$\tg x = 3 \Rightarrow x = \arctg 3 + \pi n$.
💡 $\arctg 3$ не табличное, но ответ в виде $\arctg 3$ — вполне законный.
Ответ: $x = \dfrac{\pi}{4} + \pi n$; $x = \arctg 3 + \pi n$, $n \in \mathbb{Z}$.
📐 Замена $t = \sin x \pm \cos x$ когда есть $\sin x + \cos x$ и $\sin x \cos x$

Используем соотношение: $(\sin x + \cos x)^2 = 1 + 2\sin x \cos x$. Отсюда $\sin x \cos x = \dfrac{t^2 - 1}{2}$, где $t = \sin x + \cos x$.

Пример 4. $\sin x + \cos x + \sin x \cos x = 1$.

Шаг 1. Замена. $t = \sin x + \cos x$, $t \in [-\sqrt{2}; \sqrt{2}]$. Тогда $\sin x \cos x = \dfrac{t^2 - 1}{2}$.
Шаг 2. Подставляем. $t + \dfrac{t^2 - 1}{2} = 1 \Rightarrow 2t + t^2 - 1 = 2 \Rightarrow t^2 + 2t - 3 = 0$.
Шаг 3. Корни. $t_1 = 1$, $t_2 = -3$. Второй не входит в $[-\sqrt{2}; \sqrt{2}]$ — отбрасываем.
Шаг 4. Обратная замена. $\sin x + \cos x = 1$.
Способ: $\sin x + \cos x = \sqrt{2}\sin\left(x + \dfrac{\pi}{4}\right) = 1 \Rightarrow \sin\left(x + \dfrac{\pi}{4}\right) = \dfrac{\sqrt{2}}{2}$.
$x + \dfrac{\pi}{4} = \dfrac{\pi}{4} + 2\pi n$ или $x + \dfrac{\pi}{4} = \dfrac{3\pi}{4} + 2\pi n$.
$x = 2\pi n$ или $x = \dfrac{\pi}{2} + 2\pi n$.
Ответ: $x = 2\pi n$; $x = \dfrac{\pi}{2} + 2\pi n$, $n \in \mathbb{Z}$.
📐 Однородные уравнения $a\sin x + b\cos x = 0$ и $a\sin^2 x + b\sin x\cos x + c\cos^2 x = 0$

1-й степени. Вид: $a\sin x + b\cos x = 0$. Делим на $\cos x \neq 0$, получаем линейное относительно $\tg x$.

Пример 5. $\sin x + \cos x = 0$.

Шаг 1. Делим на $\cos x$. $\tg x + 1 = 0 \Rightarrow \tg x = -1$.
💡 Перед делением проверяем: если $\cos x = 0$, то $\sin x = \pm 1$ — подстановка даёт $\pm 1 \neq 0$. Значит, $\cos x \neq 0$ для всех решений.
Шаг 2. Решаем. $x = -\dfrac{\pi}{4} + \pi n$.
Ответ: $x = -\dfrac{\pi}{4} + \pi n$, $n \in \mathbb{Z}$.

2-й степени. Вид: $a\sin^2 x + b\sin x\cos x + c\cos^2 x = 0$. Делим на $\cos^2 x \neq 0$, получаем квадратное относительно $\tg x$.

Пример 6. $\sin^2 x - 3\sin x\cos x + 2\cos^2 x = 0$.

Шаг 1. Делим на $\cos^2 x$. $\tg^2 x - 3\tg x + 2 = 0$.
Шаг 2. Замена $t = \tg x$. $t^2 - 3t + 2 = 0 \Rightarrow t_1 = 1$, $t_2 = 2$.
Шаг 3. Обратная замена. $\tg x = 1 \Rightarrow x = \dfrac{\pi}{4} + \pi n$.
$\tg x = 2 \Rightarrow x = \arctg 2 + \pi n$.
Ответ: $x = \dfrac{\pi}{4} + \pi n$; $x = \arctg 2 + \pi n$, $n \in \mathbb{Z}$.
📐 Уравнения вида $a\sin x + b\cos x = c$ метод вспомогательного аргумента

Идея: свернуть $a\sin x + b\cos x$ в одну функцию вида $R\sin(x + \varphi)$.

$a\sin x + b\cos x = R\sin(x + \varphi)$,
где $R = \sqrt{a^2 + b^2}$, $\cos\varphi = \dfrac{a}{R}$, $\sin\varphi = \dfrac{b}{R}$.
💡 Когда решений нет: если $|c| > \sqrt{a^2 + b^2}$ — уравнение решений не имеет, потому что $R\sin(\ldots) \in [-R; R]$.
Пример 7. $\sin x + \sqrt{3}\cos x = 1$.

Шаг 1. Находим $R$ и $\varphi$. $R = \sqrt{1 + 3} = 2$. Так как $\cos\varphi = \dfrac{1}{2}$, $\sin\varphi = \dfrac{\sqrt{3}}{2}$, то $\varphi = \dfrac{\pi}{3}$.
$\sin x + \sqrt{3}\cos x = 2\sin\left(x + \dfrac{\pi}{3}\right)$.
Шаг 2. Решаем. $2\sin\left(x + \dfrac{\pi}{3}\right) = 1 \Rightarrow \sin\left(x + \dfrac{\pi}{3}\right) = \dfrac{1}{2}$.
$x + \dfrac{\pi}{3} = \dfrac{\pi}{6} + 2\pi n \Rightarrow x = -\dfrac{\pi}{6} + 2\pi n$.
$x + \dfrac{\pi}{3} = \dfrac{5\pi}{6} + 2\pi n \Rightarrow x = \dfrac{\pi}{2} + 2\pi n$.
Ответ: $x = -\dfrac{\pi}{6} + 2\pi n$; $x = \dfrac{\pi}{2} + 2\pi n$, $n \in \mathbb{Z}$.
📐 Универсальная подстановка $t = \tg\dfrac{x}{2}$ когда ничего другое не работает

Универсальная подстановка позволяет свести любое уравнение с $\sin x$ и $\cos x$ к дробно-рациональному относительно $t$.

$\sin x = \dfrac{2t}{1 + t^2}$,   $\cos x = \dfrac{1 - t^2}{1 + t^2}$,   $\tg x = \dfrac{2t}{1 - t^2}$.
⚠️ ВАЖНО: проверка потери корня!

При замене $t = \tg\dfrac{x}{2}$ мы теряем точки, где $\tg\dfrac{x}{2}$ не определён: $x = \pi + 2\pi n$.

Алгоритм:
  1. Подставь $x = \pi + 2\pi n$ в исходное уравнение.
  2. Если равенство выполняется — это корень, запомни его и добавь в финальный ответ.
  3. Если не выполняется — потери нет, делай замену.
Запомни: всегда проверяй $x = \pi + 2\pi n$ перед заменой!
Пример 8 (без потери корня). $6\cos x - 5\sin x = 7$.

Шаг 1. Проверка. При $x = \pi + 2\pi n$: $\cos = -1$, $\sin = 0$. Тогда $6 \cdot (-1) - 0 = -6 \neq 7$. Корень не подходит, потери нет.
Шаг 2. Замена $t = \tg\dfrac{x}{2}$. $6 \cdot \dfrac{1 - t^2}{1 + t^2} - 5 \cdot \dfrac{2t}{1 + t^2} = 7$.
$6(1 - t^2) - 10t = 7(1 + t^2)$.
$6 - 6t^2 - 10t = 7 + 7t^2$.
$-13t^2 - 10t - 1 = 0 \Rightarrow 13t^2 + 10t + 1 = 0$.
Шаг 3. Корни. $D = 100 - 52 = 48 = 16 \cdot 3$, $t_{1,2} = \dfrac{-10 \pm 4\sqrt{3}}{26} = \dfrac{-5 \pm 2\sqrt{3}}{13}$.
Шаг 4. Обратная замена. $\tg\dfrac{x}{2} = \dfrac{-5 \pm 2\sqrt{3}}{13} \Rightarrow x = 2\arctg\left(\dfrac{-5 \pm 2\sqrt{3}}{13}\right) + 2\pi n$.
Ответ: $x = 2\arctg\left(\dfrac{-5 \pm 2\sqrt{3}}{13}\right) + 2\pi n$, $n \in \mathbb{Z}$.
Пример 9 (с потерей корня!). $\sin x = 0$.

Шаг 1. Проверка. При $x = \pi + 2\pi n$: $\sin(\pi + 2\pi n) = 0$. Подходит! Запоминаем корень $x = \pi + 2\pi n$.
Шаг 2. Замена. $\dfrac{2t}{1 + t^2} = 0 \Rightarrow t = 0$.
Шаг 3. Обратная замена. $\tg\dfrac{x}{2} = 0 \Rightarrow x = 2\pi n$.
Шаг 4. Объединяем. Из замены: $x = 2\pi n$. Из проверки: $x = \pi + 2\pi n$. Объединяем: $x = \pi n$.
💡 Без проверки мы бы потеряли половину корней.
Ответ: $x = \pi n$, $n \in \mathbb{Z}$.
📋 Сводная таблица методов
1. Замена $t = \sin x$ или $t = \cos x$
Ограничение: $t \in [-1; 1]$. Применяем, когда есть одна и та же функция в разных степенях.

2. Замена $t = \tg x$ или $t = \ctg x$
$t \in \mathbb{R}$. Следим за ОДЗ: $\cos x \neq 0$ или $\sin x \neq 0$.

3. Замена $t = \sin x \pm \cos x$
$t \in [-\sqrt{2}; \sqrt{2}]$, $\sin x \cos x = \dfrac{t^2 \mp 1}{2}$.

4. Однородные
Делим на $\cos x$ (1-я степень) или $\cos^2 x$ (2-я степень), получаем уравнение относительно $\tg x$.

5. $a\sin x + b\cos x = c$
Метод вспомогательного аргумента: $R = \sqrt{a^2 + b^2}$. Если $|c| > R$ — решений нет.

6. Универсальная подстановка $t = \tg\dfrac{x}{2}$
$\sin x = \dfrac{2t}{1+t^2}$, $\cos x = \dfrac{1-t^2}{1+t^2}$.
⚠️ Перед заменой проверяем $x = \pi + 2\pi n$!
