Простейшие тригонометрические уравнения

📖 Зачем нужны арксинус, арккосинус и т.д.

Уравнение $\sin x = \dfrac{1}{2}$ имеет бесконечно много решений: $x = 30°$, $x = 150°$, $x = 390°$ и так далее. Но среди них есть одно «главное», к которому мы «привязываемся», чтобы записать все остальные. Это и есть арксинус.

Арксинус числа $a$ — это угол из отрезка $\left[-\dfrac{\pi}{2}; \dfrac{\pi}{2}\right]$, синус которого равен $a$. Обозначается $\arcsin a$.

Аналогично определяются арккосинус, арктангенс, арккотангенс — каждый со своим отрезком значений.

💡 Главная идея: аркфункции — это «углы-эталоны» из узкого диапазона. Через них записываются все решения простейших уравнений. Дальше — просто добавляем период.
📐 Определения аркфункций

Арксинус: $\arcsin a = \alpha \Leftrightarrow \sin\alpha = a$, $\alpha \in \left[-\dfrac{\pi}{2}; \dfrac{\pi}{2}\right]$, $a \in [-1; 1]$.

Примеры: $\arcsin 0 = 0$, $\arcsin \dfrac{1}{2} = \dfrac{\pi}{6}$, $\arcsin 1 = \dfrac{\pi}{2}$.

Арккосинус: $\arccos a = \alpha \Leftrightarrow \cos\alpha = a$, $\alpha \in [0; \pi]$, $a \in [-1; 1]$.

Примеры: $\arccos 1 = 0$, $\arccos \dfrac{1}{2} = \dfrac{\pi}{3}$, $\arccos 0 = \dfrac{\pi}{2}$.

Арктангенс: $\arctg a = \alpha \Leftrightarrow \tg\alpha = a$, $\alpha \in \left(-\dfrac{\pi}{2}; \dfrac{\pi}{2}\right)$, $a \in \mathbb{R}$.

Примеры: $\arctg 0 = 0$, $\arctg 1 = \dfrac{\pi}{4}$, $\arctg \sqrt{3} = \dfrac{\pi}{3}$.

Арккотангенс: $\arcctg a = \alpha \Leftrightarrow \ctg\alpha = a$, $\alpha \in (0; \pi)$, $a \in \mathbb{R}$.

Примеры: $\arcctg 1 = \dfrac{\pi}{4}$, $\arcctg 0 = \dfrac{\pi}{2}$, $\arcctg \sqrt{3} = \dfrac{\pi}{6}$.

📐 Формулы решений

Уравнение $\sin x = a$ ($|a| \leq 1$):

$x = (-1)^n \arcsin a + \pi n$, $n \in \mathbb{Z}$
или в альтернативной форме: $x = \arcsin a + 2\pi n$ или $x = \pi - \arcsin a + 2\pi n$.
sin x = 1

$x = \dfrac{\pi}{2} + 2\pi n$

sin x = 0

$x = \pi n$

sin x = −1

$x = -\dfrac{\pi}{2} + 2\pi n$

Уравнение $\cos x = a$ ($|a| \leq 1$):

$x = \pm \arccos a + 2\pi n$, $n \in \mathbb{Z}$.
cos x = 1

$x = 2\pi n$

cos x = 0

$x = \dfrac{\pi}{2} + \pi n$

cos x = −1

$x = \pi + 2\pi n$

Уравнение $\tg x = a$ ($a \in \mathbb{R}$):

$x = \arctg a + \pi n$, $n \in \mathbb{Z}$.

Уравнение $\ctg x = a$ ($a \in \mathbb{R}$):

$x = \arcctg a + \pi n$, $n \in \mathbb{Z}$.
💡 Частая ошибка: путать периоды. У $\sin$ и $\cos$ — период $2\pi$, у $\tg$ и $\ctg$ — $\pi$. Особые случаи ($\sin x = 0$, $\cos x = 0$, $\tg x = 0$ и т.д.) имеют свои короткие формулы — их лучше запомнить.
📝 Примеры решения
Пример 1. $\sin x = \dfrac{\sqrt{3}}{2}$.

Решение. $\arcsin \dfrac{\sqrt{3}}{2} = \dfrac{\pi}{3}$. По формуле:
$x = (-1)^n \cdot \dfrac{\pi}{3} + \pi n$, $n \in \mathbb{Z}$.
Ответ: $x = (-1)^n \dfrac{\pi}{3} + \pi n$, $n \in \mathbb{Z}$.
Пример 2. $\sin x = -\dfrac{1}{2}$. Найти корни на $[0; 2\pi]$.

Решение. $\arcsin\left(-\dfrac{1}{2}\right) = -\dfrac{\pi}{6}$.
$x = (-1)^n \cdot \left(-\dfrac{\pi}{6}\right) + \pi n$.
$n = 1$: $x = \dfrac{\pi}{6} + \pi = \dfrac{7\pi}{6}$.
$n = 2$: $x = -\dfrac{\pi}{6} + 2\pi = \dfrac{11\pi}{6}$.
💡 Перебираем $n$ и отбираем те, что попали в отрезок.
Ответ: $x = \dfrac{7\pi}{6}$, $x = \dfrac{11\pi}{6}$.
Пример 3. $\cos x = \dfrac{1}{2}$.

Решение. $\arccos \dfrac{1}{2} = \dfrac{\pi}{3}$.
$x = \pm \dfrac{\pi}{3} + 2\pi n$, $n \in \mathbb{Z}$.
Ответ: $x = \pm\dfrac{\pi}{3} + 2\pi n$, $n \in \mathbb{Z}$.
Пример 4. $\tg x = \dfrac{1}{2}$.

Решение. По формуле $\tg x = a$: $x = \arctg \dfrac{1}{2} + \pi n$.
💡 $\arctg \dfrac{1}{2}$ не табличный — оставляем в таком виде.
Ответ: $x = \arctg \dfrac{1}{2} + \pi n$, $n \in \mathbb{Z}$.
Пример 5 (с аргументом 3x). $\tg(3x - \dfrac{\pi}{4}) = \dfrac{1}{2}$.

Шаг 1. Применяем формулу. $3x - \dfrac{\pi}{4} = \arctg \dfrac{1}{2} + \pi n$.
Шаг 2. Выражаем $x$. $3x = \arctg \dfrac{1}{2} + \dfrac{\pi}{4} + \pi n$.
$x = \dfrac{1}{3}\arctg \dfrac{1}{2} + \dfrac{\pi}{12} + \dfrac{\pi n}{3}$, $n \in \mathbb{Z}$.
Ответ: $x = \dfrac{1}{3}\arctg \dfrac{1}{2} + \dfrac{\pi}{12} + \dfrac{\pi n}{3}$, $n \in \mathbb{Z}$.
⚠️ Что запомнить
📌 Периоды и особые случаи:
• $\sin$ и $\cos$ — период $2\pi$.
• $\tg$ и $\ctg$ — период $\pi$.
• $\sin x = 0$: $x = \pi n$ (период $\pi$ — короче, чем у общей формулы).
• $\cos x = 0$: $x = \dfrac{\pi}{2} + \pi n$ (период $\pi$).
• $\sin x = \pm 1$: $x = \pm\dfrac{\pi}{2} + 2\pi n$ (период $2\pi$).
• $\cos x = \pm 1$: $x = \pi n$ или $x = \pi + 2\pi n$ (период $2\pi$).
