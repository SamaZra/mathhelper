Производная сложной функции

Определение · Формула · Подробные примеры · Ошибки

Сложная функция — это функция от функции: \(y = f(g(x))\), где \(u = g(x)\) — внутренняя функция, \(f(u)\) — внешняя функция.

Производная сложной функции равна произведению производной внешней функции по внутренней на производную внутренней функции.

$$ (f(g(x)))' = \color{#e74c3c}{f'(g(x))} \cdot \color{#3498db}{g'(x)} $$
Красным — производная внешней, синим — производная внутренней.
Примеры с подробным решением 9 разобранных примеров с пошаговым решением
Пример 1. \(y = \sin(4x - \pi/3)\)

Шаг 1. Внешняя: \(f(u) = \color{#e74c3c}{\sin u}\), внутренняя: \(u = g(x) = \color{#3498db}{4x - \frac{\pi}{3}}\).
Шаг 2. \(f'(u) = \color{#e74c3c}{\cos u}\).
Шаг 3. \(g'(x) = \color{#3498db}{4}\).
Шаг 4. \(y' = \color{#e74c3c}{\cos(4x - \frac{\pi}{3})} \cdot \color{#3498db}{4}\).
Ответ: \(y' = 4\cos(4x - \frac{\pi}{3})\).
Пример 2. \(y = e^{-2x^2+1}\)

Шаг 1. Внешняя: \(f(u) = \color{#e74c3c}{e^u}\), внутренняя: \(u = g(x) = \color{#3498db}{-2x^2+1}\).
Шаг 2. \(f'(u) = \color{#e74c3c}{e^u}\).
Шаг 3. \(g'(x) = \color{#3498db}{-4x}\).
Шаг 4. \(y' = \color{#e74c3c}{e^{-2x^2+1}} \cdot \color{#3498db}{(-4x)}\).
Ответ: \(y' = -4x \cdot e^{-2x^2+1}\).
Пример 3. \(y = \ln(5x^3-2x+7)\)

Шаг 1. Внешняя: \(f(u) = \color{#e74c3c}{\ln u}\), внутренняя: \(u = g(x) = \color{#3498db}{5x^3-2x+7}\).
Шаг 2. \(f'(u) = \color{#e74c3c}{\frac{1}{u}}\).
Шаг 3. \(g'(x) = \color{#3498db}{15x^2 - 2}\).
Шаг 4. \(y' = \color{#e74c3c}{\frac{1}{5x^3-2x+7}} \cdot \color{#3498db}{(15x^2 - 2)}\).
Ответ: \(y' = \frac{15x^2 - 2}{5x^3-2x+7}\).
Пример 4. \(y = \sqrt{3x^2+2x}\)

Шаг 1. Внешняя: \(f(u) = \color{#e74c3c}{\sqrt{u}}\), внутренняя: \(u = g(x) = \color{#3498db}{3x^2+2x}\).
Шаг 2. \(f'(u) = \color{#e74c3c}{\frac{1}{2\sqrt{u}}}\).
Шаг 3. \(g'(x) = \color{#3498db}{6x+2}\).
Шаг 4. \(y' = \color{#e74c3c}{\frac{1}{2\sqrt{3x^2+2x}}} \cdot \color{#3498db}{(6x+2)}\).
Шаг 5. Упрощаем: \(y' = \frac{6x+2}{2\sqrt{3x^2+2x}} = \frac{3x+1}{\sqrt{3x^2+2x}}\).
Ответ: \(y' = \frac{3x+1}{\sqrt{3x^2+2x}}\).
Пример 5. \(y = \frac{1}{\sqrt{x^2+4}}\)

Шаг 1. \(y = (x^2+4)^{-1/2}\).
Шаг 2. Внешняя: \(f(u) = \color{#e74c3c}{u^{-1/2}}\), внутренняя: \(u = g(x) = \color{#3498db}{x^2+4}\).
Шаг 3. \(f'(u) = \color{#e74c3c}{-\frac{1}{2}u^{-3/2}}\).
Шаг 4. \(g'(x) = \color{#3498db}{2x}\).
Шаг 5. \(y' = \color{#e74c3c}{-\frac{1}{2}(x^2+4)^{-3/2}} \cdot \color{#3498db}{2x}\).
Шаг 6. Упрощаем: \(y' = -\frac{x}{(x^2+4)^{3/2}}\).
Ответ: \(y' = -\frac{x}{(x^2+4)\sqrt{x^2+4}}\).
Пример 6. \(y = \frac{1}{(2x+1)^3}\)

Шаг 1. \(y = (2x+1)^{-3}\).
Шаг 2. Внешняя: \(f(u) = \color{#e74c3c}{u^{-3}}\), внутренняя: \(u = g(x) = \color{#3498db}{2x+1}\).
Шаг 3. \(f'(u) = \color{#e74c3c}{-3u^{-4}}\).
Шаг 4. \(g'(x) = \color{#3498db}{2}\).
Шаг 5. \(y' = \color{#e74c3c}{-3(2x+1)^{-4}} \cdot \color{#3498db}{2}\).
Шаг 6. Упрощаем: \(y' = -\frac{6}{(2x+1)^4}\).
Ответ: \(y' = -\frac{6}{(2x+1)^4}\).
Пример 7. \(y = \cos(5x^2+2)\)

Шаг 1. Внешняя: \(f(u) = \color{#e74c3c}{\cos u}\), внутренняя: \(u = g(x) = \color{#3498db}{5x^2+2}\).
Шаг 2. \(f'(u) = \color{#e74c3c}{-\sin u}\).
Шаг 3. \(g'(x) = \color{#3498db}{10x}\).
Шаг 4. \(y' = \color{#e74c3c}{-\sin(5x^2+2)} \cdot \color{#3498db}{10x}\).
Ответ: \(y' = -10x \cdot \sin(5x^2+2)\).
Пример 8. \(y = \operatorname{tg}(2x-\pi)\)

Шаг 1. Внешняя: \(f(u) = \color{#e74c3c}{\operatorname{tg} u}\), внутренняя: \(u = g(x) = \color{#3498db}{2x-\pi}\).
Шаг 2. \(f'(u) = \color{#e74c3c}{\frac{1}{\cos^2 u}}\).
Шаг 3. \(g'(x) = \color{#3498db}{2}\).
Шаг 4. \(y' = \color{#e74c3c}{\frac{1}{\cos^2(2x-\pi)}} \cdot \color{#3498db}{2}\).
Ответ: \(y' = \frac{2}{\cos^2(2x-\pi)}\).
Пример 9. \(y = \operatorname{ctg}(3x)\)

Шаг 1. Внешняя: \(f(u) = \color{#e74c3c}{\operatorname{ctg} u}\), внутренняя: \(u = g(x) = \color{#3498db}{3x}\).
Шаг 2. \(f'(u) = \color{#e74c3c}{-\frac{1}{\sin^2 u}}\).
Шаг 3. \(g'(x) = \color{#3498db}{3}\).
Шаг 4. \(y' = \color{#e74c3c}{-\frac{1}{\sin^2(3x)}} \cdot \color{#3498db}{3}\).
Ответ: \(y' = -\frac{3}{\sin^2(3x)}\).
⚠️ Частые ошибки

❌ Забывают умножить на производную внутренней функции — самая распространённая ошибка.

❌ Путают порядок: сначала производная внешней (с внутренней!), потом умножаем на производную внутренней.

❌ Неправильно находят производную внешней — убедитесь, что внешняя функция продифференцирована правильно.

❌ В нелинейных функциях забывают продифференцировать внутреннюю правильно (например, \((x^2)' = 2x\), а не \(2\)).

✅ Правило: «сначала внешнюю, умножить на производную внутренней».
