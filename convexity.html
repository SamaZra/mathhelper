Выпуклость и точки перегиба

Определение · Алгоритм · Примеры · Связь с экстремумами
📖 Что это такое?
📌 Выпуклость функции — это направление «изгиба» графика.
Выпуклая вниз (∪):
График лежит выше касательной.
📌 Вторая производная: \(f''(x) > 0\)
📌 Пример: \(y = x^2\) (парабола ветвями вверх)
🟢 График \(y = x^2\) выше касательной (выпуклый вниз)
Выпуклая вверх (∩):
График лежит ниже касательной.
📌 Вторая производная: \(f''(x) < 0\)
📌 Пример: \(y = -x^2\) (парабола ветвями вниз)
🔴 График \(y = -x^2\) ниже касательной (выпуклый вверх)
Точка перегиба — это точка, где функция меняет направление выпуклости.
📌 В точке перегиба: \(f''(x) = 0\) (или не существует) и меняется знак \(f''(x)\).
📌 Пример: \(y = x^3\) в точке \(x = 0\).
🟡 График \(y = x^3\) меняет выпуклость в точке \((0; 0)\)
📋 Алгоритм исследования с методом интервалов
Как найти промежутки выпуклости и точки перегиба:

1️⃣ Найти вторую производную \(f''(x)\). 2️⃣ Найти точки, где \(f''(x) = 0\) или не существует. 3️⃣ Нанести эти точки на числовую прямую. 4️⃣ Метод интервалов: определить знак \(f''(x)\) на каждом промежутке, подставляя любое число из промежутка.
• если \(f''(x) > 0\) → функция выпукла вниз (∪)
• если \(f''(x) < 0\) → функция выпукла вверх (∩)
5️⃣ Если в точке \(x_0\) знак \(f''(x)\) меняется, то \(x_0\) — точка перегиба.
💡 Метод интервалов — это способ определить знак функции на промежутке: берём любое число из промежутка, подставляем в функцию и смотрим, какой знак получился.
📐 Пример 1. \(f(x) = x^3\) классическая точка перегиба
Шаг 1. Находим производные: $$ f(x) = x^3 $$ $$ f'(x) = 3x^2 $$ $$ f''(x) = 6x $$ Шаг 2. Находим \(f''(x) = 0\): $$ 6x = 0 \Rightarrow x = 0 $$ Шаг 3. Метод интервалов. Наносим \(x = 0\) на числовую прямую и определяем знаки: $$ (-\infty; 0) \quad \text{— берём } x = -1, \quad f''(-1) = -6 < 0 $$ $$ (0; +\infty) \quad \text{— берём } x = 1, \quad f''(1) = 6 > 0 $$ Шаг 4. Анализируем знаки: $$ x < 0: \quad f''(x) < 0 \Rightarrow \text{выпукла вверх (∩)} $$ $$ x > 0: \quad f''(x) > 0 \Rightarrow \text{выпукла вниз (∪)} $$
💡 В точке \(x = 0\) знак меняется с \(-\) на \(+\).
Ответ: • Функция выпукла вверх на \((-\infty; 0)\) • Функция выпукла вниз на \((0; +\infty)\) • \(x = 0\) — точка перегиба, \(f(0) = 0\)
✅ График \(y = x^3\) перегибается в точке \((0; 0)\).
📐 Пример 2. \(f(x) = x^4 - 6x^2\) две точки перегиба
Шаг 1. Находим производные: $$ f(x) = x^4 - 6x^2 $$ $$ f'(x) = 4x^3 - 12x $$ $$ f''(x) = 12x^2 - 12 = 12(x^2 - 1) $$ Шаг 2. Находим \(f''(x) = 0\): $$ 12(x^2 - 1) = 0 \Rightarrow x = \pm 1 $$ Шаг 3. Метод интервалов. Наносим \(x = -1\) и \(x = 1\) на числовую прямую: $$ (-\infty; -1) \quad \text{— берём } x = -2, \quad f''(-2) = 12(4-1) = 36 > 0 $$ $$ (-1; 1) \quad \text{— берём } x = 0, \quad f''(0) = 12(0-1) = -12 < 0 $$ $$ (1; +\infty) \quad \text{— берём } x = 2, \quad f''(2) = 12(4-1) = 36 > 0 $$ Шаг 4. Анализируем знаки: $$ x < -1: \quad f''(x) > 0 \Rightarrow \text{выпукла вниз (∪)} $$ $$ -1 < x < 1: \quad f''(x) < 0 \Rightarrow \text{выпукла вверх (∩)} $$ $$ x > 1: \quad f''(x) > 0 \Rightarrow \text{выпукла вниз (∪)} $$ Ответ: • Выпукла вниз на \((-\infty; -1)\) и \((1; +\infty)\) • Выпукла вверх на \((-1; 1)\) • Точки перегиба: \(x = -1\) и \(x = 1\) $$ f(-1) = 1 - 6 = -5, \quad f(1) = 1 - 6 = -5 $$ • Координаты точек перегиба: \((-1; -5)\) и \((1; -5)\)
✅ В точках \(x = \pm 1\) знак \(f''(x)\) меняется, значит это точки перегиба.
📐 Пример 3. \(f(x) = \sin x\) периодические точки перегиба
Шаг 1. Находим производные: $$ f(x) = \sin x $$ $$ f'(x) = \cos x $$ $$ f''(x) = -\sin x $$ Шаг 2. Находим \(f''(x) = 0\): $$ -\sin x = 0 \Rightarrow x = \pi k, \quad k \in \mathbb{Z} $$ Шаг 3. Метод интервалов. Рассмотрим промежутки: $$ (0; \pi) \quad \text{— берём } x = \frac{\pi}{2}, \quad f''\left(\frac{\pi}{2}\right) = -1 < 0 $$ $$ (\pi; 2\pi) \quad \text{— берём } x = \frac{3\pi}{2}, \quad f''\left(\frac{3\pi}{2}\right) = 1 > 0 $$ Шаг 4. Анализируем знаки: $$ x \in (0; \pi): \quad f''(x) < 0 \Rightarrow \text{выпукла вверх (∩)} $$ $$ x \in (\pi; 2\pi): \quad f''(x) > 0 \Rightarrow \text{выпукла вниз (∪)} $$ Ответ: • Выпукла вверх на \((2\pi k; \pi + 2\pi k)\) • Выпукла вниз на \((\pi + 2\pi k; 2\pi + 2\pi k)\) • Точки перегиба: \(x = \pi k\), \(f(\pi k) = 0\) • Координаты точек перегиба: \((\pi k; 0)\), где \(k \in \mathbb{Z}\)
✅ Точки перегиба синуса: \((\pi k; 0)\).
📐 Пример 4. \(f(x) = x^4\) нет точек перегиба
Шаг 1. Находим производные: $$ f(x) = x^4 $$ $$ f'(x) = 4x^3 $$ $$ f''(x) = 12x^2 $$ Шаг 2. Находим \(f''(x) = 0\): $$ 12x^2 = 0 \Rightarrow x = 0 $$ Шаг 3. Метод интервалов. Наносим \(x = 0\) на числовую прямую: $$ (-\infty; 0) \quad \text{— берём } x = -1, \quad f''(-1) = 12 > 0 $$ $$ (0; +\infty) \quad \text{— берём } x = 1, \quad f''(1) = 12 > 0 $$ Шаг 4. Анализируем знаки: $$ x < 0: \quad f''(x) > 0 \Rightarrow \text{выпукла вниз (∪)} $$ $$ x > 0: \quad f''(x) > 0 \Rightarrow \text{выпукла вниз (∪)} $$ Ответ: • Функция выпукла вниз на всей области определения \((-\infty; +\infty)\) • Точек перегиба нет, так как знак \(f''(x)\) не меняется
✅ В точке \(x = 0\) вторая производная равна нулю, но знак не меняется → это не точка перегиба.
📐 Пример 5. \(f(x) = x^5\) точка перегиба с плоским участком
Шаг 1. Находим производные: $$ f(x) = x^5 $$ $$ f'(x) = 5x^4 $$ $$ f''(x) = 20x^3 $$ Шаг 2. Находим \(f''(x) = 0\): $$ 20x^3 = 0 \Rightarrow x = 0 $$ Шаг 3. Метод интервалов. Наносим \(x = 0\) на числовую прямую: $$ (-\infty; 0) \quad \text{— берём } x = -1, \quad f''(-1) = -20 < 0 $$ $$ (0; +\infty) \quad \text{— берём } x = 1, \quad f''(1) = 20 > 0 $$ Шаг 4. Анализируем знаки: $$ x < 0: \quad f''(x) < 0 \Rightarrow \text{выпукла вверх (∩)} $$ $$ x > 0: \quad f''(x) > 0 \Rightarrow \text{выпукла вниз (∪)} $$
💡 В точке \(x = 0\) знак меняется с \(-\) на \(+\).
Ответ: • Функция выпукла вверх на \((-\infty; 0)\) • Функция выпукла вниз на \((0; +\infty)\) • \(x = 0\) — точка перегиба, \(f(0) = 0\)
✅ График \(y = x^5\) перегибается в точке \((0; 0)\), но переход более плавный, чем у \(x^3\).
📐 Пример 6. \(f(x) = \frac{1}{x}\) вторая производная не существует в точке \(x = 0\)
Шаг 1. Находим производные: $$ f(x) = \frac{1}{x} = x^{-1} $$ $$ f'(x) = -x^{-2} = -\frac{1}{x^2} $$ $$ f''(x) = 2x^{-3} = \frac{2}{x^3} $$ Шаг 2. Находим, где \(f''(x) = 0\) или не существует: $$ f''(x) = 0 \text{ — решений нет} $$ $$ f''(x) \text{ не существует при } x = 0 $$
💡 В точке \(x = 0\) функция \(f(x) = \frac{1}{x}\) не определена (разрыв).
Шаг 3. Метод интервалов. Наносим \(x = 0\) на числовую прямую: $$ (-\infty; 0) \quad \text{— берём } x = -1, \quad f''(-1) = -2 < 0 $$ $$ (0; +\infty) \quad \text{— берём } x = 1, \quad f''(1) = 2 > 0 $$ Шаг 4. Анализируем знаки: $$ x < 0: \quad f''(x) < 0 \Rightarrow \text{выпукла вверх (∩)} $$ $$ x > 0: \quad f''(x) > 0 \Rightarrow \text{выпукла вниз (∪)} $$ Ответ: • Функция выпукла вверх на \((-\infty; 0)\) • Функция выпукла вниз на \((0; +\infty)\) • В точке \(x = 0\) разрыв, поэтому это не точка перегиба
✅ Важно: точка перегиба должна принадлежать области определения функции!
⭐ Пример 7. \(f(x) = x^3 + ax^2 + 3x\) найти \(a\), при которых есть точка перегиба
⭐ Задача повышенной сложности (с параметром).

Условие: При каких значениях параметра \(a\) функция \(f(x) = x^3 + ax^2 + 3x\) имеет точку перегиба?

Шаг 1. Находим вторую производную: $$ f(x) = x^3 + ax^2 + 3x $$ $$ f'(x) = 3x^2 + 2ax + 3 $$ $$ f''(x) = 6x + 2a $$ Шаг 2. Находим \(f''(x) = 0\): $$ 6x + 2a = 0 \Rightarrow x = -\frac{a}{3} $$ Шаг 3. Метод интервалов. Проверяем, меняется ли знак \(f''(x)\) в этой точке: $$ f''(x) = 6x + 2a \text{ — линейная функция} $$ $$ \text{При } x < -\frac{a}{3}: \quad f''(x) < 0 $$ $$ \text{При } x > -\frac{a}{3}: \quad f''(x) > 0 $$
💡 Линейная функция всегда меняет знак в точке \(x = -a/3\).
Ответ: • При любом значении \(a\) функция имеет точку перегиба • Точка перегиба: \(x = -\frac{a}{3}\) • Координата точки перегиба: \(\left(-\frac{a}{3};\; f\left(-\frac{a}{3}\right)\right)\)
✅ Для кубического многочлена \(x^3 + ax^2 + bx + c\) точка перегиба всегда существует.
🔗 Связь с экстремумами вторая производная и точки экстремума
Вторая производная помогает определять тип экстремума:

Если \(f'(x_0) = 0\) и \(f''(x_0) \neq 0\), то:

• \(f''(x_0) < 0\) → \(x_0\) — точка максимума
💡 Функция выпукла вверх → вершина — максимум.
• \(f''(x_0) > 0\) → \(x_0\) — точка минимума
💡 Функция выпукла вниз → вершина — минимум.
• \(f''(x_0) = 0\) → требуется дополнительное исследование.
💡 Может быть экстремум, а может быть точка перегиба.
Пример: \(f(x) = x^2\) $$ f'(x) = 2x = 0 \Rightarrow x = 0 $$ $$ f''(x) = 2 > 0 \Rightarrow x = 0 \text{ — точка минимума} $$
✅ Вторая производная положительна → минимум.
