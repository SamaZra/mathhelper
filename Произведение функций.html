Произведение тригонометрических функций

📖 Зачем преобразовывать произведение в сумму

Формулы этого раздела позволяют заменить произведение двух тригонометрических функций на сумму или разность. Это удобно, когда нужно:

  • Упростить выражение с произведениями.
  • Найти интеграл от тригонометрической функции.
  • Решить уравнение, где есть произведения.

Все три формулы легко получаются из формул сложения: нужно сложить или вычесть две подходящие формулы сложения, и произведения превратятся в сумму.

💡 Главная идея: произведение — это «плохо» (сложно интегрировать, упрощать). Сумма — «хорошо». Формулы этого раздела переводят «плохое» в «хорошее».
📐 Формулы произведения

$\sin\alpha\sin\beta = \dfrac{1}{2}[\cos(\alpha-\beta) - \cos(\alpha+\beta)]$

$\cos\alpha\cos\beta = \dfrac{1}{2}[\cos(\alpha-\beta) + \cos(\alpha+\beta)]$

$\sin\alpha\cos\beta = \dfrac{1}{2}[\sin(\alpha-\beta) + \sin(\alpha+\beta)]$

💡 Обрати внимание на знак:
• В произведении $\sin\cdot\sin$ — минус между косинусами.
• В произведении $\cos\cdot\cos$ — плюс.
• В $\sin\cdot\cos$ — оба слагаемых с синусами, знаки «+».
📝 Примеры применения
Пример 1. Преобразовать в сумму: $\sin 5\alpha \sin 3\alpha$.

Решение. По формуле $\sin\alpha\sin\beta = \dfrac{1}{2}[\cos(\alpha-\beta) - \cos(\alpha+\beta)]$:
$\sin 5\alpha \sin 3\alpha = \dfrac{1}{2}[\cos 2\alpha - \cos 8\alpha]$.
💡 Считаем разность углов ($5-3=2$) и сумму ($5+3=8$). Знак между косинусами — минус.
Ответ: $\dfrac{1}{2}(\cos 2\alpha - \cos 8\alpha)$.
Пример 2. Преобразовать в сумму: $\cos 40°\cos 10°$.

Решение. По формуле $\cos\alpha\cos\beta = \dfrac{1}{2}[\cos(\alpha-\beta) + \cos(\alpha+\beta)]$:
$\cos 40°\cos 10° = \dfrac{1}{2}[\cos 30° + \cos 50°] = \dfrac{1}{2} \cdot \dfrac{\sqrt{3}}{2} + \dfrac{\cos 50°}{2}$.
Ответ: $\dfrac{\sqrt{3}}{4} + \dfrac{\cos 50°}{2}$.
Пример 3. Вычислить $\sin 75°\cos 15°$.

Решение. По формуле $\sin\alpha\cos\beta = \dfrac{1}{2}[\sin(\alpha-\beta) + \sin(\alpha+\beta)]$:
$\sin 75°\cos 15° = \dfrac{1}{2}[\sin 60° + \sin 90°] = \dfrac{1}{2}\left[\dfrac{\sqrt{3}}{2} + 1\right] = \dfrac{\sqrt{3}}{4} + \dfrac{1}{2}$.
Ответ: $\dfrac{\sqrt{3}}{4} + \dfrac{1}{2}$.
Пример 4 (упрощение). Упростить $\sin x \sin 3x + \cos x \cos 3x$.

Шаг 1. Разложим каждое произведение. $\sin x \sin 3x = \dfrac{1}{2}[\cos 2x - \cos 4x]$
$\cos x \cos 3x = \dfrac{1}{2}[\cos 2x + \cos 4x]$
Шаг 2. Складываем. $\dfrac{1}{2}[\cos 2x - \cos 4x + \cos 2x + \cos 4x] = \dfrac{1}{2} \cdot 2\cos 2x = \cos 2x$.
💡 Слагаемые с $\cos 4x$ сократились — поэтому и получилось просто.
Ответ: $\cos 2x$.
⚠️ На что обратить внимание
  • Следи за знаком. Только в формуле $\sin\cdot\sin$ появляется минус. Остальные две — с плюсом.
  • Правильный порядок разностей. Всегда $\cos(\alpha-\beta)$ или $\sin(\alpha-\beta)$ — сначала вычитаем. Не наоборот.
  • Формулы симметричны. Если поменять местами $\alpha$ и $\beta$, ничего не изменится (кроме знака в третьей формуле, который сохранится, потому что оба слагаемых — синусы).
