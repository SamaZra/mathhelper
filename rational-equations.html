📐 Рациональные уравнения (ЕГЭ)

📖 Что такое рациональное уравнение?

Рациональное уравнение — это уравнение вида \(f(x) = 0\), где \(f(x)\) — рациональная функция (отношение двух многочленов).

📌 Основные методы решения (задания из ЕГЭ):
1️⃣ Приведение к общему знаменателю.
2️⃣ Разложение на множители.
3️⃣ Замена переменной.
4️⃣ Использование ОДЗ (обязательно!).
📐 Пример 1 (ЕГЭ). \(\frac{2x}{x-3} = \frac{x+1}{x+2}\) метод — приведение к общему знаменателю
🔹 1. ОДЗ
\(x \neq 3,\; x \neq -2\)
🔹 2. Умножаем на общий знаменатель \((x-3)(x+2)\)
\(2x(x+2) = (x+1)(x-3)\)
\(2x^2 + 4x = x^2 - 2x - 3\)
\(x^2 + 6x + 3 = 0\)
🔹 3. Решаем квадратное уравнение
\(D = 36 - 12 = 24\)
\(x = \frac{-6 \pm 2\sqrt{6}}{2} = -3 \pm \sqrt{6}\)
🔹 4. Проверка по ОДЗ
💡 Оба корня не равны 3 и -2 → подходят.
✅ Ответ: \(x = -3 \pm \sqrt{6}\)
📐 Пример 2 (ЕГЭ). \(\frac{x^2-3x+2}{x-2} = x+1\) метод — разложение на множители + сокращение
🔹 1. ОДЗ
\(x \neq 2\)
🔹 2. Разлагаем числитель
\(\frac{(x-1)(x-2)}{x-2} = x+1\)
💡 При \(x \neq 2\) сокращаем на \(x-2\).
\(x-1 = x+1\)
\(-1 = 1\) — противоречие
✅ Ответ: \(\varnothing\) (решений нет)
💡 В ЕГЭ такие задания встречаются — важно уметь определять, что корней нет.
📐 Пример 3 (ЕГЭ). \(\frac{x}{x-1} + \frac{2}{x+1} = \frac{3x+1}{x^2-1}\) метод — общий знаменатель + ОДЗ
🔹 1. ОДЗ
\(x \neq \pm 1\)
🔹 2. Общий знаменатель: \((x-1)(x+1) = x^2-1\)
\(\frac{x(x+1) + 2(x-1)}{x^2-1} = \frac{3x+1}{x^2-1}\)
\(x^2 + x + 2x - 2 = 3x + 1\)
\(x^2 + 3x - 2 = 3x + 1\)
\(x^2 - 3 = 0\)
\(x = \pm \sqrt{3}\)
🔹 3. Проверка по ОДЗ
💡 \(\pm \sqrt{3} \neq \pm 1\) → подходят.
✅ Ответ: \(x = \pm \sqrt{3}\)
📐 Пример 4 (ЕГЭ). \(\left(\frac{x}{x+1}\right)^2 - 4\cdot\frac{x}{x+1} + 3 = 0\) метод — замена переменной
🔹 1. ОДЗ
\(x \neq -1\)
🔹 2. Замена \(t = \frac{x}{x+1}\)
\(t^2 - 4t + 3 = 0\)
\((t-1)(t-3) = 0\)
\(t = 1\) или \(t = 3\)
🔹 3. Возвращаемся к \(x\)
\(\frac{x}{x+1} = 1 \Rightarrow x = x+1 \Rightarrow 0 = 1\) — нет решений
\(\frac{x}{x+1} = 3 \Rightarrow x = 3x + 3 \Rightarrow -2x = 3 \Rightarrow x = -1.5\)
🔹 4. Проверка по ОДЗ
💡 \(x = -1.5 \neq -1\) → подходит.
✅ Ответ: \(x = -1.5\)
📐 Пример 5 (ЕГЭ). \(\frac{1}{x-1} + \frac{2}{x-2} = \frac{3}{x-3}\) метод — общий знаменатель + ОДЗ
🔹 1. ОДЗ
\(x \neq 1,\; x \neq 2,\; x \neq 3\)
🔹 2. Общий знаменатель: \((x-1)(x-2)(x-3)\)
\((x-2)(x-3) + 2(x-1)(x-3) = 3(x-1)(x-2)\)
\((x^2 - 5x + 6) + 2(x^2 - 4x + 3) = 3(x^2 - 3x + 2)\)
\(x^2 - 5x + 6 + 2x^2 - 8x + 6 = 3x^2 - 9x + 6\)
\(3x^2 - 13x + 12 = 3x^2 - 9x + 6\)
\(-13x + 12 = -9x + 6\)
\(-4x = -6\)
\(x = 1.5\)
🔹 3. Проверка по ОДЗ
💡 \(x = 1.5 \neq 1, 2, 3\) → подходит.
✅ Ответ: \(x = 1.5\)
📐 Пример 6 (ЕГЭ). \(\frac{x^2}{x^2-4} - \frac{4}{x^2-4} = 1\) метод — общий знаменатель + ОДЗ
🔹 1. ОДЗ
\(x^2 - 4 \neq 0 \Rightarrow x \neq \pm 2\)
🔹 2. Общий знаменатель уже есть
\(\frac{x^2 - 4}{x^2-4} = 1\)
💡 При \(x \neq \pm 2\) левая часть всегда равна 1.
🔹 3. Проверка
💡 Все \(x\), кроме \(\pm 2\), подходят.
✅ Ответ: \(x \in (-\infty; -2) \cup (-2; 2) \cup (2; +\infty)\)
💡 В ЕГЭ такие уравнения называются «тождественно верными» на ОДЗ.
