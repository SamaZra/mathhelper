Первообразная

$F'(x) = f(x)$ · множество функций $+ C$
📖 Зачем нужна первообразная

До сих пор ты двигался «вперёд»: по функции находил её производную — то есть скорость изменения. А что, если задача обратная? Дана скорость, нужно найти саму функцию.

Например: известна скорость движения тела $v(t)$. Как найти путь $s(t)$? Нужно «отменить» дифференцирование. Эта операция называется интегрированием, а её результат — первообразной.

Первообразная — это «функция, производная которой равна данной». Именно она лежит в основе интегралов, площадей под графиком и объёмов тел вращения.

💡 Главная идея: первообразная — это обратная операция к производной. Если $(F(x))' = f(x)$, то $F$ — первообразная для $f$. И таких функций бесконечно много — все они отличаются на константу $C$.
📘 Определение

Первообразная функции \(f(x)\) — такая функция \(F(x)\), что \(F'(x) = f(x)\).

Если \(F(x)\) — первообразная, то \(F(x) + C\) — тоже первообразная (общее решение).

+C означает семейство функций, сдвинутых по вертикали.

✅ Проверка: \((F(x) + C)' = F'(x) = f(x)\). Всегда проверяйте себя через производную!

⚙️ Правила нахождения первообразных
Правило 1 · сумма / разность
\(F(x) \pm G(x)\) — первообразная для \(f(x) \pm g(x)\)
\(f(x)=x^2+\sin x\)
\(F(x)=\frac{x^3}{3}-\cos x + C\)
Правило 2 · постоянный множитель
\(a\cdot F(x)\) — первообразная для \(a\cdot f(x)\)
\(f(x)=5\cos x\)
\(F(x)=5\sin x + C\)
Правило 3 · сложная функция (линейная замена)
\(\frac{1}{k}F(kx+b)\) — первообразная для \(f(kx+b)\)
\(f(x)=\sin(5x)\)
\(F(x)=-\frac{\cos(5x)}{5} + C\)
📋 Первообразные сложных функций

💡 Если под знаком функции стоит линейное выражение \(kx+b\), то первообразная находится по правилу:

\(\displaystyle \frac{1}{k}F(kx+b) + C\)

\(f(x)\)\(F(x) + C\)
\((kx+b)^n\;(n \neq -1)\)\(\frac{(kx+b)^{n+1}}{k(n+1)} + C\)
\(\frac{1}{kx+b}\)\(\frac{1}{k}\ln|kx+b| + C\)
\(\sin(kx+b)\)\(-\frac{\cos(kx+b)}{k} + C\)
\(\cos(kx+b)\)\(\frac{\sin(kx+b)}{k} + C\)
\(\frac{1}{\sin^2(kx+b)}\)\(-\frac{\operatorname{ctg}(kx+b)}{k} + C\)
\(\frac{1}{\cos^2(kx+b)}\)\(\frac{\operatorname{tg}(kx+b)}{k} + C\)
\(e^{kx+b}\)\(\frac{e^{kx+b}}{k} + C\)
\(a^{kx+b}\)\(\frac{a^{kx+b}}{k\cdot\ln a} + C\)

📝 Разобранные примеры с проверкой

Пример 1. Найти первообразную для \(f(x) = 3x^2 + \sin(2x)\)

Шаг 1. Используем правило суммы: \(F(x) = F_1(x) + F_2(x)\), где \(F_1'(x) = 3x^2\), \(F_2'(x) = \sin(2x)\)

Шаг 2. Для \(3x^2\): \(F_1(x) = 3 \cdot \frac{x^3}{3} = x^3\)

Шаг 3. Для \(\sin(2x)\): \(F_2(x) = -\frac{\cos(2x)}{2}\)

Шаг 4. Складываем: \(F(x) = x^3 - \frac{\cos(2x)}{2} + C\)

💡 Здесь работают **два правила сразу**: сумма (правило 1) и линейная замена $kx+b$ (правило 3). Не забудь поделить на $k = 2$ при интегрировании $\sin(2x)$.

✅ Проверка: \(F'(x) = 3x^2 + \sin(2x) = f(x)\) ✓

Пример 2. Найти первообразную для \(f(x) = \frac{5}{3x-1} + e^{2x}\)

Шаг 1. Используем правило суммы: \(F(x) = F_1(x) + F_2(x)\), где \(F_1'(x) = \frac{5}{3x-1}\), \(F_2'(x) = e^{2x}\)

Шаг 2. Для \(\frac{5}{3x-1}\): \(F_1(x) = 5 \cdot \frac{1}{3}\ln|3x-1| = \frac{5}{3}\ln|3x-1|\)

Шаг 3. Для \(e^{2x}\): \(F_2(x) = \frac{e^{2x}}{2}\)

Шаг 4. Складываем: \(F(x) = \frac{5}{3}\ln|3x-1| + \frac{e^{2x}}{2} + C\)

💡 Коэффициент **выносится** за знак первообразной (правило 2), а $1/k$ появляется из-за линейной замены (правило 3).

✅ Проверка: \(F'(x) = \frac{5}{3} \cdot \frac{3}{3x-1} + \frac{1}{2}\cdot 2e^{2x} = \frac{5}{3x-1} + e^{2x} = f(x)\) ✓

⚠️ Типичные ошибки

Эти ошибки встречаются чаще всего. Проверь себя — не допускаешь ли ты их?

ОшибкаПочему неверноКак правильно
Забыли $+C$ в ответе Первообразных бесконечно много — все они отличаются на константу. Без $+C$ ответ неполный. Всегда писать $+ C$ в конце
$\int \sin x \, dx = \cos x + C$ Знак перепутан. Производная $\cos x$ равна $-\sin x$, а не $\sin x$. $\int \sin x \, dx = -\cos x + C$
При линейной замене забыли разделить на $k$ Например, $\int \sin(5x)\,dx = -\cos(5x) + C$ — неверно. Нужно разделить на 5. $\int \sin(5x)\,dx = -\dfrac{\cos(5x)}{5} + C$
$\int \dfrac{1}{x}\,dx = \dfrac{x^0}{0} + C$ Формула $\dfrac{x^{n+1}}{n+1}$ работает только при $n \neq -1$. При $n = -1$ она «ломается». $\int \dfrac{1}{x}\,dx = \ln|x| + C$
Не пишут модуль в $\ln|x|$ Под логарифмом должно быть положительное число. Но $x$ может быть отрицательным. Писать $\ln|x|$, а не $\ln x$
$\int a^x\,dx = a^x + C$ Забыли разделить на $\ln a$. $\int a^x\,dx = \dfrac{a^x}{\ln a} + C$
