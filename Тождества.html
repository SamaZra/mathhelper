Основные тригонометрические тождества

📖 Откуда берутся тождества

Тригонометрические тождества — не «магические формулы», которые надо зубрить. Все они вытекают из одного-единственного факта: точка на тригонометрическом круге имеет координаты $(\cos\alpha; \sin\alpha)$ и лежит на окружности радиуса $1$.

Применим к этой точке теорему Пифагора. Катеты прямоугольного треугольника: $|\cos\alpha|$ и $|\sin\alpha|$; гипотенуза — радиус, равный $1$. Значит:

$\cos^2\alpha + \sin^2\alpha = 1$

Это и есть основное тригонометрическое тождество. Все остальные формулы — его следствия.

💡 Главная идея: не нужно заучивать все тождества по отдельности. Достаточно помнить: • $\sin^2 + \cos^2 = 1$ — это теорема Пифагора • $\tg = \dfrac{\sin}{\cos}$, $\ctg = \dfrac{\cos}{\sin}$ — это определения • Остальные формулы выводятся из этих двух за пару шагов.

📐 Теорема Пифагора на единичной окружности: $\sin^2\alpha + \cos^2\alpha = 1$

📐 Основные тождества шесть формул, из которых выводится всё

$\sin^2 \alpha + \cos^2 \alpha = 1$

$\tg \alpha = \dfrac{\sin \alpha}{\cos \alpha}$

$\ctg \alpha = \dfrac{\cos \alpha}{\sin \alpha}$

$\tg \alpha \cdot \ctg \alpha = 1$

$1 + \tg^2 \alpha = \dfrac{1}{\cos^2 \alpha}$

$1 + \ctg^2 \alpha = \dfrac{1}{\sin^2 \alpha}$

💡 Как получаются последние два? Разделим основное тождество $\sin^2 + \cos^2 = 1$ на $\cos^2\alpha$ — получим $1 + \tg^2\alpha = \dfrac{1}{\cos^2\alpha}$. То же, но делим на $\sin^2\alpha$ — получаем $1 + \ctg^2\alpha = \dfrac{1}{\sin^2\alpha}$. Не нужно заучивать — достаточно помнить исходное.
⚠️ Ограничения:
• $\tg\alpha$ определён при $\alpha \neq \dfrac{\pi}{2} + \pi k$, $k \in \mathbb{Z}$
• $\ctg\alpha$ определён при $\alpha \neq \pi k$, $k \in \mathbb{Z}$
• В тождествах с $\dfrac{1}{\cos^2}$ и $\dfrac{1}{\sin^2}$ — те же ограничения.
📝 Примеры применения упрощение, доказательство, вычисление
Пример 1 (упрощение). Упростить: $\sin^2\alpha \cdot \ctg^2\alpha + \sin^2\alpha$.

Шаг 1. Расписываем $\ctg^2\alpha$. $\ctg^2\alpha = \dfrac{\cos^2\alpha}{\sin^2\alpha}$.
Шаг 2. Подставляем. $\sin^2\alpha \cdot \dfrac{\cos^2\alpha}{\sin^2\alpha} + \sin^2\alpha = \cos^2\alpha + \sin^2\alpha$.
Шаг 3. Используем основное тождество. $\cos^2\alpha + \sin^2\alpha = 1$.
💡 Синусы в первом слагаемом сократились — так и должно быть: $\ctg$ и $\sin$ «взаимно уничтожаются».
Ответ: $1$.
Пример 2 (вычисление). Дано $\tg\alpha = 2$. Найти $\cos\alpha$.

Шаг 1. Используем тождество с $\tg$ и $\cos$. $1 + \tg^2\alpha = \dfrac{1}{\cos^2\alpha}$.
Шаг 2. Подставляем. $1 + 2^2 = 5 = \dfrac{1}{\cos^2\alpha} \Rightarrow \cos^2\alpha = \dfrac{1}{5} = 0{,}2$.
Шаг 3. Извлекаем корень. $\cos\alpha = \pm\sqrt{0{,}2} = \pm\dfrac{\sqrt{5}}{5}$.
💡 Знак не определить без четверти — оба варианта возможны. Если бы была указана четверть, оставили бы только один.
Ответ: $\cos\alpha = \pm\dfrac{\sqrt{5}}{5}$.
Пример 3 (вычисление с указанием четверти). Дано $\sin\alpha = 0{,}6$, $\alpha \in (0°; 90°)$. Найти $\cos\alpha$ и $\tg\alpha$.

Шаг 1. Основное тождество. $\cos^2\alpha = 1 - \sin^2\alpha = 1 - 0{,}36 = 0{,}64$.
Шаг 2. Знак косинуса. В I четверти $\cos\alpha > 0$, значит $\cos\alpha = 0{,}8$.
Шаг 3. Тангенс. $\tg\alpha = \dfrac{\sin\alpha}{\cos\alpha} = \dfrac{0{,}6}{0{,}8} = 0{,}75$.
Ответ: $\cos\alpha = 0{,}8$, $\tg\alpha = 0{,}75$.
Пример 4 (упрощение дроби). Упростить: $\dfrac{\sin\alpha}{1 + \cos\alpha} + \dfrac{1 + \cos\alpha}{\sin\alpha}$.

Шаг 1. Общий знаменатель. $\dfrac{\sin^2\alpha + (1 + \cos\alpha)^2}{\sin\alpha(1 + \cos\alpha)}$.
Шаг 2. Раскрываем числитель. $\sin^2\alpha + 1 + 2\cos\alpha + \cos^2\alpha$.
Шаг 3. Группируем. $(\sin^2\alpha + \cos^2\alpha) + 1 + 2\cos\alpha = 1 + 1 + 2\cos\alpha = 2 + 2\cos\alpha$.
Шаг 4. Выносим 2 и сокращаем. $\dfrac{2(1 + \cos\alpha)}{\sin\alpha(1 + \cos\alpha)} = \dfrac{2}{\sin\alpha}$.
Ответ: $\dfrac{2}{\sin\alpha}$.
Пример 5 (доказательство). Доказать тождество: $\dfrac{1 - \cos^2\alpha}{1 - \sin^2\alpha} = \tg^2\alpha$.

Шаг 1. Преобразуем левую часть. $1 - \cos^2\alpha = \sin^2\alpha$ (из основного тождества).
$1 - \sin^2\alpha = \cos^2\alpha$ (тоже).
Шаг 2. Подставляем. $\dfrac{\sin^2\alpha}{\cos^2\alpha} = \left(\dfrac{\sin\alpha}{\cos\alpha}\right)^2 = \tg^2\alpha$.
💡 Обе части совпали — значит, тождество доказано.
Тождество доказано.
⚠️ Две ошибки, которые встречаются чаще всего:
• Знак в основном тождестве. Правильно: $\sin^2\alpha + \cos^2\alpha = 1$. Не минус, а плюс!
• Забыли модуль при извлечении корня. Если $\cos^2\alpha = 0{,}2$, то $\cos\alpha = \pm\sqrt{0{,}2}$, а не просто $\sqrt{0{,}2}$. Знак выбирается по четверти.
