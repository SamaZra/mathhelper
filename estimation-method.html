📊 Метод оценки (мажорант)

📖 Что такое метод оценки?

Метод оценки (мажорант) — это метод, при котором мы находим верхнюю оценку одной части уравнения и нижнюю оценку другой. Если они совпадают — мы нашли решение.

🎯 Главная идея: Если \(f(x) \le M\) и \(g(x) \ge M\), то уравнение \(f(x) = g(x)\) имеет решение только при \(f(x) = M\) и \(g(x) = M\).
📋 Алгоритм метода мажорант
📌 Пошаговый алгоритм Ключевой
  • Шаг 1. Преобразовать уравнение к виду \(f(x) = g(x)\).
  • Шаг 2. Найти максимальное значение \(f(x)\) (обозначим \(M\)).
  • Шаг 3. Найти минимальное значение \(g(x)\) (обозначим \(m\)).
  • Шаг 4. Если \(M < m\) → решений нет.
  • Шаг 5. Если \(M = m\) → решаем систему \(f(x) = M\) и \(g(x) = M\).
  • Шаг 6. Проверить, что найденные корни подходят.
    • 📐 Пример 1. \(x^2 + y^2 = 0\) простейший случай
    🔹 Шаг 1. Оцениваем
    \(x^2 \ge 0\), \(y^2 \ge 0\)
    Значит, \(x^2 + y^2 \ge 0\)
    🔹 Шаг 2. Находим точку равенства
    💡 Равенство \(= 0\) достигается только когда \(x^2 = 0\) и \(y^2 = 0\).
    \(x = 0\), \(y = 0\)
    ✅ Ответ: \((0; 0)\)
    💡 Оценка \(x^2 + y^2 \ge 0\) даёт ответ мгновенно!
    📐 Пример 2. \(\sin x + x^2 = 1\) комбинация ограниченных функций
    🔹 Шаг 1. Оцениваем каждую часть
    \(\sin x \le 1\)
    \(x^2 \ge 0\)
    💡 \(\sin x + x^2\) может принимать разные значения, но оценим:
    \(\sin x + x^2 \le 1 + x^2\) — не помогает.
    🔹 Шаг 2. Ищем другой подход
    💡 Заметим, что \(\sin x \le 1\), а \(x^2 \ge 0\).
    💡 Для равенства \(= 1\) нужно, чтобы \(\sin x = 1\) и \(x^2 = 0\).
    Из \(x^2 = 0\) → \(x = 0\).
    Но \(\sin 0 = 0 \neq 1\).
    ✅ Ответ: решений нет
    ⚠️ Здесь метод мажорант показывает, что решений нет!
    📐 Пример 3. \(x^2 - 2x + 2 + \sqrt{x^2-2x+3} = 2\) сложная мажоранта
    🔹 Шаг 1. Замечаем полный квадрат
    \(x^2 - 2x + 2 = (x-1)^2 + 1\)
    \(x^2 - 2x + 3 = (x-1)^2 + 2\)
    🔹 Шаг 2. Переписываем уравнение
    \((x-1)^2 + 1 + \sqrt{(x-1)^2 + 2} = 2\)
    \((x-1)^2 + \sqrt{(x-1)^2 + 2} = 1\)
    🔹 Шаг 3. Оцениваем
    \((x-1)^2 \ge 0\)
    \(\sqrt{(x-1)^2 + 2} \ge \sqrt{2}\)
    💡 Сумма \(\ge \sqrt{2} \approx 1.414\). Но правая часть \(= 1\).
    \(\sqrt{2} > 1\), значит левая часть всегда больше 1.
    ✅ Ответ: решений нет
    💡 Оценка снизу показала, что левая часть всегда больше правой.
    📐 Пример 4. \(x^2 + y^2 - 2x - 4y + 5 = 0\) выделение полных квадратов
    🔹 Шаг 1. Выделяем полные квадраты
    \(x^2 - 2x + y^2 - 4y + 5 = 0\)
    \((x-1)^2 - 1 + (y-2)^2 - 4 + 5 = 0\)
    \((x-1)^2 + (y-2)^2 = 0\)
    🔹 Шаг 2. Оцениваем
    \((x-1)^2 \ge 0\), \((y-2)^2 \ge 0\)
    💡 Сумма равна 0 только когда оба квадрата равны 0.
    \(x-1 = 0\) → \(x = 1\)
    \(y-2 = 0\) → \(y = 2\)
    ✅ Ответ: \((1; 2)\)
    💡 Метод оценки через полные квадраты — один из самых эффективных приёмов!
    📐 Пример 5. \(x^2 + y^2 \ge 2xy\) неравенство через оценку
    🔹 Шаг 1. Преобразуем
    \(x^2 + y^2 - 2xy \ge 0\)
    \((x-y)^2 \ge 0\)
    🔹 Шаг 2. Оцениваем
    💡 Квадрат всегда \(\ge 0\). Значит неравенство верно при всех \(x, y\).
    💡 Равенство достигается при \(x = y\).
    ✅ Ответ: верно при всех \(x, y \in \mathbb{R}\); равенство при \(x = y\)
    💡 Метод оценки позволяет доказывать неравенства и находить точки равенства.
    📌 Когда применять метод оценки
    🎯 Признаки того, что нужен метод оценки:

    📌 В уравнении есть сумма квадратов → \(\ge 0\).
    📌 Есть \(\sin x\) или \(\cos x\) → \( \le 1\).
    📌 Есть корень → \(\sqrt{x} \ge 0\).
    📌 Есть модуль → \(|x| \ge 0\).
    📌 Нужно доказать, что решений нет или найти единственное решение.

    ✅ Частые приёмы:
    • \(a^2 + b^2 = 0 \iff a = 0, b = 0\)
    • \(\sin x + \cos x \le \sqrt{2}\)
    • \(\sqrt{x} + \frac{1}{\sqrt{x}} \ge 2\) (при \(x > 0\))
    • \(x^2 - 2x + 2 = (x-1)^2 + 1 \ge 1\)
