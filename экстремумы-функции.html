📈 Экстремумы функции

📖 Зачем нужны экстремумы от горных вершин до прибыли компании

Представь горный хребет. Ты идёшь по тропе: сначала поднимаешься вверх, потом спускаешься вниз, потом снова вверх. Вершины и впадины на этом пути — и есть экстремумы (от латинского extremum — «крайний»).

В математике экстремумы — это точки, где функция достигает максимума или минимума. Они встречаются везде: максимальная прибыль компании, минимальные затраты, наибольшая скорость, наименьшее расстояние.

💡 Главная идея: в точке экстремума функция меняет направление — возрастание сменяется убыванием (максимум) или наоборот (минимум). А производная в этой точке либо равна нулю, либо не существует — и меняет знак.
📈 Возрастание и убывание функции связь с производной
Функция возрастает на интервале, если для любых $x_1 < x_2$ выполняется $f(x_1) < f(x_2)$.
Функция убывает на интервале, если для любых $x_1 < x_2$ выполняется $f(x_1) > f(x_2)$.
💡 Связь с производной:
• $f'(x) > 0$ на интервале → функция возрастает
• $f'(x) < 0$ на интервале → функция убывает
• $f'(x) = 0$ — критическая точка: либо экстремум, либо перегиб.
📌 Определение экстремумов максимум и минимум
Точка максимума $x_{\text{max}}$ — точка, в которой производная меняет знак с «+» на «−». Значение $f(x_{\text{max}})$ называется максимумом функции.
Точка минимума $x_{\text{min}}$ — точка, в которой производная меняет знак с «−» на «+». Значение $f(x_{\text{min}})$ называется минимумом функции.

Точки максимума и минимума вместе называются точками экстремума.

💡 Важно: максимум и минимум — это локальные понятия. Функция может иметь несколько максимумов, и один из них может быть меньше другого минимума. Экстремум — это «вершина в своей окрестности», а не глобальный максимум.
🔄 Смена знака производной главный признак экстремума
+ → − — максимум (возрастание сменяется убыванием)

− → + — минимум (убывание сменяется возрастанием)

+ → + — экстремума нет (функция продолжает возрастать)

− → − — экстремума нет (функция продолжает убывать)
✅ Экстремум есть только тогда, когда производная меняет знак! Если $f'(x_0) = 0$, но знак не меняется — это не экстремум, а точка перегиба.
📐 Алгоритм нахождения экстремумов 5 шагов
  1. Найти производную $f'(x)$.
  2. Найти критические точки: решить $f'(x) = 0$.
  3. Определить знаки производной на интервалах (метод интервалов).
  4. Сделать вывод: + → − — максимум, − → + — минимум.
  5. Вычислить значения функции в точках экстремума.
📖 Пример 1. $f(x) = x^3 - 3x$ с подробным решением
Шаг 1. Найдём производную.
$f'(x) = 3x^2 - 3$.

Шаг 2. Найдём критические точки.
$f'(x) = 0$
$3x^2 - 3 = 0$
$x = -1,\; x = 1$.

Шаг 3. Метод интервалов.
Критические точки $-1$ и $1$ разбивают числовую прямую на три интервала:
$(-\infty, -1)$, $(-1, 1)$, $(1, +\infty)$.
Знаки производной $f'(x) = 3x^2 - 3$ на интервалах
На интервале $(-\infty, -1)$:
$f'(-2) = 9 > 0$ — знак «+», функция возрастает.

На интервале $(-1, 1)$:
$f'(0) = -3 < 0$ — знак «−», функция убывает.

На интервале $(1, +\infty)$:
$f'(2) = 9 > 0$ — знак «+», функция возрастает.

Шаг 4. Определяем точки экстремума.
$x = -1$: $+ \to -$ ⇒ максимум, $x_{\text{max}} = -1$.
$x = 1$: $- \to +$ ⇒ минимум, $x_{\text{min}} = 1$.

Шаг 5. Находим значения функции.
$f(-1) = (-1)^3 - 3(-1) = -1 + 3 = 2$ — максимум.
$f(1) = 1^3 - 3 \cdot 1 = 1 - 3 = -2$ — минимум.

Ответ: максимум в $(-1; 2)$, минимум в $(1; -2)$.
📌 Дополнительные примеры
Пример 2. $f(x) = x^2 - 4x + 3$

Шаг 1. $f'(x) = 2x - 4$.
Шаг 2. $f'(x) = 0 \Rightarrow x = 2$.
Шаг 3. $- \to +$ ⇒ минимум.
Шаг 4. $f(2) = 4 - 8 + 3 = -1$.
Ответ: минимум в $(2; -1)$.
Пример 3. $f(x) = -x^2 + 4x - 3$

Шаг 1. $f'(x) = -2x + 4$.
Шаг 2. $f'(x) = 0 \Rightarrow x = 2$.
Шаг 3. $+ \to -$ ⇒ максимум.
Шаг 4. $f(2) = -4 + 8 - 3 = 1$.
Ответ: максимум в $(2; 1)$.
Пример 4. $f(x) = x^4 - 2x^2$

Шаг 1. $f'(x) = 4x^3 - 4x = 4x(x^2 - 1)$.
Шаг 2. $f'(x) = 0 \Rightarrow x = -1, 0, 1$.
Шаг 3. Знаки: $+$, $-$, $-$, $+$ (чередование с учётом чётности).
💡 $x = -1$: $- \to +$? Проверь самостоятельно.
Шаг 4. $x = -1$: минимум, $x = 0$: максимум, $x = 1$: минимум.
$f(-1) = -1,\; f(0) = 0,\; f(1) = -1$.
Ответ: минимумы в $(-1; -1)$, $(1; -1)$, максимум в $(0; 0)$.
⚠️ Типичные ошибки
ОшибкаПочему неверноКак правильно
Считают, что если $f'(x_0) = 0$, то это экстремум Если производная не меняет знак — экстремума нет (например, $y = x^3$ при $x = 0$). Проверять смену знака производной
Путают точку экстремума и значение функции в ней Точка — это $x$, значение — это $y$. В ответе пишут оба числа. Максимум в $(-1; 2)$ — точка и значение
Не проверяют знаки на всех интервалах Можно пропустить экстремум или принять точку перегиба за экстремум. Проверять знак на каждом интервале
Забывают про критические точки, где $f'(x)$ не существует Экстремум может быть в точке, где производная не определена. Учитывать и нули, и точки разрыва $f'$
📊 Сводная таблица
1. $f'(x) > 0$ → возрастает; $f'(x) < 0$ → убывает.

2. Экстремум — только при смене знака производной.

3. $+ \to -$ → максимум; $- \to +$ → минимум.

4. Алгоритм: производная → критические точки → знаки → вывод → значения.

5. В ответе указывать точку и значение: $(x_{\text{max}}; f(x_{\text{max}}))$.
