Экстремумы функции

📈 Возрастание и убывание функции

Функция возрастает на интервале, если для любых \(x_1 < x_2\) выполняется \(f(x_1) < f(x_2)\).

Функция убывает на интервале, если для любых \(x_1 < x_2\) выполняется \(f(x_1) > f(x_2)\).

Связь с производной: \(f'(x) > 0\) — возрастает, \(f'(x) < 0\) — убывает.

📌 Определение экстремумов

Точка максимума \(x_{\text{max}}\) — точка, в которой производная меняет знак с «+» на «−». Значение \(f(x_{\text{max}})\) называется максимумом функции.

Точка минимума \(x_{\text{min}}\) — точка, в которой производная меняет знак с «−» на «+». Значение \(f(x_{\text{min}})\) называется минимумом функции.

Точки максимума и минимума называются точками экстремума.

🔄 Смена знака производной
  • \(+ \to -\) — максимум (возрастание → убывание)
  • \(- \to +\) — минимум (убывание → возрастание)
  • \(+ \to +\) — экстремума нет (продолжает возрастать)
  • \(- \to -\) — экстремума нет (продолжает убывать)

✅ Экстремум есть только когда производная меняет знак!

📐 Алгоритм нахождения экстремумов
  1. Найти производную \(f'(x)\).
  2. Найти критические точки: \(f'(x) = 0\).
  3. Определить знаки производной на интервалах.
  4. Сделать вывод: \(+ \to -\) — максимум, \(- \to +\) — минимум.
  5. Вычислить значения функции в точках экстремума.
📖 Пример 1 (с подробным решением): \(f(x) = x^3 - 3x\)
Шаг 1. Найдём производную.
\(f'(x) = 3x^2 - 3\)

Шаг 2. Найдём критические точки.
\(f'(x) = 0\)
\(3x^2 - 3 = 0\)
\(x = -1,\; x = 1\)

Шаг 3. Метод интервалов.
Критические точки \(-1\) и \(1\) разбивают числовую прямую на три интервала:
\((-\infty, -1)\), \((-1, 1)\), \((1, +\infty)\)
На интервале \((-\infty, -1)\):
\(f'(-2) = 9 > 0\) — знак «+», функция возрастает.

На интервале \((-1, 1)\):
\(f'(0) = -3 < 0\) — знак «−», функция убывает.

На интервале \((1, +\infty)\):
\(f'(2) = 9 > 0\) — знак «+», функция возрастает.

Шаг 4. Определяем точки экстремума.
\(x = -1\): \(+ \to -\) ⇒ максимум \(x_{\text{max}} = -1\)
\(x = 1\): \(- \to +\) ⇒ минимум \(x_{\text{min}} = 1\)

Шаг 5. Находим значения функции.
\(f(-1) = 2\) — максимум
\(f(1) = -2\) — минимум

Ответ: максимум в \((-1; 2)\), минимум в \((1; -2)\).
📌 Дополнительные примеры
Пример 2. \(f(x) = x^2 - 4x + 3\)
\(f'(x) = 2x - 4\), \(x = 2\)
\(- \to +\) ⇒ минимум
\(f(2) = -1\)
Ответ: минимум в \((2; -1)\).
Пример 3. \(f(x) = -x^2 + 4x - 3\)
\(f'(x) = -2x + 4\), \(x = 2\)
\(+ \to -\) ⇒ максимум
\(f(2) = 1\)
Ответ: максимум в \((2; 1)\).
Пример 4. \(f(x) = x^4 - 2x^2\)
\(f'(x) = 4x(x^2-1)\), точки: \(x = -1, 0, 1\)
\(x = -1\): минимум, \(x = 0\): максимум, \(x = 1\): минимум
\(f(-1) = -1,\; f(0) = 0,\; f(1) = -1\)
Ответ: минимумы в \((-1;-1)\), \((1;-1)\), максимум в \((0;0)\).
